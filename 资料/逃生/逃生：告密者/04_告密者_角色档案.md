# 《逃生：告密者》（Outlast: Whistleblower）全角色档案与事迹经历

## 一、作品元信息

- **作品名**：逃生：告密者（Outlast: Whistleblower）
- **开发商**：Red Barrels
- **发售年份**：2014 年
- **性质**：《逃生1》（Outlast）的 DLC 章节，故事线与正传并行并延伸至正传结局之后
- **主角**：韦伦·帕克（Waylon Park）

## 二、角色分类说明

本档案将角色分为三类：

1. **核心角色**：本 DLC 的专属主要角色，包括主角韦伦、主要追猎者、关键 NPC 与反派。
2. **联动角色**：同时登场于正传的跨作角色，在《告密者》中承担关键剧情衔接作用。
3. **群体条目**：以群体形式出现的敌人或背景角色。

## 三、核心角色

### 1. 韦伦·帕克（Waylon Park）

- **别名**：无
- **身份 / 职业**：穆克夫（Murkoff）签约软件工程师，《告密者》主角
- **外貌与性格特征**：
  - 作为穆克夫雇员，韦伦身着普通工作服，外貌在游戏中以第一人称呈现，直接形象较少。
  - 性格上具有强烈的良知与责任感：在发现公司非法人体实验后选择冒死向全球媒体群发举报邮件，体现出正义感与对家庭的责任感。
- **游戏内事迹经历（按时间线）**：
  1. 2013 年 9 月 17 日，潜入巨山精神病院（Mount Massive Asylum）服务器机房，向全球多家媒体发送举报邮件。
  2. 邮件发送行为被上司杰里米·布莱尔察觉，随即被逮捕并关押审讯室。
  3. 被公司以"病人"身份强制接受 Morphogenic Engine（形态发生引擎）疗法，险些沦为实验体。
  4. 暴乱夜趁乱逃出审讯室牢房，开始在病院内逃亡。
  5. 在医院区/拘留区目睹弗兰克·马内拉啃食守卫尸体，并在此后多次躲避弗兰克的追杀。
  6. 穿过娱乐区，继续向出口方向前进。
  7. 在职业培训区被埃迪·格鲁斯金用毒气熏晕，险遭"婚礼/阉割"仪式。
  8. 借助现场梯子与反击手段逃脱格鲁斯金的控制。
  9. 在出口处被布莱尔暗算；危急时刻被瓦尔里德形态下的迈尔斯所救。
  10. 驾车逃离巨山精神病院，与家人团聚。
- **结局**：成功逃离巨山精神病院，与家人团聚（正传/流程来源）。
- **登场媒介**：《逃生：告密者》DLC（核心主角）。
- **配音演员**：Shawn Baichoo（同时为《逃生1》主角迈尔斯·阿普舍配音）。
- **来源标注**：Fandom、BehindTheVoiceActors、Steam 社区指南、游戏流程。

### 2. 埃迪·格鲁斯金（Eddie Gluskin）

- **别名**："新郎"（The Groom）
- **身份 / 职业**：巨山精神病院被拘禁的病人 / 变种人，DLC 中段主要追猎者
- **外貌与性格特征**：
  - 年龄 46 岁（中文维基数据）。
  - 病例番号 196（NGA 评测）。
  - 外观具有明显的"新郎"式变态仪式感，常以婚礼相关意象进行恐吓。
  - 性格扭曲、偏执，因童年性暴力创伤而形成极端控制欲，将受害者视为自己的"新娘"并企图实施阉割/割礼仪式。
- **游戏内事迹经历（按时间线）**：
  1. 童年时期遭受性暴力创伤，成为其精神扭曲的根源背景。
  2. 被穆克夫拘禁于巨山精神病院，并因 Morphogenic Engine 实验进一步异化为"新郎"。
  3. 在职业培训区设立"猎场"，布置陷阱并猎杀其他病人与闯入者。
  4. 用毒气熏晕韦伦，企图将其作为"新娘"进行婚礼/阉割仪式。
  5. 在仪式现场被韦伦借助梯子与反击手段逃脱。
  6. 最终追逐至正传中也有出现的地下实验室区域，被瓦尔里德（迈尔斯形态）撕碎。
- **结局**：被瓦尔里德（迈尔斯形态）杀死，尸体状态对应《逃生1》正传中其球形容器已破损的场景。
- **登场媒介**：《逃生：告密者》DLC（核心追猎者），《逃生1》正传（容器与背景呼应）。
- **配音演员**：Graham Cuthbertson。
- **来源标注**：中文维基、NGA 评测、IMDb、Fandom Eddie Gluskin 词条。

### 3. 弗兰克·马内拉（Frank Antonio Manera）

- **别名**："食人者厨师"（The Cannibal）
- **身份 / 职业**：食人癖变种人，暴乱夜在巨山病院医院区 / 厨房游荡的追猎者
- **外貌与性格特征**：
  - 外形具有厨师/屠夫特征，手持肉钩等凶器，给人强烈的嗜血、残忍印象。
  - 性格极度暴力且丧失人性，以猎杀和啃食人肉为乐。
- **游戏内事迹经历（按时间线）**：
  1. 暴乱夜期间在医院区/拘留区活动，杀死并啃食守卫尸体，被韦伦在牢房中目睹。
  2. 此后多次追踪并试图杀死韦伦。
  3. 在厨房 / 屠宰场区域与韦伦展开周旋与追逐。
  4. 在娱乐区 / 剧场区域有进一步遭遇，但具体被杀细节未明确呈现。
- **结局**：公开资料普遍认定其死亡（Steam 指南汇总称"death"），但**具体死法未明确**。Reddit 讨论提出可能死于克里斯·沃克、穆克夫特勤队或其他变种人，均为推测，未证实。
- **登场媒介**：《逃生：告密者》DLC（医院区、厨房、娱乐区）。
- **配音演员**：Edward Yankie。
- **来源标注**：Steam 指南、Reddit 讨论、Fandom Frank Manera 词条、Metacritic 详情页。

### 4. 丹尼斯（Dennis）

- **别名**：无
- **身份 / 职业**：变种人囚犯，职业培训区阁楼区域出现的 NPC
- **外貌与性格特征**：
  - 作为普通变种人之一，外形无明显特异性，主要出现在阁楼等阴暗区域。
  - 从他与另一变种人的隔墙对话中可窥见其精神恍惚、沉浸于自我世界的状态。
- **游戏内事迹经历（按时间线）**：
  1. 在职业培训区阁楼透过墙板与另一变种人交谈，韦伦可在附近偷听。
  2. 有粉丝考证认为他就是"从格鲁斯金手中救下韦伦的人"，但**该说法属于粉丝考证，未证实**。
- **结局**：未明确。
- **登场媒介**：《逃生：告密者》DLC（职业培训区阁楼）。
- **配音演员**：未确认（推测为 Alain Goulem 或 Neil Napier 之一，二人均配 Variants）。
- **来源标注**：Fandom Dennis 词条、Reddit 粉丝考证、Fandom 西语配音页。

### 5. 杰里米·布莱尔（Jeremy Blaire）

- **别名**：无
- **身份 / 职业**：穆克夫公司高管，瓦尔里德计划 / 巨山病院项目负责人层级，韦伦的直接上司
- **外貌与性格特征**：
  - 外表为公司高层管理人员形象，西装革履，态度冷酷。
  - 性格阴险、控制欲强，对泄密零容忍，为达目的不择手段。
- **游戏内事迹经历（按时间线）**：
  1. 察觉韦伦向外界群发举报邮件后，下令逮捕韦伦。
  2. 将韦伦关押审讯室，并以"病人"名义强制其接受 Morphogenic Engine 疗法。
  3. 暴乱夜期间伪装受伤，在出口处设局暗算韦伦。
  4. 被瓦尔里德形态的迈尔斯击杀。
- **结局**：瓦尔里德进入其身体并将其撕碎，当场死亡。
- **登场媒介**：《逃生：告密者》DLC（核心反派）。
- **配音演员**：Matt Holland。
- **来源标注**：Fandom Jeremy Blaire 词条、Metacritic 详情页、游戏流程。

## 四、联动角色

### 6. 迈尔斯·阿普舍（Miles Upshur）

- **别名**：无
- **身份 / 职业**：独立记者，《逃生1》正传主角
- **外貌与性格特征**：
  - 身穿深色外套与牛仔裤，手持摄像机，是典型的调查记者形象。
  - 勇敢、执着，为了揭露真相不惜深入险境。
- **游戏内事迹经历（按时间线）**：
  1. 收到韦伦群发的举报邮件，决定前往巨山精神病院调查。
  2. 在《逃生1》正传雨夜潜入病院，经历一系列恐怖事件。
  3. 正传结局中被瓦尔里德附身为新宿主。
  4. 在《告密者》结尾以瓦尔里德形态现身，杀死布莱尔并救下韦伦。
- **结局**：成为瓦尔里德的新宿主，以超自然形态继续存在。
- **登场媒介**：《逃生1》正传（主角），《逃生：告密者》结尾客串。
- **配音演员**：Shawn Baichoo。
- **来源标注**：YouTube 角色配音视频、BehindTheVoiceActors、游戏流程。

---

### 7. 瓦尔里德（The Walrider）

- **别名**：无
- **身份 / 职业**：穆克夫"瓦尔里德计划"产物，纳米虫群实体，受宿主控制
- **外貌与性格特征**：
  - 外观为一团由纳米虫群构成的发光人形雾状实体，具有极强的压迫感。
  - 本身无意识，行为受宿主意志支配。
- **游戏内事迹经历（按时间线）**：
  1. 《逃生1》正传中宿主为比利·霍普（Billy Hope）。
  2. 迈尔斯关闭比利维生系统后，瓦尔里德转附身于迈尔斯。
  3. 在《告密者》结局以迈尔斯形态击杀布莱尔，间接帮助韦伦脱逃。
- **结局**：随宿主迈尔斯继续以超自然形态存在。
- **登场媒介**：《逃生1》正传，《逃生：告密者》结局。
- **配音演员**：无（非人声实体）。
- **来源标注**：游戏流程、Fandom Outlast 维基。

## 五、群体条目

### 8. 双胞胎（The Twins）

- **别名**：无
- **身份 / 职业**：变种人，DLC 医院区出现的追猎者（与正传同款敌人）
- **外貌与性格特征**：
  - 两名身形高大的男性变种人，常结伴行动，给人阴森、协同威胁的感觉。
  - 与正传中的双胞胎敌人形象一致。
- **游戏内事迹经历（按时间线）**：
  1. 在 DLC 医院区多次出现，协同追杀韦伦。
  2. 与正传剧情无直接互动，但作为敌人群体增强了医院区的压迫氛围。
- **结局**：未明确。
- **登场媒介**：《逃生：告密者》DLC（医院区），《逃生1》正传。
- **配音演员**：Alain Goulem、Neil Napier。
- **来源标注**：Fandom 西语配音页、游戏流程。

### 9. 穆克夫守卫与普通变种人群像（Murkoff Guards & Common Variants）

- **别名**：无
- **身份 / 职业**：巨山精神病院的看守人员与接受实验的普通病人 / 变种人
- **外貌与性格特征**：
  - 守卫身着穆克夫保安制服，装备有限，在暴乱中大量被杀。
  - 普通变种人则形态各异，多数精神错乱、具有攻击性，少数仅作为背景 NPC 出现。
- **游戏内事迹经历（按时间线）**：
  1. 暴乱夜爆发时，多数穆克夫守卫被屠杀（弗兰克等变种人参与弑杀），少数幸存。
  2. 韦伦逃亡途中大量遭遇普通变种患者，他们构成 DLC 最主要的敌对群体之一。
- **结局**：多数守卫死亡；普通变种人群体结局未明确。
- **登场媒介**：《逃生：告密者》DLC（全区域）。
- **配音演员**：Alain Goulem 等（Variants）。
- **来源标注**：Fandom 西语配音页、游戏流程。
