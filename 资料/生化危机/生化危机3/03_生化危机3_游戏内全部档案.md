## 三、机械解谜收集品（本作核心）

### 3.1 电池与铜像（市政区域）

| 步骤 | 物品 | 位置 / 操作 |
|------|------|-----------|
| 1 | **铜书（Bronze Book）** | 加油站附近铜像上取得 |
| 2 | 放置于餐厅前街**喷水池**的空位 | — |
| 3 | **铜盘（Bronze Compass）** | 从喷水池取得 |
| 4 | 装回市政大楼铜像 | 取得**电池（Battery）** |

### 3.2 电车三件套

| 物品 | 取得方式 |
|------|---------|
| **电线（Power Cable）** | 大型车库中闪光的汽车上 |
| **保险丝（Fuse）** | 变电站 |
| **混合机油（Mixed Oil）** | 由**机油（Machine Oil）+ 机油添加剂（Oil Additive）**混合而成 |

### 3.3 变电房（Sub Station）变压装置

- 先设为 **manual mode**；
- **第一间房（115v-125v）**：按 **红 → 红 → 红 → 蓝** → 取得**榴弹发射器**；
- **第二间房（15v-25v）**：按 **红 → 蓝 → 蓝 → 蓝** → 取得**保险丝**；
- 丧尸聚在门口时**可选提高电压**将其全部击倒；亦可再按**青青赤赤**取得另一闸中的武器。

### 3.4 安布雷拉办公室：化学药品贮藏室

- 用桌上**遥控器**看电视广告，记下英文大字——**三选一：AQUACURE / SAFSPRIN / ADRAVIL**；
- 在电脑上输入该密码解锁大门；
- 进入取得**机油添加剂**。

### 3.5 时钟塔：齿轮与时钟机关

| 收集品 | 说明 |
|--------|------|
| **时之神的钥匙 / 时钟塔钥匙** | 礼堂取得 |
| **贝榭尔钥匙（Basement Key）** | 客厅取得 |
| **银色齿轮（Silver Gear）** | 时钟塔最高层柜子（存档点旁） |
| **金色齿轮（Gold Gear）** | 解开"**时之女神时钟机关**"后从暗格取得 |
| **时之神的齿轮（Chronos Gear）** | 金 + 银齿轮组合而成 |
| **时之神的钥匙（Chronos Key）** | Chronos Gear + 时钟塔钥匙组合 |

**时之女神时钟机关解法**：
- 需令中央"**现在之女神**"的时钟画与其余两幅一样指向 **12 时**；
- 三颗宝石的作用：**黑曜石（Obsidian）= 过去、水晶（Crystal）= 现在、琥珀（Amber）= 未来**（依初始时间不同而有变体）；
- 若"现在"时钟画最初指 **9:00**，则：**黑曜石放"过去"、琥珀放"现在"、水晶放"未来"**。

**音乐盒机关（Music Box Puzzle）**：
- 需令音乐与操作音乐盒时听到的旋律一致；
- 正确设定可取得 **Chronos Gear**。

### 3.6 医院：疫苗合成

| 步骤 | 内容 |
|------|------|
| 电梯声锁 | 用桌上的**录音机（tape recorder）**开启电梯 |
| 401 病房 | 从尸体手中读取**三位数字密码** |
| 402 病房 | **推动铁架到正确位置**（与 401 柜子位置对应）→ 输入密码 → 取得**疫苗原素（Vaccine Medium）** |
| B3 实验室 | 取得**培养液原料**；在**药品合成装置**上按 **I → III → A** → 取得**疫苗培养液** |
| 合成 | 培养液 + 疫苗原素 = **疫苗** |

### 3.7 公园与废品处理厂

| 区域 | 收集 / 解谜要点 |
|------|---------------|
| **公园** | **佣兵钥匙（Mercenary Key）**（红油桶旁尸体）；大门左侧喷水池机关（**将黑色与白色轮互换位置**）；墓地小屋的火炉用**打火机 + 铁棒**开启秘密房间取得**公园钥匙** |
| **蒸气室** | 依 **A → B → C → A → E → D → A → B → C** 顺序按掣启动电力装置 |
| **实验室** | 装上**水质样本**；调节条子与样本一致；打卡机取得**Umbrella 卡** |
| **火箭筒** | 限定时间内击倒追迹者后在尸体上取得 **Umbrella 卡**，回蒸气电梯用卡取得**火箭筒** |
| **最终战前** | 依序将 **12 个电池**推回电池箱（**必须全部推完**才打 Boss） |

**证据等级：【已核实】（巴哈姆特、任地鱼、Video-Games-Museum 攻略）。**
