# 05 生化危机3 大事件时间线

> 对应游戏：《生化危机3》（Resident Evil 3: Nemesis, 1999 / 2020 重制版）
> 说明：本作与《生化危机2》**时间线高度重合**（同一时段的另一主角线），并以"**浣熊市被核弹毁灭**"收束整个 1998 年篇章。
> 证据标注：【已核实】【推测】【未明确】。

```

        ↓

```

## 四、结局：浣熊市毁灭（1998 年 10 月 1 日）

| 项目 | 内容 |
|------|------|
| **时间** | **1998 年 10 月 1 日**，伴随黎明的曙光 |
| **行动** | 美国政府为杜绝后患，以**核弹对浣熊市进行彻底消毒** |
| **结果** | 浣熊市**化为焦土**；生化病毒造物与可能遗留的幸存者尽数毁灭；**约 10 万人死亡** |
| **史称** | "**浣熊市生化危机事件**" |
| **影响** | 惨剧震惊世界，**生化病毒引发的纷争由此正式开启** |
| **原版字幕** | "**浣熊市已经被彻底从地图上抹去。**" |
| **重制版差异** | 从吉尔直升机视角望去，**导弹落下后城市被浓烟覆盖**，而非烈火吞噬 |

**证据等级：【已核实】（百度百科、360百科、游民星空）。**

## 六、要点与易混提示

1. **两作同期**：《生化危机2》与《生化危机3》**时间线高度重合**——分别对应**里昂/克莱尔线**与**吉尔线**，共同构成"浣熊市事件"。
2. **追迹者 ≠ 暴君**：追迹者是 **Nemesis-α 寄生虫 + T-103 暴君**的组合体，产于**欧洲第六实验室**，拥有智力与服从性——是《生化危机2》暴君的"进化版"。
3. **U.B.C.S. 是实验品**：名义救援平民，实为**测试 B.O.W. 作战能力**；尼古拉是安布雷拉安插的"监视员"。
4. **核弹是终点**：浣熊市的毁灭是**政府掩盖真相**的极端手段，直接导致安布雷拉走向崩解。
5. **吉尔的命运**：她在本作中感染 T 病毒后被救回；后续在《生化危机5》等作中继续登场（部分版本有"被威斯克控制"的桥段）。
