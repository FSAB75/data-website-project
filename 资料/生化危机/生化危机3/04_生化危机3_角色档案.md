# 04 生化危机3 角色档案

> 对应游戏：《生化危机3》（Resident Evil 3: Nemesis, 1999 / 2020 重制版）
> 收录范围：**主角** + **U.B.C.S. 成员** + **前作回归角色** + **主要敌人**。
> 说明：本作角色多为系列核心班底，其背景多在其他作品中补完，本文件以本作登场信息为主并标注延伸。
> 证据标注：【已核实】【推测】【未明确】。

## 一、主角

### 1.1 吉尔·瓦伦蒂安（Jill Valentine）

| 项目 | 内容 |
|------|------|
| 身份 | S.T.A.R.S. 成员；**本作主角** |
| 背景 | 洋馆事件后**展开对安布雷拉公司的秘密调查**；在队中担任**后援工作** |
| 性格 | 为人爽朗、**正义感很强** |
| 履历 | 加入 S.T.A.R.S. 前在**美国陆军特种部队**接受训练，是**爆炸物处理专家** |
| 战斗风格 | 一般使用**自己调较过的手枪**；对各种武器亦能熟练使用；展现**优秀作战能力与对异常事件的良好把握** |
| 本作经历 | 被追迹者追杀 → 遇卡洛斯 → 电车/钟楼 → **感染 T 病毒** → 被卡洛斯疫苗救回 → 击败变异追迹者 |
| 结局 | 与卡洛斯一同乘**巴瑞驾驶的直升机**逃出核爆前的浣熊市 |

**证据等级：【已核实】（百度百科、360百科）。**

## 二、U.B.C.S. 成员

### 2.1 卡洛斯·奥利维拉（Carlos Oliveira）

| 项目 | 内容 |
|------|------|
| 身份 | **U.B.C.S.（安布雷拉生化危机对策部队）士兵** |
| 剧情 | 部队抵达浣熊市后**几乎全灭**、人员死伤分离；他决定与吉尔共同行动 |
| 关键行动 | 吉尔感染 T 病毒后**奔赴医院寻找疫苗**；带回疫苗使吉尔感染得到控制 |
| 结局 | 与吉尔一同逃出浣熊市 |

**证据等级：【已核实】（百度百科、游民星空）。**

## 四、主要敌人

### 4.1 追迹者（Nemesis / T-203）

| 项目 | 内容 |
|------|------|
| 身份 | **本作主要敌人**；"T-203 型化学武器" |
| 真身 | **保护伞公司欧洲分部第六实验室**的产物——**Nemesis-α 寄生虫植入 T-103 型暴君**体内开发而成 |
| 特征 | 身着黑色外套；**手持火箭筒**；具备**远超同类产品的智力与服从性** |
| 设计目标 | **超越《生化危机2》中的暴君**，让玩家体会"被猎杀"的窒息感 |
| 剧情 | 全篇追杀吉尔；轰碎救援直升机；导致吉尔感染；**最终变异形态在废品处理厂被吉尔击败** |
| 另注 | 原版中**使用灯光无法取得其身上道具但可避免追击；使用电源线则相反** |

**证据等级：【已核实】（游民星空、中文百科、360百科）。**

## 五、角色关系速览

```
吉尔（S.T.A.R.S.，洋馆事件后独查安布雷拉）
   │  被追迹者追杀
   ├──→ 卡洛斯（U.B.C.S.，部队几乎全灭后同行）
   │        └─ 为感染的吉尔取回疫苗
   │
   ├── 米歇尔（U.B.C.S. B队长，电车上与追迹者同归于尽）
   ├── 尼古拉（U.B.C.S. "监视员"，为雇主收集数据）
   │
   ├── 布拉德（前S.T.A.R.S.飞行员，被追迹者杀害）
   └── 巴瑞（前S.T.A.R.S.老队友，结局驾直升机救援）

追迹者（Nemesis-α + T-103暴君）＝ 全篇追杀者
结局：1998-10-01 浣熊市被核弹毁灭
```
