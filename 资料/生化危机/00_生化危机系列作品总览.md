## 一、系列概况

《生化危机》是 Capcom 于 **1996 年**在 PlayStation 上推出的**生存恐怖（Survival Horror）**游戏系列，被公认为"**开创生存恐怖这一游戏类型**"的奠基之作。

- **标题由来**：日本版名为"バイオハザード（Biohazard，生物危害）"；因该名称在欧美已被占用，英语版改名"**Resident Evil（常驻之恶）**"——大陆/香港译为"生化危机"，台湾则据欧美版标题与初代洋馆译为"**恶灵古堡**"。
- **核心主题**：**病毒、寄生虫等病原体**及其感染体；剧情围绕**生物武器引发的灾难**展开，而非"生物化学"本身。
- **系列规模**：全球累计销量**超过 1.6 亿份**（官方 2024 年数据），是 Capcom 最畅销的 IP；衍生出真人电影、CG 动画电影、电视剧、漫画、小说、主题娱乐等庞大媒体矩阵。

## 五、资料收集标准（沿用既有 5 项）

每部作品收集：

1. **主线剧情** → `01_<作品>_主线剧情.md`
2. **支线剧情** → `02_<作品>_支线剧情.md`
3. **游戏内全部档案 / 收集要素** → `03_<作品>_游戏内全部档案.md` + `03_<作品>_档案清单.csv`
4. **角色档案与事迹经历** → `04_<作品>_角色档案.md` + `04_<作品>_角色清单.csv`
5. **大事件时间线** → `05_<作品>_大事件时间线.md`

**本系列的"档案"口径**：与《逃生》（文档/录音）、《尸体派对》（名牌/手记）不同，《生化危机》的收集品为——
- **文件 / 日记 / 笔记（Files / Documents）**：剧情关键文献；
- **钥匙、道具、拼图 /  emblem、徽章、棋子**（谜题收集品）；
- **武器 / 弹药 / 特殊武器（Infinite Rocket Launcher 等）**；
- **隐藏要素**：额外模式（佣兵模式、The Ghost、豆腐块）、隐藏服装、S 级评价、速通奖励；
- **重制版新增**：Records（记录/资料收集）、挑战列表、Request 悬赏。

内容规范沿用：证据三档标注【已核实 / 推测 / 未明确】；专有名词用"中文译名（英文原名）"；概括性转述、不逐字转录游戏内文本；文末附来源清单与不确定项清单。

## 六、系列核心时间线（速览，详见各作品 05 文件）

| 游戏内年份 | 事件 | 作品 |
|-----------|------|------|
| 1960s–1980s | 斯宾塞与安布雷拉创立；始祖病毒发现；生化武器研发 | 背景（贯穿系列） |
| **1998 年 7 月** | **黄道列车事件** → **洋馆事件** | 生化危机0 → 生化危机1 |
| **1998 年 9 月底** | **浣熊市事件**（T 病毒全面爆发、城市毁灭） | 生化危机2 / 生化危机3 |
| **1998 年 12 月** | **洛克福特岛事件** | 生化危机：代号维罗妮卡 |
| **2004–2005 年** | 西班牙"光明教"事件（里昂救总统女儿） | 生化危机4 |
| **2005 年** | 地中海"女王号"恐怖袭击 | 生化危机：启示录 |
| **2009 年** | 非洲"三联（TRICELL）"事件；与威斯克决战 | 生化危机5 |
| **2012–2013 年** | 全球 C 病毒爆发；三线并行 | 生化危机6 |
| **2013 年** | 萨比提岛事件 | 生化危机：启示录2 |
| **2017 年** | 美国贝克农场事件（伊森登场） | 生化危机7 |
| **2021 年** | 东欧村庄事件；伊森之死；母神米兰达 | 生化危机8：村庄 |
| **2026 年** | 系列最新正作 | 生化危机9：安魂曲 |

**贯穿暗线**：**伞公司（Umbrella）创始人奥斯威尔·E·斯宾塞的"永生计划"**——从发现始祖病毒起，其真实目标并非制造生物武器牟利，而是筛选能完美适配病毒的个体以实现人类永生。威斯克的 Uroboros 计划、米兰达与菌主（Mutamycete）的研究，均是这一野心在不同时代的延伸。
