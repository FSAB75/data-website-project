# 04 生化危机2 角色档案

> 对应游戏：《生化危机2》（Resident Evil 2, 1998 / 2019 重制版）
> 收录范围：**双主角** + **核心配角** + **反派**。
> 说明：本作角色多为系列核心班底，其背景多在其他作品中补完，本文件以本作登场信息为主并标注延伸。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、可玩主角

### 1.1 里昂·斯科特·肯尼迪（Leon S. Kennedy）

| 项目 | 内容 |
|------|------|
| 身份 | **浣熊市警察局新人警察**；可玩主角之一 |
| 背景 | 警校毕业时**主动申请调往浣熊市警察局**就职 |
| 性格 | 缺乏经验，但**正义感与责任感极强** |
| 名场面 | 上任当天**睡过头**，直到将近傍晚才急急忙忙开车出发 |
| 本作结局 | 与雪莉**被美国政府拘捕**（接《生化危机4》） |
| 延伸 | 系列后续核心主角 |

**证据等级：【已核实】（百度百科）。**

### 1.2 克莱尔·雷德菲尔德（Claire Redfield）

| 项目 | 内容 |
|------|------|
| 身份 | **女大学生**（骑摩托车）；可玩主角之一 |
| 背景 | **S.T.A.R.S. 克里斯·雷德菲尔德之妹**；平时接受过哥哥在**格斗和射击**方面的指导 |
| 性格 | **活泼开朗** |
| 来意 | 为**寻找失去联络的哥哥**而造访浣熊市 |
| 本作结局 | 继续寻找克里斯（接《代号维罗妮卡》） |

**证据等级：【已核实】（百度百科）。**

---

## 二、核心配角

### 2.1 艾达·王（Ada Wong）

| 项目 | 内容 |
|------|------|
| 身份 | **身份充满重重谜团的亚裔女性**；里昂在警局遇到的女子 |
| 表面说法 | "**为寻找失联的恋人约翰**" |
| 真实身份 | **某秘密组织派出的间谍**，目的是**回收 G 病毒样本** |
| 性格 | **遇事格外冷静** |
| 剧情 | 为里昂疗伤；危急时刻出现让暴君掉入熔炉；战斗中重伤，**向里昂表达爱意后"死去"** |
| 真相 | **实际并未死亡**——远处扔给里昂火箭发射器；最终**生还并带走 G 病毒样本** |
| 延伸 | 被暗示**在前任 S.T.A.R.S. 队长威斯克的救助下复活**；1998 年 10 月上旬**欧洲有人目击艾达**，随后证人去向不明 |

**证据等级：【已核实】（百度百科、Resident Evil Wiki）。**

### 2.2 雪莉·柏金（Sherry Birkin）

| 项目 | 内容 |
|------|------|
| 身份 | **威廉·柏金的女儿** |
| 特征 | **项链上有一个圆形挂坠**（后成为 G 病毒样本的藏匿处） |
| 剧情 | 浣熊市陷落时接到母亲安妮特的电话，**逃到浣熊市警局**；后被 **G 威廉植入胚胎** |
| 获救 | 里昂与克莱尔**给她注射疫苗 DEVIL**，挽救其生命 |
| 结局 | 与里昂一同**被美国政府拘捕** |

**证据等级：【已核实】（百度百科）。**

### 2.3 安妮特·柏金（Annette Birkin）

| 项目 | 内容 |
|------|------|
| 身份 | **威廉·柏金之妻**；安布雷拉科学家 |
| 剧情 | 为救女儿雪莉而奔走；认出艾达佩戴女儿的吊坠，**推搡中被艾达推落重伤** |
| 临终 | 告知克莱尔如何制造疫苗 **DEVIL** 以阻止胚胎融合，随后**重伤不治** |
| 遗言 | 向雪莉**为做一个坏母亲道歉**，虚弱地请求原谅 |

**证据等级：【已核实】（百度百科、Resident Evil Wiki）。**

### 2.4 汉克（HUNK）

| 项目 | 内容 |
|------|------|
| 身份 | **安布雷拉 U.S.S.（安布雷拉特种勤务部队）阿尔法小队队长** |
| 战绩 | 在威廉袭击下**唯一幸存**的安布雷拉特工；**完成 G 病毒回收任务**返回安布雷拉 |
| 登场 | "**第四生存者**"模式主角 |
| 地位 | 系列高人气配角，后续多作登场 |

**证据等级：【已核实】（百度百科、Resident Evil Wiki）。**

## 三、反派与次要角色

### 3.1 威廉·柏金（William Birkin）

| 项目 | 内容 |
|------|------|
| 身份 | **安布雷拉科学家**；G 病毒研发者 |
| 剧情 | 因争夺 G 病毒被射杀，**临死前自行注射 G 病毒**，化身怪物"**G**" |
| 形态 | 共 **5 种形态**，最终为**庞然大物（第五形态）** |
| 结局 | 随**母巢爆炸**葬身火海 |

**证据等级：【已核实】（百度百科）。**

### 3.2 布莱恩·艾恩斯（Brian Irons）

| 项目 | 内容 |
|------|------|
| 身份 | **浣熊市警察局局长** |
| 真面目 | 表面关心浣熊市安危，**背地里为一己私欲不择手段**；与安布雷拉勾结 |
| 罪行 | 杀死市长之女**凯萨琳·沃伦**并**试图将其尸体制成标本**；囚禁记者**班·贝托鲁奇** |
| 结局 | 被 G 病毒怪物杀死（被 G **切成两半**或**被 G 寄生**，依剧本而异） |

**证据等级：【已核实】（百度百科、Wikiwand）。**

## 四、角色关系速览

```
威廉·柏金（G病毒研发者）
   ├─ 妻子：安妮特·柏金（为救女儿奔走，重伤不治）
   └─ 女儿：雪莉·柏金（被植入G胚胎 → 疫苗DEVIL获救 → 与里昂被政府拘捕）

里昂（新人警察）── 爱上 ── 艾达·王（实为间谍，"死后"生还并带走样本）
        │
        └─ 与克莱尔、雪莉一同逃出母巢 → 被美国政府拘捕

克莱尔（克里斯之妹）── 寻找哥哥 → 《代号维罗妮卡》

汉克（U.S.S.阿尔法队长）── 唯一完成G病毒回收的特工
```
