# 02 生化危机1 支线剧情

> 对应游戏：《生化危机》（Resident Evil, 1996 / 2002 重制版）
> 说明：本作是**线性单线**的生存恐怖，"支线"主要体现为**8 种多结局分支**、**双主角路线差异**、**隐藏要素**与**衍生外传**。本文件与 `01_生化危机1_主线剧情.md` 互补。

---

## 一、多结局分支（本作"支线"主体）

### 1.1 触发机制

- 结局由两个变量决定：
  1. **协助 NPC（吉尔线：巴瑞 / 克里斯线：瑞贝卡）是否存活**；
  2. **另一主角是否被救出独居牢房**。
- 救人的前置条件：收集 **MO 磁片** → 在解码装置输入密码 → 打开地下实验室牢房。

### 1.2 结局矩阵

| 伙伴 | 另一主角 | 结局 | 洋馆 | 暴君 |
|------|---------|------|------|------|
| 存活 | 救出 | **最佳结局**（三人逃生） | 被毁 | 被打倒 |
| 存活 | 未救 | 次佳结局（两人逃生） | 被毁 | 被打倒 |
| 未存活 | 救出 | 次差结局（吉尔+克里斯两人） | **未毁** | **逃入森林** |
| 未存活 | 未救 | **最差结局**（独自生还） | **未毁** | **逃入森林** |

- **正史口径**：取"最佳结局"——四人全数逃出、洋馆被毁、暴君被打倒（由《生化危机2》承接）。

**证据等级：【已核实】（维基百科、Capcom Wiki）。**

## 二、双主角路线差异（"另一条路线"）

- **吉尔线**：8 格道具栏、可开简单门锁、专属**开锁器**与**榴弹枪**、由**巴瑞**协助；
  - 揭示"**巴瑞的家人被威斯克绑架**"这一背景；
- **克里斯线**：6 格道具栏、体力更高、可找钥匙开锁、专属**打火机**、由**瑞贝卡**协助；
  - 揭示**瑞贝卡作为布拉沃小队幸存者**的经历。

> 两条路线在**可拾取物品、门锁解法、部分剧情演出**上均有差异，是早期"重复可玩性"设计的典范。【已核实】

## 三、隐藏要素与额外模式

| 要素 | 说明 |
|------|------|
| **隐藏服装** | 完成特定条件解锁（如克里斯的女装等系列传统） |
| **特殊武器** | 满足条件的无限弹药武器奖励 |
| **难度 / 时间限制** | 影响结局与解锁 |
| **《保护伞编年史》再现** | 本作洋馆事件在《保护伞编年史》（2007）中被设计为关卡，分 **Round 1 / Round 2 / Round 3 / 瑞贝卡篇 / 威斯克转生篇** 多篇章 |
| **丽莎·特雷弗（重制版）** | 2002 重制版新增的关键悲剧角色（详见下） |

**证据等级：【已核实】（百度百科《洋馆事件》、Capcom Wiki）。**

## 四、《保护伞编年史》中的洋馆事件（衍生再述）

| 篇章 | 内容要点 |
|------|---------|
| **Round 1** | 开篇丧尸、餐厅急救喷雾、大厅伞公司标志、狂暴丧尸、犬群、**蛇 Boss**战 |
| **Round 2** | 水池、**Hunter**、**植物 Boss** 战 |
| **Round 3** | **Chimera**、威斯克研究室、**暴君 Boss** 战 |
| **瑞贝卡篇** | 瑞贝卡视角 |
| **威斯克转生篇** | 威斯克视角 |

**Boss 战要点**：
- 蛇的弱点在**张嘴时的嘴内**；
- 植物 Boss 的弱点是**吐出的内核**；
- 暴君的弱点是**心脏**。

**证据等级：【已核实】（百度百科《洋馆事件》）。**

## 五、重制版新增内容（2002 年 GameCube《生化危机》重制版）

| 新增要素 | 说明 |
|---------|------|
| **绯红头颅（Crimson Head）** | T 病毒宿主进一步变异的原型 B.O.W.——肌肉与速度、敏捷大幅提升；因高攻击性导致**四名研究员死亡**；过于危险而被**冷冻并藏于斯宾塞宅邸后院墓地** |
| **年长绯红头颅（Elder Crimson Head）** | 更进一步的变异体 |
| **丽莎·特雷弗（Lisa Trevor）** | 重制版新增的关键角色（悲剧实验体） |
| **蝰蛇（Adder）** | 未被 T 病毒深度变异的小蛇；有毒牙、体型小难命中 |
| **黄蜂（Wasp）** | 变异黄蜂 |
| **场景与剧情扩写** | 洋馆布局、剧情演出大幅重制 |

**证据等级：【已核实】（Capcom Wiki）。**
