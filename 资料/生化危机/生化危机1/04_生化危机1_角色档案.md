# 04 生化危机1 角色档案

> 对应游戏：《生化危机》（Resident Evil, 1996 / 2002 重制版）
> 收录范围：**S.T.A.R.S. 成员** + **幕后人物**。
> 说明：本作角色是系列后续作品的核心班底，其背景多在其他作品中补完，本文件以本作登场信息为主，并标注延伸。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、可玩主角

### 1.1 克里斯·雷德菲尔德（Chris Redfield）

| 项目 | 内容 |
|------|------|
| 身份 | S.T.A.R.S. 阿尔法小队成员；**可玩主角之一** |
| 背景 | **原隶属空军**的热血男儿；因与上级冲突被除名，经**巴瑞引荐**加入 S.T.A.R.S. |
| 性格 | 精神坚韧；但开场因逃跑**丢失配枪**，只能以小刀开局，显粗心莽撞的一面 |
| 路线特性 | 6 格道具栏；**体力更高**、持枪动作更快；可找钥匙开上锁房间；专属**打火机** |
| 协助 NPC | **瑞贝卡·钱伯斯** |
| 后续 | 洋馆事件后**前往欧洲暗中调查安布雷拉**；成为系列贯穿主角 |

**证据等级：【已核实】（生化危机中文站、百度百科）。**

### 1.2 吉尔·瓦伦蒂安（Jill Valentine）

| 项目 | 内容 |
|------|------|
| 身份 | S.T.A.R.S. 阿尔法小队成员；**可玩主角之一** |
| 背景 | 在美国陆军特种部队**"三角洲部队"**完成训练；**爆炸物、化学知识专家**；擅长**开锁与处理陷阱** |
| 路线特性 | 8 格道具栏；可开简单门锁；专属**开锁器**与**榴弹枪** |
| 协助 NPC | **巴瑞·伯顿** |
| 后续 | 洋馆事件后**独自留在浣熊市继续调查安布雷拉**；这些经历令她执着于查清安布雷拉内幕 |

**证据等级：【已核实】（生化危机中文站、百度百科）。**

## 二、S.T.A.R.S. 阿尔法小队

### 2.1 巴瑞·伯顿（Barry Burton）

| 项目 | 内容 |
|------|------|
| 身份 | S.T.A.R.S. 阿尔法小队成员；**吉尔线伙伴** |
| 背景 | **前美国特种武器和战术部队（SWAT）成员**；**珍惜家人**，与克里斯很亲近 |
| 专长 | **精通枪械**，负责队内枪械维修与补充 |
| 本作剧情 | 吉尔线揭示其**家人被威斯克绑架**，为保护家人**被迫与威斯克合作**；最终**良心发现**，击昏威斯克 |
| 备注 | **克里斯线中不登场** |

**证据等级：【已核实】（生化危机中文站、Wikipedia）。**

### 2.2 阿尔伯特·威斯克（Albert Wesker）

| 项目 | 内容 |
|------|------|
| 身份 | S.T.A.R.S. 阿尔法小队**队长**；**本作主要反派** |
| 真身 | **安布雷拉安插进 S.T.A.R.S. 的间谍** |
| 阴谋 | 与研究员**威廉·柏金**合谋，**收集安布雷拉终极生物武器暴君的实战战斗数据** |
| 手段 | 以**巴瑞家人性命相要挟**逼其合作；释放暴君 T-002 抹杀主角 |
| 结局 | **惨死于暴君之手**（本作）；后续作品中**复活并成为系列核心反派** |
| 细节 | 释放暴君前**预先给自己注射了威廉·柏金提供的特殊病毒**，并**假装被暴君杀死** |

**证据等级：【已核实】（百度百科《洋馆事件》、Wikipedia）。**

### 2.3 布拉德·维克斯（Brad Vickers）

| 项目 | 内容 |
|------|------|
| 身份 | S.T.A.R.S. 阿尔法小队**直升机飞行员** |
| 性格 | 胆小——开场遭丧尸犬袭击时**弃机逃离**，抛下队友 |
| 结局贡献 | 结局时仍在空中搜寻幸存者；**投下火箭筒**助主角彻底摧毁暴君 |
| 后续 | 在《生化危机3》中**被追迹者杀害** |

**证据等级：【已核实】（Wikipedia、百度百科）。**

### 2.4 约瑟夫·弗罗斯特（Joseph Frost）

| 项目 | 内容 |
|------|------|
| 身份 | S.T.A.R.S. 阿尔法小队成员 |
| 结局 | 序章遭**地狱犬袭击遇害**（系列第一位死亡的 S.T.A.R.S. 成员） |

**证据等级：【已核实】（百度百科）。**

## 四、幕后人物（提及）

| 人物 | 说明 |
|------|------|
| **威廉·柏金（William Birkink）** | 安布雷拉研究员；与威斯克**合谋策划整个洋馆事件**；为威斯克提供特殊病毒 |
| **奥斯威尔·E·斯宾塞（Oswell E. Spencer）** | 安布雷拉创始人；**洋馆（Spencer Mansion）以其姓氏命名**，为其私产 |
| **安布雷拉公司（Umbrella Corporation）** | 明面为制药企业，暗地研发 T 病毒与 B.O.W. |

**证据等级：【已核实】（百度百科《洋馆事件》、Capcom Wiki）。**

## 五、角色关系速览

```
安布雷拉（斯宾塞 / 威廉·柏金）
        │  安插
        ▼
    威斯克（S.T.A.R.S.阿尔法队长，双面间谍）
        │  要挟（家人性命）
        ├──→ 巴瑞（被迫合作 → 最终良心发现）
        │
        └──→ 合谋对象：威廉·柏金（提供特殊病毒）

S.T.A.R.S.阿尔法小队：克里斯 / 吉尔 / 巴瑞 / 威斯克 / 布拉德 / 约瑟夫（阵亡）
S.T.A.R.S.布拉沃小队：恩里科（队长，被枪杀）/ 瑞贝卡 / 肯尼思 / 福雷斯特 / 爱德华 / 凯文

正史生还：克里斯、吉尔、巴瑞、瑞贝卡（四人）
```
