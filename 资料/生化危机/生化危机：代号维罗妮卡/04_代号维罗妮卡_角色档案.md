# 04 代号维罗妮卡 角色档案

> 对应游戏：《生化危机：代号维罗妮卡》（Resident Evil – Code: Veronica, 2000）
> 收录范围：**三名可操作角色** + **阿什福德家族** + **复活的反派**。
> 说明：本作角色是系列核心班底与最经典反派之一，其背景多在其他作品中补完。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、可操作角色

### 1.1 克莱尔·雷德菲尔德（Claire Redfield）

| 项目 | 内容 |
|------|------|
| 身份 | **浣熊市事件幸存者**；克里斯之妹 |
| 本作经历 | 为寻兄**潜入安布雷拉巴黎研究所**，**行踪暴露被擒**，被押至**洛克福特岛** |
| 剧情 | 病毒外泄后逃出监狱，与**史蒂夫**展开亡命之旅 |
| 结局 | 被克里斯救出；与克里斯一同乘战斗机逃离爆炸的南极基地 |
| 情感线 | 与史蒂夫在逃亡中**产生好感**；史蒂夫临终前**向她表白爱意** |

**证据等级：【已核实】（百度百科、Fandom）。**

### 1.2 史蒂夫·伯恩赛德（Steve Burnside）

| 项目 | 内容 |
|------|------|
| 身份 | **洛克福特岛的囚犯** |
| 背景 | 个性逞强；**因父亲泄漏安布雷拉机密而全家被捕入狱**；**母亲被杀死，父亲被抓去实验** |
| 性格 | 因此**对任何人产生不信任** |
| 剧情 | 与克莱尔逃亡中**产生好感**；在南极篇后半段**被阿莱克西亚注入圣女病毒（T-Veronica）变成怪物攻击克莱尔** |
| 结局 | **以自身意志力反抗阿莱克西亚并遭其杀害**；临终**向克莱尔表白爱意**；**遗体最后被威斯克带走** |

**证据等级：【已核实】（百度百科、Fandom、叶子猪）。**

### 1.3 克里斯·雷德菲尔德（Chris Redfield）

| 项目 | 内容 |
|------|------|
| 身份 | **S.T.A.R.S. 成员**；克莱尔之兄 |
| 本作经历 | 洋馆事件后发现安布雷拉阴谋而**前往欧洲调查找寻犯罪证据**；**从里昂处得知克蕾儿被囚**，独赴洛克福特岛救人 |
| 剧情 | 得知妹妹已被劫至南极；与**威斯克**再度相遇；最终**击败阿莱克西亚**、**重创威斯克** |
| 结局 | 启动基地自毁；在爆炸前与克莱尔一同乘飞机逃离 |
| 宿命 | "**两人的宿命一战，尚未结束**"——引出《生化危机5》 |

**证据等级：【已核实】（百度百科、Fandom）。**

## 二、反派

### 2.1 阿尔伯特·威斯克（Albert Wesker）

| 项目 | 内容 |
|------|------|
| 身份 | 前 S.T.A.R.S. 队长；实为安布雷拉研究员 |
| 复活 | **在洋馆地下研究所被暴君所杀后，因体内始祖病毒之力量而复活**，获得更可怕的能力 |
| 所属 | **一心一意只有要对克里斯复仇**；其后**加入某组织（HCF）**，被组织要求**找寻阿莱克西亚、取得圣女病毒** |
| 本作行动 | **释放 T 病毒造成岛上混乱**；**以克莱尔为诱饵吸引克里斯前来** |
| 结局 | 与阿莱克西亚交手后**感到无法控制她而逃走**；**救活史蒂夫**、在阿莱克西亚身上**提取 T-veronica 病毒**；与克里斯在冰原决战未分胜负，**受重创后离去** |

**证据等级：【已核实】（Fandom、叶子猪）。**

### 2.2 阿尔弗雷德·阿什福德（Alfred Ashford）

| 项目 | 内容 |
|------|------|
| 身份 | **洛克福特岛岛主**；**阿什福德家现任当主**；**爱德华·阿什福德之孙** |
| 性格 | **脾气古怪，似乎有多重人格**，**有时会打扮成自己的妹妹出现**——因精神分裂而诞生出以双胞胎妹妹阿莱克西亚为基础的人格 |
| 剧情 | 对克莱尔与史蒂夫**展开持续追杀**；逃出岛时**把搭乘的飞机改变航向飞往南极实验室**追杀他们；**被史蒂夫攻击而掉落冰谷受重伤** |
| 结局 | **临死前到南极大堂的实验室唤醒阿莱克西亚后断气**；**其后遗体被塞入培养槽冷冻** |

**证据等级：【已核实】（百度百科、Fandom）。**

### 2.3 阿莱克西亚·阿什福德（Alexia Ashford）

| 项目 | 内容 |
|------|------|
| 身份 | **阿尔弗雷德之妹**；**南极实验室高阶主管** |
| 履历 | **10 岁时以优异成绩从大学毕业**，被安布雷拉招募 |
| 研究 | 进行"**圣女计划（Veronica Project）**"——**将始祖病毒注入女王蚁的基因而成功创造出圣女病毒** |
| 实验 | **先注入其父亲体内失败**；**后注入自身并冷冻睡眠 15 年**后成功适应——**使自己的血液具有发火能力** |
| 苏醒 | 被兄长阿尔弗雷德**提前唤醒**（冷冻期不足，仍有缺陷） |
| 战斗 | T-Veronica 使其具备**飞翔能力**、**召唤昆虫**；**普通物理攻击无效** |
| 结局 | **被克里斯用线性激光炮干掉** |

**证据等级：【已核实】（Fandom、叶子猪）。**

### 2.4 亚历山大·阿什福德（Alexander Ashford）

| 项目 | 内容 |
|------|------|
| 身份 | **前任阿什福德家当主**；阿尔弗雷德与阿莱克西亚之父 |
| 行动 | **为了复兴家族，发起圣女计划** |
| 结局 | **计划中被女儿阿莱克西亚注入圣女病毒变异成怪物"诺斯拉图（Nosferatu）"**，被封印在南极实验室底下；**后脱逃并攻击克莱尔与史蒂夫**；被击败后**被阿莱克西亚带走，挂在吊环上冷冻死亡** |

**证据等级：【已核实】（百度百科、Fandom）。**

## 四、角色关系速览

```
阿什福德家族（安布雷拉创始三族之一）
   爱德华（创始人）→ 亚历山大（前任当主）
                      ├─ 阿尔弗雷德（现任当主，精神分裂）
                      └─ 阿莱克西亚（南极主管，T-Veronica适应者，最终首领）
                              │
                              └─ 圣女计划：始祖病毒+女王蚁基因 = T-Veronica
                                  父亲（亚历山大）实验失败 → 诺斯拉图

克莱尔（寻兄被捕）── 相爱 ── 史蒂夫（全家被害的囚犯）
        │                          │
        │                          └─ 被注入T-Veronica变异 → 恢复理智 → 被阿莱克西亚杀害
        │                              （遗体被威斯克带走）
        │
克里斯（救妹）── 宿敌 ── 威斯克（始祖病毒复活，为夺取T-Veronica而来）
        │
        └─ 击败阿莱克西亚（线性激光炮）→ 启动自毁 → 与克莱尔逃离
```
