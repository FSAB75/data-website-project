# 02 代号维罗妮卡 支线剧情

> 对应游戏：《生化危机：代号维罗妮卡》（Resident Evil – Code: Veronica, 2000）
> 说明：本作是**线性单线**的生存恐怖，"支线"主要体现为**三名可操作角色的切换视角**、**完全版新增内容**、**阿什福德家族暗线**与**后续衔接**。本文件与 `01_代号维罗妮卡_主线剧情.md` 互补。

---

## 一、三名可操作角色的切换视角

- **设计**：不同于以往的"双主角选择"，本作**随主线进展自动切换操控角色**：
  - **前中期：克莱尔**；
  - **克莱尔主线中：史蒂夫**切换为可操作；
  - **后半部分：克里斯**为主要操控（期间克莱尔亦会切换为可操作）。
- **叙事意义**：让"**妹妹寻兄 → 恋人（史蒂夫）线 → 兄长救妹**"三层视角自然衔接。

**证据等级：【已核实】（百度百科、Fandom）。**

## 四、阿什福德家族暗线（本作核心"支线"背景）

### 4.1 家族谱系

| 人物 | 身份 |
|------|------|
| **爱德华·阿什福德** | **安布雷拉创始人之一**；发现始祖病毒的三人之一 |
| **亚历山大·阿什福德** | 爱德华之子；**前任阿什福德家当主**；阿尔弗雷德与阿莱克西亚之父 |
| **阿尔弗雷德·阿什福德** | 亚历山大之子；**现任当主**；洛克福特岛岛主 |
| **阿莱克西亚·阿什福德** | 阿尔弗雷德之妹；南极实验室高阶主管 |

### 4.2 "圣女计划"（Veronica Project）

- **发起人**：**亚历山大**——为**复兴家族**而发起；
- **内容**：**将始祖病毒注入女王蚁的基因**，成功创造出**圣女病毒（T-Veronica）**；
- **人体实验**：
  - **先注入其父亲亚历山大体内 → 失败**（变异为怪物"**诺斯拉图 / Nosferatu**"，被封印在南极实验室底下）；
  - **再注入阿莱克西亚自身 → 成功**，并**冷冻睡眠 15 年**后**完美适应**——使自己的**血液具有发火能力**。

**证据等级：【已核实】（Fandom、百度百科）。**

### 4.3 诺斯拉图（Nosferatu）

- **真身**：**亚历山大·阿什福德**；
- 被封印于南极实验室底下；后**脱逃并出现在克莱尔与史蒂夫面前**攻击他们；
- 被击败后由**阿莱克西亚带走，挂在吊环上冷冻死亡**。

**证据等级：【已核实】（Fandom）。**

## 五、T-维罗妮卡病毒（T-Veronica）设定

| 项目 | 说明 |
|------|------|
| 起源 | 阿什福德家族研发——**始祖病毒 + 女王蚁基因** |
| 能力 | 使人具备**飞翔能力**、**召唤昆虫**；**普通物理攻击无效** |
| 缺陷 | 阿莱克西亚因**冷冻期不足、被阿尔弗雷德提前唤醒**，仍存**较大缺陷**——因此最终被克里斯以**线性激光炮**击败 |
| 史蒂夫案例 | 被注入后变异追杀克莱尔；**最后一刻恢复理智**、表达爱意后死亡 |

**证据等级：【已核实】（叶子猪、百度百科）。**

## 六、跨作品衔接（支线延伸）

| 事件 | 衔接 |

## 七、开发史的特殊性（"支线"外的关键背景）

- **世嘉开发、Capcom 授权**——为拉动 Dreamcast 销量而生；
- **起源**：源自一次**将《生化危机2》移植至世嘉土星（Saturn）的失败尝试**；三上真司团队认定无法在不严重牺牲品质的前提下完成移植，遂被要求"**为世嘉粉丝做点别的**"，转而开发原创作品；
- 开发中期，一款**以吉尔为主角的 PS 外传**（讲述《生化危机2》前的事件）正在开发；最终 PS 作品被改为**编号作《生化危机3》**，而 DC 作品命名为**《代号维罗妮卡》**；
- **评价**：发售获极高评价——"**一部最完美的《恶灵古堡》作品**"（有媒体给出最高评价）；
- **编号争议**：2020 年三上真司称本作"**比《生化危机3》更该有编号**"，未编号系"**Capcom 与主机制造商之间的政治原因**"。

**证据等级：【已核实】（Fandom、Reference.org）。**
