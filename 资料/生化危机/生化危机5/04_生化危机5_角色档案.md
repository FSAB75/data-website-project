# 04 生化危机5 角色档案

> 对应游戏：《生化危机5》（Resident Evil 5, 2009）
> 收录范围：**BSAA 双主角** + **反派威斯克与吉奥内** + **回归角色**。
> 说明：本作是"克里斯 vs 威斯克"宿命的终点，也是系列反派线的收束。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、BSAA 双主角

### 1.1 克里斯·雷德菲尔德（Chris Redfield）

| 项目 | 内容 |
|------|------|
| 身份 | **BSAA（生化恐怖主义安全评估联盟）特工**；系列老牌主角之一 |
| 履历 | S.T.A.R.S. 出身；洋馆事件、浣熊市事件、洛克福特岛事件的核心人物 |
| 本作 | 被派往西非基祖祖；与新搭档谢娃会合；**不向总部报告**以追寻吉尔下落 |
| 结局 | **救出吉尔、与谢娃离开非洲**——"**完成了他在十年前南极基地里的话**" |
| 战力特色 | 被戏称"**肌肉猛男**"——纯火力与体能型 |

**证据等级：【已核实】（剧情网、游民星空、巴哈姆特）。**

### 1.2 谢娃·阿洛玛（Sheva Alomar）

| 项目 | 内容 |
|------|------|
| 身份 | **BSAA 非洲分部特工**；克里斯新搭档 |
| 能力 | **擅长近战与支援**（与克里斯互补） |
| 关系 | 导师为**三角洲小队队长约书亚·斯通** |
| 关键行动 | **留下吉奥内掉落的血清注射器**——成为终局击败威斯克的关键 |
| 评价 | 系列首次双人合作的女主角，人气极高 |

**证据等级：【已核实】（Wikipedia、剧情网）。**

## 二、反派

### 2.1 阿尔伯特·威斯克（Albert Wesker）

| 项目 | 内容 |
|------|------|
| 身份 | **系列核心反派**；曾为安布雷拉高层 / S.T.A.R.S. 队长 |
| 力量来源 | 体内**始祖病毒**（复活来源）；另靠**定期注射血清**维持力量与速度——**剂量稍大或稍小都会中毒** |
| 所属 | **TRICELL**（与艾达一同效力的"第三组织"） |
| 计划 | **用 Uroboros 病毒感染全球**；"**人类每天都在自我毁灭，我这样做是在救赎这个世界**"；从混乱中挑选少数人统治，**创造"新人类"**——"**世界会因此得到救赎，而我会成为造物主**" |
| 背叛 | **背叛并感染了同谋吉奥内** |
| 结局 | 被注射过量血清导致**力量稳定性被破坏**；孤注一掷用 Uroboros **自我变异为触手怪物**（心脏外露）；**被重创后坠入岩浆**；虽从岩浆伸触手试图拉下直升机，**被 RPG 爆炸掀起的岩浆掩埋** |

**证据等级：【已核实】（Wikipedia、巴哈姆特、游民星空）。**

### 2.2 艾克塞拉·吉奥内（Excella Gionne）

| 项目 | 内容 |
|------|------|
| 身份 | **三联制药（Tricell）CEO** |
| 行动 | 与威斯克密谋，**用装载 Uroboros 的导弹袭击全球** |
| 结局 | **被威斯克背叛并用 Uroboros 感染**；**变异成巨大怪物**，被克里斯与谢娃击败 |

**证据等级：【已核实】（Wikipedia）。**

### 2.3 里卡多·欧文（Ricardo Irving）

| 项目 | 内容 |
|------|------|
| 身份 | **军火商** |
| 任务目标 | 在他将 B.O.W. 卖到黑市前将其逮捕 |
| 结局 | 在戴兜帽蒙面人帮助下逃走；后**给自己注射普拉卡变种，变异成巨大章鱼状怪物**；被击败后**临终遗言引向洞穴** |

**证据等级：【已核实】（Wikipedia）。**

## 三、回归角色

### 3.1 吉尔·瓦伦蒂安（Jill Valentine）

| 项目 | 内容 |
|------|------|
| 身份 | 克里斯昔日搭档；前 S.T.A.R.S.；BSAA 特工 |
| "死亡"真相 | 在之前的任务中，**为了让克里斯不被威斯克杀掉而同归于尽**——**与威斯克一同坠崖**（此剧情出自《**安布雷拉编年史**，**未移植到 PC**） |
| 被控制 | 重伤不治后，**威斯克救活并控制了吉尔的心智**（使用"宿主病毒"），使她成为帮凶；**胸前装有脑控装置** |
| 获救 | 克里斯与谢娃**将其制服并移除脑控装置**后恢复神智 |
| 关键贡献 | **通过无线电告知**：威斯克必须**精确、定期服用血清**维持力量，剂量偏差会中毒——这是击败他的关键情报 |
| 结局 | 与斯通一同搭直升机**及时救出克里斯与谢娃** |

**证据等级：【已核实】（Wikipedia、游民星空、巴哈姆特）。**

### 3.2 约书亚·斯通（Josh Stone）

| 项目 | 内容 |
|------|------|
| 身份 | **BSAA 三角洲小队队长**；谢娃的导师 |
| 经历 | 三角洲小队几近全灭（被巨魔状 B.O.W. 屠杀）；**斯通不在死者之中**；后在沼泽与克里斯谢娃重逢并协助追踪欧文 |
| 结局 | 与吉尔一同搭直升机救援主角二人 |

**证据等级：【已核实】（Wikipedia）。**

## 四、组织

| 组织 | 说明 |
|------|------|
| **BSAA（生化恐怖主义安全评估联盟）** | **2009 年成立**；宗旨为"**消除世界各地任何使用生化科技达成个人野心的计划**"；本作中**被 TRICELL 资助** |
| **三联制药（Tricell）** | **比安布雷拉更有历史、资格更老的国际型生化公司**；**T 病毒、G 病毒等生化武器的源头——始祖病毒就是他们发现的**；**威斯克与艾达效力的"第三组织"**；本作正式成为幕后黑手 |

**证据等级：【已核实】（巴哈姆特、Wikipedia）。**

## 五、角色关系速览

```
TRICELL（三联制药，始祖病毒发现者，资历老于安布雷拉）
   ├─ CEO：艾克塞拉·吉奥内 ── 密谋 ── 威斯克
   │       └─ 被威斯克背叛并用 Uroboros 感染 → 巨大怪物
   └─ 威斯克（系列核心反派）
          ├─ 控制：吉尔（坠崖被救后洗脑，胸前装置）
          ├─ 计划：Uroboros 全球感染 → 统治"新人类"
          └─ 结局：血清过量 → 触手怪物 → 坠入岩浆

BSAA（2009 成立，被 TRICELL 资助）
   ├─ 克里斯（肌肉猛男，火力型）
   ├─ 谢娃（近战与支援型；留下关键血清）
   └─ 斯通（三角洲队长；与吉尔一同救援）
```
