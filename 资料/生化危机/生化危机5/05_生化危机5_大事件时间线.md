# 05 生化危机5 大事件时间线

## 六、要点与易混提示

1. **两种病原体**：本作核心是 **Uroboros（衔尾蛇病毒）**；而**马吉尼**的感染源是**普拉卡变种**（承自《生化危机4》）。
2. **TRICELL 是"更老的恶"**：**比安布雷拉更有历史、资格更老**；**始祖病毒就是他们发现的**——这解释了整个系列的病毒源头。
3. **威斯克的力量是双刃剑**：靠**血清**维持，**剂量稍大或稍小都会中毒**——这正是他被击败的关键。
4. **吉尔的"死亡"是假象**：她与威斯克一同坠崖、被救活并洗脑——此剧情出自《安布雷拉编年史》（**未移植到 PC**），易被遗漏。
5. **年份有两说**：**Wikipedia 2009** / **游民星空 2008**——本文件并列标注，未强行统一。
