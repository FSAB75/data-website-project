# 03 生化危机5 游戏内全部档案

> 对应游戏：《生化危机5》（Resident Evil 5, 2009）
> 收集体系：本作的核心收集为**文件 / 情报**（叙事载体）、**宝物（可出售换钱）**、**钥匙与场景互动**、**武器与升级**、**佣兵模式**。
> 数据说明：整理自 Wikipedia、游民星空、巴哈姆特；**未逐字转录**游戏内文本。

---

## 一、档案（收集）体系说明

| 收集类型 | 说明 |
|---------|------|
| **文件 / 情报（Files）** | 村庄、油田、实验室、油轮内散落的文献——叙事载体 |
| **宝物（Treasures）** | 可出售换钱的收集品（系列传统） |
| **钥匙 / 场景互动** | 各区域推进（含大量 QTE 与协作机关） |
| **武器 / 弹药 / 补给** | 常规生存资源；**双人合作下的资源分配** |
| **佣兵模式** | 通关剧情后解锁的限时挑战 |

## 二、文件（Files）体系

- **形态**：民居、油田设施、地下实验室、油轮上的**报告、备忘录、研究记录**；
- **内容要点**：揭示**TRICELL 接管安布雷拉实验室**、**Uroboros 的研究**、**马吉尼的感染机制**、**威斯克与吉奥内的密谋**等；
- **地位**：理解本作阴谋全貌的主要途径。

## 四、剧情关键收集物

| 物品 | 说明 |

| **吉尔照片** | 斯通数据中的照片——**证明吉尔可能还活着**的关键线索 |

| **始祖花（Sunflower / Flower）** | **洞穴中那朵花**——曾被用于制造安布雷拉过去的病毒，以及新毒株 **Uroboros** |
| **实验胶囊** | 地下设施中**数千个装着人体实验对象的胶囊**；**吉尔的胶囊（空的）** |
| **吉尔的脑控装置** | **移除后吉尔恢复神智**；并指出威斯克靠血清维持力量 |
| **吉奥内的血清注射器** | 谢娃留下数支；**用于破坏威斯克的力量稳定性** |
| **Uroboros 导弹** | 装载于轰炸机上——威斯克全球感染计划的核心 |

## 七、玩法机制（收集的"环境"）

| 机制 | 说明 |
|------|------|
| **双人合作** | 系列首次；AI 或真人搭档 |
| **动作与掩体** | 保留系列恐怖氛围同时**增加更多动作元素**（近战攻击、掩体系统） |
| **武器与道具系统** | 可收集和升级武器；利用有限资源应对敌人 |
| **QTE / 协作机关** | 大量场景互动需双人配合 |
| **联机补丁** | 需**发售日补丁**才能访问线上多人模式 |
