# 03 启示录2 游戏内全部档案

> 对应游戏：《生化危机：启示录2》（Resident Evil: Revelations 2, 2015）
> 收集体系：本作的核心收集为**文件 / 日志**（叙事载体）、**钥匙与门禁**、**Uroboros 相关证物**、**武器与升级**、**突袭模式**。
> 数据说明：整理自 Steam、Fandom、Alchetron、Open WIKI；**未逐字转录**游戏内文本。

---

## 一、档案（收集）体系说明

| 收集类型 | 说明 |
|---------|------|
| **文件 / 日志（Files）** | 监狱、矿场、宅邸内散落的文献——叙事载体 |
| **Uroboros 相关证物** | **亚历克斯研究的关键**（剧情核心） |
| **钥匙 / 门禁** | 监狱、矿场、研究设施各区域 |

| **突袭模式（Raid Mode）** | 额外挑战 |

## 二、文件（Files）体系

- **形态**：囚室、矿场、宅邸房间中的**实验记录、日记、字条**；
- **内容要点**：揭示**亚历克斯·威斯克的研究**、**她"征服恐惧、逃脱死亡"的意图**、**娜塔莉亚的处境**、**尼尔的身份**等；
- **关键字条**：**尼尔留下的字条**（引导克莱尔与莫伊拉前往工厂）——剧情关键道具。

**证据等级：【已核实】（Fandom）。**

> 具体文件的**标题与逐条清单**公开来源未完整收录，本文件不臆造。【未明确】

## 三、剧情关键收集物

| 物品 | 说明 |
|------|------|
| **Uroboros（衔尾蛇病毒）样本** | 亚历克斯**给自己注射**后二度变异；研究设施的核心 |
| **亚历克斯的手环（Bracelet）** | 用于**向娜塔莉亚传话 / 嘲弄**她 |
| **尼尔留下的字条** | 引导克莱尔与莫伊拉前往工厂 |
| **叶夫根尼女儿的信** | 《斗争》章关键道具；导致叶夫根尼失去求生意志 |
| **洛蒂的明信片** | 《小姑娘》章关键收集物 |
| **《札宰阿箴言》（The Zürau Aphorisms）** | 尾声娜塔莉亚阅读的卡夫卡著作——**暗示亚历克斯人格潜伏** |

**证据等级：【已核实】（Fandom、Alchetron）。**
