# 04 启示录2 角色档案

> 对应游戏：《生化危机：启示录2》（Resident Evil: Revelations 2, 2015）
> 收录范围：**双主角组合（两代）** + **反派** + **关键配角**。
> 说明：本作是"伯顿家族"的情感主场，也是"威斯克之名"在系列的又一次延伸。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、克莱尔线（第 1–2 章主角）

### 1.1 克莱尔·雷德菲尔德（Claire Redfield）

| 项目 | 内容 |
|------|------|
| 身份 | **浣熊市事件幸存者**；克里斯之妹 |
| 本作 | 与**莫伊拉·伯顿**登上一座神秘岛屿后被困 |
| 能力 | 可使用**枪械**（火力担当） |
| 结局 | 好结局中**驾直升机赶到救援**三人；坏结局中独自逃生 |
| 后续 | 得知**哥哥克里斯在中国**，回应"告诉皮尔斯照顾好他"；**衔接《生化危机6》** |

**证据等级：【已核实】（Steam、Fandom）。**

### 1.2 莫伊拉·伯顿（Moira Burton）

| 项目 | 内容 |
|------|------|
| 身份 | **巴瑞·伯顿之女** |
| 创伤根源 | 年幼时与妹妹**波莉（Polly）**玩耍，**误用巴瑞的枪射伤波莉**；虽错在巴瑞（枪未妥善保管），但**巴瑞责怪了莫伊拉**，导致**父女关系严重破裂**；**波莉幸存，但莫伊拉从此恐惧枪械** |
| 能力 | **无法使用枪械**；但拥有**手电筒**（照亮黑暗、发现隐藏物） |
| 情感主线 | **克服枪械恐惧症**——全作的核心人物弧光 |
| 结局 | **好结局**：亲手击杀变异的尼尔 → 克服恐惧 → 高塔崩塌中幸存 → 救下娜塔莉亚，**与父女重逢并和解**；**坏结局**：未克服恐惧 → **被落石砸死** |

**证据等级：【已核实】（Fandom、Steam）。**

## 二、巴瑞线（第 3–4 章主角）

### 2.1 巴瑞·伯顿（Barry Burton）

| 项目 | 内容 |
|------|------|
| 身份 | **前 S.T.A.R.S. 成员**；莫伊拉之父 |
| 本作 | 收到**莫伊拉的求救信号**后**独自驾船登岛**寻女 |
| 经历 | 遇见小女孩**娜塔莉亚**并结伴；一边保护她、搜寻女儿下落，一边**揭开亚历克斯永生实验的真相** |
| 结局 | 好结局中**决定收养娜塔莉亚**、与莫伊拉和解；坏结局中**绝望站在原地** |
| 人物弧光 | 从"因愧疚而责怪女儿的父亲" → "接纳女儿与养女的父亲" |

**证据等级：【已核实】（Steam、Fandom）。**

### 2.2 娜塔莉亚·科尔达（Natalia Korda）

| 项目 | 内容 |
|------|------|
| 身份 | 巴瑞在岛上遇见的小女孩 |
| 能力 | **能感知墙壁后怪物的位置**；**无战斗力** |
| 真相 | 她是**亚历克斯"夺取躯体"的目标**——《小姑娘》章揭示这一切都是亚历克斯的计划 |
| 结局 | **好结局**：被莫伊拉救下，被巴瑞收养；**坏结局**：被亚历克斯掐死，**身体被亚历克斯的人格占据** |
| **尾声伏笔** | 数月后她在巴瑞家中阅读卡夫卡《札宰阿箴言》，**露出诡异微笑**——**亚历克斯的人格并未完全消失，依旧潜伏在她体内** |

**证据等级：【已核实】（Fandom、Alchetron）。**

## 三、反派

### 3.1 亚历克斯·威斯克（Alex Wesker）

| 项目 | 内容 |
|------|------|
| 身份 | 本作**主要反派**；"**威斯克**"之名的一员 |
| 意图 | **征服恐惧、逃脱死亡** |
| 手段 | 进行**永生实验**；研究设施**伪装成宅邸**；**给自己注射 Uroboros（衔尾蛇病毒）** |
| 关键行为 | 枪杀自己以触发高塔自毁；**在生命最后时刻感受到"恐惧"并开始变异**；通过**手环**向娜塔莉亚传话嘲弄 |
| 形态 | **二度变异**；假装死亡后突然发难 |
| 结局 | **好结局**：被克莱尔（直升机狙击）+ 莫伊拉 + 巴瑞联手以 **RPG 彻底摧毁变异肉身**；**坏结局**：掐死娜塔莉亚，**意识觉醒于娜塔莉亚体内**并摧毁自己残破肉身 |
| **遗留** | **其人格潜伏于娜塔莉亚体内**——系列最大悬念之一 |

**证据等级：【已核实】（Fandom、Alchetron、Steam）。**

### 3.2 尼尔·费舍尔（Neil Fisher）

| 项目 | 内容 |
|------|------|
| 身份 | 岛上人物 |
| 经历 | 留下字条引克莱尔与莫伊拉前往工厂；**被亚历克斯感染后变异** |
| 关键性 | **由谁击杀他直接决定结局分歧**——克莱尔击杀 → 坏结局；**莫伊拉击杀 → 好结局** |

**证据等级：【已核实】（Alchetron、Steam）。**

## 四、关键配角

| 角色 | 说明 |
|------|------|
| **叶夫根尼·雷比奇（Evgeny Rebic）** | 岛上独居的**俄国老人**；莫伊拉此前在地下污水控制室曾遇见他；高塔崩塌前**救下莫伊拉**；《斗争》章中与她共同求生；**得知女儿死讯后失去求生意志、锁门等死** |
| **波莉（Polly）** | 莫伊拉的妹妹；幼时被莫伊拉误射（巴瑞的枪）；**幸存**；是莫伊拉枪械恐惧症的根源 |
| **洛蒂（Lottie）** | 娜塔莉亚最爱的**泰迪熊**；《小姑娘》章中是亚历克斯引诱娜塔莉亚的**圈套道具** |

**证据等级：【已核实】（Fandom、Alchetron）。**

## 五、角色关系速览

```
巴瑞·伯顿（前S.T.A.R.S.）
   ├─ 女儿：莫伊拉（枪械恐惧症 → 好结局中克服）
   │        └─ 与克莱尔搭档（莫伊拉=手电筒/感知；克莱尔=火力）
   └─ （结局）收养：娜塔莉亚

亚历克斯·威斯克（反派）
   ├─ 目标：征服恐惧、逃脱死亡
   ├─ 感染：尼尔（变异；其击杀者决定结局）
   ├─ 手段：Uroboros 病毒、手环传话、伪装成宅邸的研究设施
   └─ 终极计划：夺取娜塔莉亚的身体（《小姑娘》章）
            └─ 坏结局成功 / 好结局失败但人格仍潜伏

叶夫根尼（俄国老人）→ 救莫伊拉 → 因女儿之死失去求生意志
```
