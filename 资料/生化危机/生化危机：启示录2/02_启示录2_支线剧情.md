# 02 启示录2 支线剧情

> 对应游戏：《生化危机：启示录2》（Resident Evil: Revelations 2, 2015）
> 说明：本作的"支线"主要体现为**两个奖励章节**、**双结局分歧机制**、**分章发售形式**与**突袭模式**。本文件与 `01_启示录2_主线剧情.md` 互补。

## 一、奖励章节（Bonus Episodes，2 个）

### 1.1 《小姑娘》（Little Miss）

- **时间点**：**就在娜塔莉亚遇见巴瑞之前**；
- **内容**：娜塔莉亚在**梦境般的状态**中醒来，被她最爱的泰迪熊**洛蒂（Lottie）**迎接；她出发寻找洛蒂；
- **同伴**：**"黑暗娜塔莉亚"（Dark Natalia）**——**亚历克斯心智的显化**，能**感知怪物存在**，让娜塔莉亚能在浓雾中潜行（**带有《寂静岭》式的氛围**）；
- **转折**：她们找到散落的**洛蒂寄来的明信片**，最终在海边找到"洛蒂"——**但这全是亚历克斯·威斯克为引诱娜塔莉亚而设的圈套**；另一个娜塔莉亚也随之消失；
- **真相**：黑暗娜塔莉亚告诉娜塔莉亚"**你终将被我取代**"；娜塔莉亚从清醒梦中惊醒，看到巴瑞的船正在接近；
- **本质**：**这一切都是亚历克斯夺取娜塔莉亚身体的计划**。

**证据等级：【已核实】（Alchetron、Open WIKI）。**

### 1.2 《斗争》（The Struggle）

- **时间点**：**克莱尔逃出与巴瑞登岛之间的六个月空档**；
- **内容**：**莫伊拉在荒岛上求生的半年**——在**俄国老人叶夫根尼·雷比奇**的帮助下挣扎求生；
- **关系**：叶夫根尼是莫伊拉此前在**岛上的地下污水控制室**曾遇见的人；他在高塔崩塌前救了她；
- **剧情**：两人关系紧张但**食物极其稀缺**，必须共同克服重重危险；
- **结局**：击败成群变异怪物后，他们找到**叶夫根尼女儿的信**；叶夫根尼得知女儿命运后**失去求生意志**，把自己锁在屋里等死，并劝莫伊拉独自逃走；
- **收束**：心碎的莫伊拉最终决定前行，**及时赶到救下父亲（巴瑞）与娜塔莉亚**。

**证据等级：【已核实】（Alchetron、Open WIKI、Steam）。**

## 二、双结局分歧机制

| 项目 | 说明 |
|------|------|
| **分歧点** | **第三章中由谁杀死变异的尼尔** |
| **条件 A（好结局）** | **莫伊拉**亲手击杀尼尔 → **克服枪械恐惧** → 高塔崩塌中幸存 → 救下娜塔莉亚 |
| **条件 B（坏结局）** | **克莱尔**开枪击杀尼尔 → 莫伊拉未克服恐惧 → 被落石砸死 → 娜塔莉亚被杀、亚历克斯夺舍 |

> 这是系列少见的"**角色内心成长直接决定生死**"的分支设计——**莫伊拉的枪械恐惧症**是全作的情感主线。

**证据等级：【已核实】（Steam、Fandom）。**

---

## 三、双主角能力不对称设计

| 角色 | 能力 |
|------|------|
| **克莱尔** | 可使用枪械；火力担当 |
| **莫伊拉** | **无法使用枪械**；但拥有**手电筒**（照亮黑暗、发现隐藏物） |
| **巴瑞** | 可使用枪械；战斗力强 |
| **娜塔莉亚** | **无战斗力**；但能**感知墙壁后怪物的位置**（关键生存能力） |

> 这种"**一人火力 + 一人感知 / 照明**"的不对称设计，是本作玩法核心。

**证据等级：【已核实】（Steam、Alchetron）。**
