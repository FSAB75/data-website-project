# 05 生化危机0 大事件时间线

> 对应游戏：《生化危机0》（Resident Evil 0, Capcom）
> 说明：本作是"**洋馆事件的前传**"——游戏内时间发生在《生化危机1》**之前数日**。本时间线分"**远古因**""**病毒起源**""**阿克雷事件前史**"与"**现实发布时间轴**"。
> 证据标注：【已核实】【推测】【未明确】。

## 一、本作在系列时间轴上的位置

```
远古 ─ 始祖病毒在西非迪拜亚部落的"太阳阶梯"花朵中被发现
        │
1960s–1980s ─ 斯宾塞、马库斯、爱德华·阿什福德共同研究始祖病毒 → 创立安布雷拉
        │
（本作前史）马库斯任干部养成所初代所长 → 死亡 → 经T病毒+水蛭女王复活
        │
1998年7月 ─ ★阿克雷列车与养成所事件（本作）
        ↓ 数日后
1998年7月23日 ─ 洋馆事件（《生化危机1》）
        ↓ 约两个月后
1998年9月 ─ 浣熊市事件（《生化危机2》《3》）
```

## 七、要点与易混提示

1. **本作是"前传"而非"外传"**：它补齐了**始祖病毒 → T 病毒**的研发前置剧情，并揭示威斯克与威廉的早年关系。
2. **双主角实时切换是系列首创**：瑞贝卡 + 比利的组合模式影响了后续《启示录》等作。
3. **水蛭女王 = 马库斯的"继承者"**：它并非普通怪物，而是**继承了马库斯记忆与意志**的存在。
4. **比利是开放式留白**：他隐姓埋名后再未登场，是系列著名的"未解悬念"。
5. **瑞贝卡是"承上启下"的枢纽**：她从养成所走向洋馆，把《生化危机0》与《生化危机1》无缝连接。
