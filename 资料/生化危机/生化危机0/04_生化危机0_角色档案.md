# 04 生化危机0 角色档案

> 对应游戏：《生化危机0》（Resident Evil 0, Capcom）
> 收录范围：**双主角** + **安布雷拉创始层** + **前作人物早期登场**。
> 说明：本作是系列"前史"，登场角色多在后续作品中发挥关键作用。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、双主角

### 1.1 瑞贝卡·钱伯斯（Rebecca Chambers）

| 项目 | 内容 |
|------|------|
| 身份 | **S.T.A.R.S. 布拉沃小队医疗兵**；小队**最年轻成员** |
| 年龄 / 履历 | **18 岁**即提前完成大学学业；因**药品方面丰富知识与过人技术**被 S.T.A.R.S. 招募 |
| 任务 | 本次针对杀人事件的调查是她的**首次任务** |
| 经历 | 降落时转为**逮捕杀人犯比利**；在黄道列车上搜寻队友时**逐渐发现事件背后的生化真相** |
| 结局 | 与比利逃出；**收下比利的军人身份确认牌替其伪造死讯**；独自前往斯宾塞洋馆 |
| 后续 | 《生化危机1》中协助克里斯逃出洋馆，为**布拉沃小队唯一生还者**；后在《血仇杀戮》等作中登场 |
| 轶事 | 原型传闻是日本偶像**滨崎步**，但**未获 Capcom 证实** |

**证据等级：【已核实】（百度百科、Resident Evil Wiki、Wikiwand）。**

### 1.2 比利·寇恩（Billy Coen）

| 项目 | 内容 |
|------|------|
| 身份 | **前海军陆战队少尉**；被判**死刑**的囚犯 |
| 罪名 | 因"**虐杀 23 人**"被判死刑 |
| 真相 | **实为代罪羔羊**（瑞贝卡后期了解） |
| 经历 | 被转送行刑途中因神秘袭击停留郊区，趁机逃走并在**黄道列车**遭遇瑞贝卡；为逃出生天而共同行动 |
| 结局 | **隐姓埋名、从此下落不明** |
| 声优 | 英语 James Kee；日语**小西克幸** |

**证据等级：【已核实】（百度百科、Resident Evil Wiki）。**

---

## 二、安布雷拉创始层与关键研究者

### 2.1 詹姆斯·马库斯（James Marcus）

| 项目 | 内容 |
|------|------|
| 身份 | **安布雷拉创始人之一**；**干部养成所（干部培训所）初代所长** |
| 人脉 | 与**奥斯威尔·爱德华·斯宾塞**、**爱德华·阿什福德**在大学时期结识，**共同发现始祖病毒**并以此为契机创立安布雷拉 |
| 死亡与复活 | 原本已死，却因 **T 病毒与水蛭女王**复活；濒死的他打翻培养皿，使**感染 T 病毒的水蛭女王进入其体内**；在病毒长年累月作用下，**水蛭女王继承其记忆与意志，以博士年轻时的模样重获新生** |
| 动机 | 向安布雷拉**复仇**——散布病毒，准备**让世界被地狱之火焚烧殆尽** |
| 结局 | 与瑞贝卡、比利交战后被击败，随养成所自爆消灭 |
| 声优 | 青年期**平川大辅**；老年期**糸博** |

**证据等级：【已核实】（百度百科、Wikiwand）。**

### 2.2 威廉·柏金（William Birkin）

| 项目 | 内容 |
|------|------|
| 身份 | **安布雷拉首屈一指的研究员**；**G 病毒研发者** |
| 履历 | 在 T 病毒项目发挥重要作用；与**威斯克相识多年** |
| 本作 | 作为**重启干部养成所项目的领导者之一**，发现神秘人利用水蛭对养成所发起袭击 |
| 声优 | 日语**关俊彦** |

**证据等级：【已核实】（百度百科）。**

### 2.3 阿尔伯特·威斯克（Albert Wesker）

| 项目 | 内容 |
|------|------|
| 身份 | **前安布雷拉研究员**；作为**间谍**担任 S.T.A.R.S. 总队长兼阿尔法小队队长 |
| 本作任务 | 在 **S.T.A.R.S. 抵达前处理阿克雷实验室的生化病毒泄漏并回收实验证据**；期间与威廉一起进行**干部养成所项目重启**以弥补损失 |
| 声优 | 日语**中田让治** |

**证据等级：【已核实】（百度百科）。**

### 2.4 水蛭女王（Queen Leech）

| 项目 | 内容 |
|------|------|
| 身份 | **感染 T 病毒的水蛭** |
| 关键设定 | **继承了马库斯的记忆与意志**；以博士年轻时的模样重获新生 |
| 弱点 | **惧怕阳光**——瑞贝卡与比利依此击败它 |

**证据等级：【已核实】（百度百科）。**

## 三、角色关系速览

```
安布雷拉创始三人组（大学时期结识 → 共同发现始祖病毒 → 创立安布雷拉）
   奥斯威尔·E·斯宾塞 ／ 爱德华·阿什福德 ／ 詹姆斯·马库斯
                                          │
                   马库斯任干部养成所初代所长（后死亡→经水蛭女王复活）
                                          │
   威廉·柏金（G病毒研发者）── 与 ── 威斯克（S.T.A.R.S.间谍，相识多年）
                                          │
                  ┌───────────────────────┘
                  ▼
        瑞贝卡（S.T.A.R.S.布拉沃医疗兵） + 比利（代罪羔羊死刑犯）
                  │
                  └─ 击败水蛭女王 → 逃出自爆 → 洋馆前道别
                     瑞贝卡 → 《生化危机1》（布拉沃唯一生还者）
                      比利   → 隐姓埋名
```
