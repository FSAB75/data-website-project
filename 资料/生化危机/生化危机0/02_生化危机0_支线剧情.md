# 02 生化危机0 支线剧情

> 对应游戏：《生化危机0》（Resident Evil 0, Capcom）
> 说明：本作是**线性单线**的生存恐怖，"支线"主要体现为**双主角实时切换系统**、**主角专属道具与能力差异**、**后续登场延伸**与**开发史定位**。本文件与 `01_生化危机0_主线剧情.md` 互补。

---

## 一、双主角实时切换系统（本作"支线"核心机制）

- **系列首创**：本作首次采用**双主角实时切换**——可在任意时刻在**瑞贝卡**与**比利**之间切换操控；
- **设计意义**：
  - 两人**初始位置不同**，需分别探索再汇合；
  - 部分谜题需**两人协作**（分别在不同位置操作）；
  - 为后续系列作品（如《生化危机：启示录》）的"同伴系统"奠定基础。

**证据等级：【已核实】（今日头条及系列通史）。**

## 四、开发史定位（"支线"外的关键背景）

- 本作**原计划在任天堂 64（N64）推出**，后转移至 GameCube；
- 它是**系列在 GameCube 独占三部曲**（重制版《生化危机》、《生化危机0》、《生化危机4》）的**第二部**；
- **承上启下的核心作用**：
  1. **溯源病毒起源**——完整解释始祖病毒、水蛭病毒的诞生，补齐 T 病毒研发的前置剧情；
  2. **补全人物伏笔**——揭露威斯克、威廉早年的关系，解释两人后续背叛安布雷拉的动机；
  3. **衔接 1 代主线**——瑞贝卡携带马库斯的研究资料进入洋馆，为 1 代埋下关键伏笔。

**证据等级：【已核实】（维基百科、今日头条）。**
