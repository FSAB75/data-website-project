> 对应游戏：《生化危机0》（Resident Evil 0, Capcom）

> 数据说明：整理自百度百科、Resident Evil Wiki、系列通史；**未逐字转录**游戏内文本。

## 二、文件（Files）体系

- **形态**：列车车厢、森林据点、干部养成所内的**研究记录、日志、备忘录**；
- **内容要点**：揭示**马库斯的水蛭病毒研究**、**安布雷拉干部养成所的内幕**、**始祖病毒与 T 病毒的关系**；
- **地位**：延续系列"环境叙事"传统，是理解"洋馆事件前史"的主要途径。

**证据等级：【已核实】。**

> 具体文件的**标题与逐条清单**公开来源未完整收录，本文件不臆造。【未明确】

## 四、敌人图鉴

| 敌人 | 说明 |
|------|------|
| **水蛭（Leeches）** | 感染 T 病毒的水蛭群；本作标志性敌人 |
| **丧尸（Zombies）** | 感染的研究人员 / 动物 |
| **变异猩猩 / 猿类** | 养成所实验生物 |
| **巨蝎 / 巨虫类** | 森林与养成所 |
| **马库斯（人形）** | 由水蛭重组人形的马库斯；**移动速度快、释放水蛭群侵蚀玩家**；保留部分人类意识 |
| **水蛭女王（Queen Leech）** | 完全体——巨型蠕动水蛭巨兽；**惧怕阳光**（致命弱点） |
| **暴君类早期实验体** | 养成所内的 B.O.W. |
