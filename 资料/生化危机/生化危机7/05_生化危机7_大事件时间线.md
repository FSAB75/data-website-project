## 一、本作在系列时间轴上的位置

```
远古 ─ 始祖病毒（西非“太阳阶梯”）
1960s–1980s ─ 斯宾塞、马库斯、爱德华·阿什福德研究始祖病毒 → 安布雷拉
1998 ─ 洋馆/浣熊市事件（T病毒）
2000s ─ G病毒 / Plagas / T-Veronica / T-Abyss / Uroboros / C病毒
        ↓
2014（约）── 伊森与米娅结婚
2014–2017 ─ ★三年前：伊芙琳转运失事；贝克农场被感染（本作前史）
2017 ─ ★贝克农场事件（本作本体）
        ↓
2021 ─ 东欧村庄事件；伊森之死（《生化危机8：村庄》）
```

## 七、要点与易混提示

1. **本作是"新三部曲"起点**：与"天神小学篇"（1–6 代）是**不同主角线**，但**与系列主线关联紧密**（斯宾塞日志、蓝色保护伞、霉菌源自始祖病毒）。
2. **"伊森一开始就死了"是全作最大伏笔**：他被杰克一刀砍死，**之后操控的伊森是被霉菌重构身体的感染者**——这直到《生化危机8》才正式揭晓。
3. **伊芙琳不是"怪物"，而是"想要家的孩子"**：整个本体剧情**都是她为得到新家庭而设计的**。
4. **卢卡斯是清醒的**：他**并非被伊芙琳控制**，而是**为联结组织收集数据**——贝克农场多年人口失踪的真相。
5. **两个结局的抉择极重**：**只有救米娅才衔接《生化危机8》**——首次通关建议选米娅。
6. **"4 种结局"说法不可信**：本作官方只有**两个结局**（另有 DLC 补完），网络流传的"4 结局 / 隐藏真结局"来源可靠性不足。
