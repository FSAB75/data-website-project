# 生化危机7（Resident Evil 7: Biohazard）主线剧情

- **作品名**：生化危机7（Resident Evil 7: Biohazard / バイオハザード7 レジデント イービル）
- **开发商**：Capcom（**RE 引擎**首作）
- **发售**：**2017 年 1 月 24 日**（日，PS4 / Xbox One / PC）；支持 **PSVR**；后续登陆 PS5 / Xbox Series / Switch（云版）
- **类型**：生存恐怖 / **第一人称视角回归**
- **主角**：**伊森·温特斯（Ethan Winters）**
- **舞台**：美国**路易斯安那州杜尔维（Dulvey）**的**贝克农场**——宅邸、沼泽、盐矿、地下实验室
- **游戏内时间**：**2017 年**（约）

---

## 一、作品地位：一次"壮士断腕"的回归

- 本作是"**开启生化危机新三部曲的开篇之作**"；
- 它把系列从"**过度动作化**"的方向**拉回了生存恐怖的本源**：
  - **第一人称视角**带来无与伦比的沉浸式恐怖；
  - **资源极其稀缺**——战斗往往没有收益，迫使玩家思考"生存"与"逃跑"；
  - 剥离宏大叙事与动作爽感，**回归密闭空间探索、资源管理、碎片化叙事**；
- 被视为"**第一人称生存恐怖游戏的第一梯队水平**"。

**证据等级：【已核实】（今日头条、顶点游戏）。**

---

## 二、故事背景

### 2.1 伊森的到来

- **伊森·温特斯**为寻找**失踪三年的妻子米娅**，来到路易斯安那州的**贝克农场**。

### 2.2 贝克一家

| 成员 | 身份 |
|------|------|
| **杰克·贝克（Jack Baker）** | 一家之主 |
| **玛格丽特·贝克（Marguerite Baker）** | 杰克之妻 |
| **卢卡斯·贝克（Lucas Baker）** | 小儿子 |
| **佐伊·贝克（Zoe Baker）** | **杰克之女**；**贝克家唯一清醒的成员**（伊森的盟友） |
| **贝克奶奶** | 轮椅上的老人——**实为伊芙琳的真身** |

- 贝克一家**折磨伊森并试图喂他吃人肉**；
- 一个电话分散了贝克一家的注意，伊森挣脱束缚，开始在宅邸中逃亡。

---

## 三、真相：一个想要"家庭"的生化武器

### 3.1 伊芙琳（Eveline）

| 项目 | 内容 |
|------|------|
| 代号 | **E-001** |
| 研发方 | 神秘组织"**联结组织（The Connections）**"——**E 系列霉菌实验体** |
| 研发目的 | 创造**可以控制感染者思想、渗透敌方的新一代生物武器** |
| 外形 | 被设计成 **10 岁小女孩**的模样以混入人群 |
| 能力 | **分泌特殊霉菌、感染并控制他人** |
| 缺陷 | 因实验缺陷，**身体会加速老化** |
| 渴望 | 从小被作为武器培养，**极度渴望拥有属于自己的"家庭"** |

### 3.2 三年前的事故

- **三年前**，负责监护伊芙琳的特工**米娅与艾伦**在转移她时发生意外，**轮船在贝克家附近的沼泽失事**；
- **好心的贝克夫妇救起了伊芙琳和米娅，却不知自己带回的是灾难**；
- 当晚，**伊芙琳便感染并控制了杰克和玛格丽特**，将他们变成自己扭曲的"**父母**"；
- 她**执着地将米娅视为"妈妈"**，但**米娅的抗拒让她不满**；
- 于是**伊芙琳控制米娅发出邮件，将毫不知情的伊森骗来**，试图让他成为"**爸爸**"，**拼凑一个完整的家庭**。

**证据等级：【已核实】（今日头条、顶点游戏）。**

---

## 四、章节式主线剧情

### 4.1 宅邸：逃亡与盟友

- 伊森在宅邸中被贝克一家追捕；**佐伊**揭示自己是**杰克的女儿、唯一清醒的成员**，成为伊森的盟友；
- 贝克一家展现**极快的再生能力**，并控制着名为"**菌兽（Molded）**"的霉菌人；
- 伊森**再次与杰克交手并将其杀死**（暂时）；
- **米娅被发现仍然活着**——在佐伊帮助下，伊森想救活并治愈她。

### 4.2 解药与杀戮

- 为寻找解药原料，伊森**击败并杀死玛格丽特**，**赶走疯狂的卢卡斯**；
- **变异后的杰克再度袭击**，伊森被迫**用掉仅两剂血清中的一剂**将其永久杀死；
- **只剩一剂血清**——伊森（与玩家）必须选择**救米娅**还是**救佐伊**。

### 4.3 沼泽：真相

- **（正史线：选择米娅）** 伊森与米娅前往沼泽；
- 伊森得到**关于伊芙琳的幻视**（来自杰克），以及**三年前那艘油轮的残骸**（与米娅的到来时间吻合）；
- 伊森**被伊芙琳袭击并俘获**；
- **失忆的米娅恢复了原初记忆**——她其实在为某家企业工作，参与研发**基于霉菌的生化武器**；而**伊芙琳正是 E-001**；
- 三年前伊芙琳逃脱、弄翻船只、感染米娅并**迫使她相信自己是伊芙琳的母亲**，随后**接管贝克一家以组建自己的家庭**；
- **米娅抵抗到足以帮助伊森逃脱**，并给了他**伊芙琳的 DNA 样本**。

### 4.4 终章：击杀伊芙琳

- 伊森逃出后抵达附近一处**隐蔽实验室**，**制造出针对伊芙琳的毒素**，前往农舍；
- 尽管伊芙琳以菌兽与幻觉阻挠，伊森仍**给她注射了毒素**；
- 却发现**伊芙琳的真身就是此前的"贝克奶奶"**；
- **伊芙琳变异成巨大怪物**攻击伊森，但被伊森摧毁——**得益于"蓝色保护伞（Blue Umbrella）"部队的及时赶到，其领队正是克里斯·雷德菲尔德**（他也救走了米娅，若她存活）。

**证据等级：【已核实】（blackjackrants、今日头条、顶点游戏）。**

## 五、双结局

| 结局 | 条件 | 内容 | 性质 |
|------|------|------|------|
| **正史・好结局** | 把**最后一剂血清给米娅** | 伊森与米娅**被蓝色保护伞的克里斯救出**；**直接衔接《生化危机8：村庄》**——伊森和米娅逃出去后隐居，生下女儿罗斯 | **官方正史** |
| **非正史・坏结局** | 把**最后一剂血清给佐伊** | 米娅**被伊芙琳杀死**；**只有伊森一人被救走**；**不纳入官方正史**，**与《生化危机8》完全不衔接** | 非正史 |

> **建议**：想要完整体验伊森线的玩家，**第一次玩优先选择救米娅**；二刷再尝试救佐伊的结局。

**证据等级：【已核实】（顶点游戏、guhive）。**

## 六、DLC 补完

| DLC | 内容 |
|------|------|
| **《并非英雄》（Not A Hero）** | **补全克里斯带领蓝色保护伞清剿联结组织残党的行动**——解释主线中克里斯突然出现的背景；也交代了**蓝色保护伞从安布雷拉分裂之后的立场**；玩家操控克里斯**深入沼泽下的实验室追捕卢卡斯并将其击杀** |

## 七、核心暗线（伏笔）

| 伏笔 | 说明 |
|------|------|
| **"伊森一开始就死了"** | **本作埋得最深的伏笔**——伊森刚踏进贝克家的客厅，**就被杰克贝克一刀砍死了**；之后玩家操控的伊森，**其实是被霉菌用菌丝重构身体的感染者**；这也是他**断手断脚都能接回去**的原因 |
| **佐证** | 伊芙琳在最终战快结束时对伊森说"**你也和我一样啊**"——点破伊森已是霉菌构成的躯体；游戏文档也提到"**霉菌感染深度越高的人，越能保持自我意识，还能获得极强的再生能力**" |
| **揭晓时机** | 该真相在《生化危机7》结尾**未挑明**，直到**《生化危机8》才正式揭晓** |
| **与系列的连接** | 实验室能找到**始祖病毒研究者斯宾塞的日志**——明确提到 **E 型霉菌是保护伞公司早期始祖病毒研究的分支项目**；结尾的**蓝色保护伞**是初代反派保护伞倒闭后**重组的新组织** |

**证据等级：【已核实】（顶点游戏、guhive）。**

## 八、主要角色一览

| 角色 | 身份 | 关键作用/结局 |
|------|------|--------------|
| **伊森·温特斯（Ethan Winters）** | 本作主角 | 为寻妻来到贝克农场；**实为被霉菌复活的感染者**；击杀伊芙琳；正史中被救出 |
| **米娅·温特斯（Mia Winters）** | 伊森之妻；**联结组织特工** | 三年前负责监护伊芙琳；被感染并误认自己是伊芙琳之母；恢复记忆后助伊森；正史中被救出 |
| **杰克·贝克（Jack Baker）** | 贝克一家之主 | 被伊芙琳感染控制；多次再生；最终被血清永久杀死；后化为"**沼泽人**"被乔·贝克终结 |
| **玛格丽特·贝克（Marguerite Baker）** | 杰克之妻 | 被感染控制；被伊森杀死 |
| **卢卡斯·贝克（Lucas Baker）** | 贝克家小儿子 | **反社会人格**；**其实一直神智清醒且对伊芙琳免疫**，**为联结组织暗中收集感染数据**、**把闯入农场的游客抓来做实验**（贝克农场多年人口失踪的真相）；最终被克里斯击杀 |

| **克里斯·雷德菲尔德（Chris Redfield）** | 系列经典角色 | 以**蓝色保护伞**领队身份登场；救出伊森与米娅；DLC 中追捕卢卡斯 |
| **乔·贝克（Joe Baker）** | 佐伊的叔叔 | 《佐伊的结局》登场；凭双拳横扫菌兽 |
