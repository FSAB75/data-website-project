# 02 生化危机7 支线剧情

> 对应游戏：《生化危机7》（Resident Evil 7: Biohazard, 2017）
> 说明：本作的"支线"主要体现为**两个 DLC**、**双结局分歧**、**录像带叙事系统**与**难度解锁内容**。本文件与 `01_生化危机7_主线剧情.md` 互补。

## 一、DLC 一：《并非英雄》（Not A Hero）

| 项目 | 内容 |
|------|------|
| **可操作角色** | **克里斯·雷德菲尔德** |
| **剧情** | **补全克里斯带领蓝色保护伞清剿联结组织残党的行动**——**解释了主线中克里斯突然出现的背景**；也交代了**蓝色保护伞从安布雷拉分裂之后的立场** |
| **流程** | 深入**沼泽下的实验室**，追捕**逃脱的卢卡斯**，历经其布下的怪物与陷阱迷宫 |
| **结局** | **击杀卢卡斯** |

**证据等级：【已核实】（顶点游戏、blackjackrants、今日头条）。**

## 二、DLC 二：《佐伊的结局》（End of Zoe）

| 项目 | 内容 |
|------|------|
| **主角** | **佐伊·贝克**（与**叔叔乔·贝克**） |
| **剧情** | 补全**正史线中被留下的佐伊的后续**——她在沼泽中受伤，被**蓝色保护伞**和**乔·贝克**救下 |
| **敌人** | **"沼泽人"（Swamp Man）**——一个**不可战胜的强大菌兽**，**实为杰克的变异尸体** |
| **流程** | 乔须**取得血清**并**救出被绑架的佐伊** |
| **结局** | **永久杀死沼泽人**；在蓝色保护伞帮助下**治愈佐伊**；"**为贝克家族的故事画上充满力量感的句号**" |
| **基调** | 有说法认为该结局"**给整个故事添了更浓的悲剧色彩**"；亦有评价为"**还算圆满的结局**"——两说并存 |

**证据等级：【已核实】（顶点游戏、blackjackrants、今日头条）。**

## 三、双结局分歧机制

| 项目 | 说明 |
|------|------|
| **分歧点** | 取得**两剂解毒剂**后，**用其中一剂永久杀死杰克**；**只剩一剂**时选择救**米娅**或**佐伊** |
| **正史（好结局）** | 救**米娅** → 二人被蓝色保护伞的克里斯救出 → **衔接《生化危机8：村庄》** |
| **非正史（坏结局）** | 救**佐伊** → 伊芙琳杀死米娅 → **只有伊森一人被救走**；**与《生化危机8》完全不衔接** |
| **建议** | **首次通关优先救米娅**（完整体验伊森线）；**二刷再试救佐伊** |

## 四、录像带叙事系统（VHS Tapes）——本作"支线"核心

| 录像带 | 作用 |
|--------|------|
| **"米娅的失事录像带"** | 揭示**三年前轮船失事**的经过 |
| **"废弃房子的拍摄录像带"** | 揭示**贝克农场此前的访客遭遇**（人口失踪真相之一） |
| **"佐伊的私录像带"** | 补完**贝克一家被感染的全过程** |

- **地位**：**录像带是 7 代剧情补充的核心载体**——三个录像带看完，才能完全搞懂**伊芙琳的来历、贝克一家被感染的全过程**；
- **机制**：播放录像带时**可操作其中角色**（如"调查员"视角），是碎片化叙事的重要组成。

**证据等级：【已核实】（guhive）。**

## 五、难度与隐藏内容

| 难度 / 内容 | 说明 |
|------------|------|
| **疯人院难度（Madhouse）** | 需**先通普通难度解锁**；不仅敌人伤害与刷新点变化，还会**解锁普通难度没有的隐藏剧情文件**——如**伊森失踪前给米娅发的所有邮件**、**伊芙琳在实验基地的童年记录** |
| **新手建议** | **第一次玩建议选普通难度**，省着弹药用；**不要开无敌修改器**（会严重削弱"资源匮乏 + 被贝克一家围追堵截"的压迫感与代入感） |

**证据等级：【已核实】（guhive）。**

## 六、独立性与衔接（新玩家的定位）

| 问题 | 答案 |
|------|------|
| **需要先补 1–6 代吗？** | **完全不需要**——伊森线是**独立的新剧情线**，未接触过系列的玩家也能看懂全部剧情 |
| **与系列主线有关联吗？** | **关联非常紧密**——实验室能找到**斯宾塞的日志**（E 型霉菌是始祖病毒研究的分支）；结尾的**蓝色保护伞**是原安布雷拉重组的新组织；**伊森手上的霉菌白斑**暗示他已被感染（**呼应 8 代的"不死"能力来源**） |
| **游玩顺序建议** | 从《生化危机7》开始体验**新主线**非常合适；**玩完 7 代再去玩 8 代体验感更好** |

**证据等级：【已核实】（guhive、顶点游戏）。**

## 七、敌人谱系（战斗叙事的"支线"内容）

| 敌人 | 说明 |
|------|------|
| **菌兽（Molded）** | 霉菌人——本作**几乎全部的杂兵**都是菌兽，且**变体不多**；直到游戏**过半**才作为常规敌人登场 |
| **贝克一家（感染态）** | 具**极快再生能力**的追踪型敌人 |
| **"沼泽人"（Swamp Man）** | **不可战胜**的强大菌兽；实为**杰克的变异尸体** |
| **伊芙琳（巨大变异体）** | 最终首领 |
