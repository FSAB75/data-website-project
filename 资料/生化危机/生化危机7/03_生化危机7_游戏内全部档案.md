# 03 生化危机7 游戏内全部档案

> 对应游戏：《生化危机7》（Resident危机 7: Biohazard, 2017）
> 收集体系：本作的核心收集为**录像带（VHS Tapes）**、**文件**、**古董硬币（Antique Coins）**、**"无处不在先生"雕像（Mr. Everywhere）**、**解谜道具与血清**。
> 数据说明：整理自 blackjackrants、顶点游戏、guhive 等；**未逐字转录**游戏内文本。

## 一、档案（收集）体系说明

|---------|------|

| 录像带 | 作用 | 证据 |

## 四、解谜与场景收集

| 项目 | 说明 |
|------|------|
| **投影斧头 / 宝箱** | 拖车草丛的宝箱（用投影斧头开）——**稳定剂**（提升生命值上限） |
| **糖厂的"黄色钥匙卡"** | **第一次进必须拿**，否则后续结构坍塌后**不可逆遗漏** |
| **贝克家阁楼的"录音带 07"** | **没有它解不开地下室保险柜密码（1123）**，会丢**火焰喷射器燃料** |
| **地下室保险柜** | 密码 **1123**；内有火焰喷射器燃料 |
| **场景** | 宅邸（主厅、安全屋）、沼泽、**盐矿**、油轮残骸、隐蔽实验室 |

**证据等级：【已核实】（开方游戏）。**

## 七、玩法机制（第一人称生存恐怖的回归）

| 机制 | 说明 |
|------|------|
| **第一人称视角** | 带来沉浸式恐怖；支持 **PSVR** |
| **资源稀缺** | 弹药与补给极其有限；**战斗往往没有收益**，需思考"生存"与"逃跑" |
| **录像带可操作** | 播放录像带时**可操作其中角色**——碎片化叙事的重要组成 |
| **安全屋** | 存档点（系列传统的"安全屋"设计） |

**证据等级：【已核实】（今日头条、blackjackrants）。**
