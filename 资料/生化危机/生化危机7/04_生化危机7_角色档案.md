# 04 生化危机7 角色档案

> 对应游戏：《生化危机7》（Resident Evil 7: Biohazard, 2017）
> 收录范围：**伊森与米娅** + **贝克一家** + **伊芙琳** + **蓝色保护伞**。
> 说明：本作开启"**新三部曲**"，角色阵容全新，但与系列主线关联紧密。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、主角夫妇

### 1.1 伊森·温特斯（Ethan Winters）

| 项目 | 内容 |
|------|------|
| 身份 | **本作主角**；为**寻找失踪三年的妻子米娅**来到贝克农场 |
| **核心真相** | **伊森刚踏进贝克家的客厅，就被杰克贝克一刀砍死了**；之后玩家操控的伊森，**其实是被霉菌用菌丝重构身体的感染者** |
| 能力表现 | **断手断脚都能接回去**；只要核心意识不被破坏就能存活；**极强的再生能力** |
| 剧情 | 被贝克一家折磨后逃脱；在佐伊协助下救米娅；杀玛格丽特；用血清永久杀死杰克；制造毒素**击杀伊芙琳** |
| 结局 | **正史中与米娅一同被蓝色保护伞的克里斯救出**；后与米娅隐居、生下女儿罗斯（接《生化危机8》） |
| 伏笔佐证 | 伊芙琳在最终战快结束时对伊森说"**你也和我一样啊**"——点破他已是霉菌构成的躯体；游戏文档提到"**霉菌感染深度越高的人，越能保持自我意识，还能获得极强的再生能力**" |

**证据等级：【已核实】（顶点游戏、guhive、blackjackrants）。**

### 1.2 米娅·温特斯（Mia Winters）

| 项目 | 内容 |
|------|------|
| 身份 | **伊森之妻**；**联结组织（The Connections）特工** |
| 过往 | **三年前**负责监护 **E-001 伊芙琳**；与**艾伦**在转移她时**轮船在贝克家附近沼泽失事** |
| 被感染 | 被伊芙琳感染，并被**迫使她相信自己是伊芙琳的"母亲"**；**抗拒伊芙琳** |
| 主线中的角色 | **最初看似失踪**，实为被控制；向伊森发出邮件（受控） |
| 恢复 | 在沼泽被俘期间**恢复原初记忆**——她其实在为某家企业工作，参与研发**基于霉菌的生化武器**；**抵抗到足以帮助伊森逃脱**，并给了他**伊芙琳的 DNA 样本** |
| 结局 | **正史中被克里斯救走**；后与伊森隐居生子 |

**证据等级：【已核实】（blackjackrants、今日头条）。**

## 二、贝克一家

| 成员 | 身份 | 详情 |
|------|------|------|
| **杰克·贝克（Jack Baker）** | 一家之主 | 被伊芙琳感染控制；**具极快再生能力**；多次袭击伊森；最终被**血清永久杀死**；后化为"**沼泽人**"（DLC）被乔·贝克终结 |
| **玛格丽特·贝克（Marguerite Baker）** | 杰克之妻 | 被感染控制；**被伊森击败并杀死** |
| **卢卡斯·贝克（Lucas Baker）** | 小儿子 | **反社会人格**；**其实一直神智清醒且对伊芙琳免疫**；**为联结组织暗中收集伊芙琳的感染数据**，**把闯入农场的游客抓来做实验**——**贝克农场多年人口失踪的真相**；最终在 DLC《并非英雄》中被**克里斯击杀** |
| **佐伊·贝克（Zoe Baker）** | **杰克之女** | **贝克家唯一清醒的成员**；**伊森的盟友**；正史中被留在庄园；DLC《佐伊的结局》中被**叔叔乔·贝克与蓝色保护伞治愈** |
| **"贝克奶奶"** | 轮椅上的老人 | **实为伊芙琳的真身** |

**证据等级：【已核实】（blackjackrants、顶点游戏、今日头条）。**

## 三、核心反派：伊芙琳（Eveline）

| 项目 | 内容 |
|------|------|
| 代号 | **E-001** |
| 身份 | **联结组织开发的 E 系列霉菌实验体**；本作核心反派 |
| 研发目的 | 创造**可控制感染者思想、渗透敌方的新一代生物武器** |
| 外形 | 被设计成 **10 岁小女孩**的模样以**混入人群** |
| 能力 | **分泌特殊霉菌、感染并控制他人** |
| 缺陷 | 因实验缺陷，**身体会加速老化** |
| 渴望 | 从小被作为武器培养，**极度渴望拥有属于自己的"家庭"** |
| 行为逻辑 | 在转运途中**主动失控**，感染整个贝克家，把他们变成自己扭曲的"父母"；**把米娅视为"妈妈"**；**控制米娅发邮件把伊森骗来当"爸爸"**——**本体剧情其实都是伊芙琳为了得到新家庭设计的结果** |
| 真身 | **"贝克奶奶"**（轮椅上的老人） |
| 结局 | 被注射毒素后**变异成巨大怪物**；被伊森摧毁 |

**证据等级：【已核实】（顶点游戏、今日头条、blackjackrants）。**

## 四、蓝色保护伞（Blue Umbrella）

| 项目 | 内容 |
|------|------|
| 性质 | **原安布雷拉破产后，部分原成员重组的新组织**；以**清理全球生化恐怖活动**为目标 |
| 与初代安布雷拉的区别 | "**早已不是初代那个开发生化武器的邪恶组织**" |
| 登场 | 主线终局**领队正是克里斯·雷德菲尔德**；**救出伊森与米娅** |
| 后续 | 在《生化危机8》《生化危机9》中都会登场 |

**证据等级：【已核实】（顶点游戏、guhive）。**

## 六、角色关系速览

```
联结组织（The Connections）
   └─ 研发：E-001 伊芙琳（10岁女孩外形、霉菌控制、渴望家庭）
          │  三年前转运失事
          ▼
      贝克农场（好心的贝克夫妇救起伊芙琳与米娅）
          ├─ 杰克 + 玛格丽特 → 被感染成“父母”
          ├─ 佐伊（唯一清醒者 → 伊森盟友）
          └─ 卢卡斯（清醒且免疫 → 实为联结组织暗线）
          │
          └─ 米娅被感染成“妈妈”；受控发邮件骗来伊森当“爸爸”
                    │
                    ▼
              伊森（实为霉菌复活的感染者）
                    ├─ 杀玛格丽特、血清永久杀杰克
                    ├─ 沼泽获真相、取得伊芙琳DNA
                    └─ 制造毒素 → 击杀巨大变异的伊芙琳

蓝色保护伞（原安布雷拉重组）── 克里斯领队 ── 救出伊森与米娅
```
