# 02 生化危机9 支线剧情

> 对应游戏：《生化危机9：安魂曲》（Resident Evil Requiem, 2026）
> 说明：本作是 2026 年 2 月新作，"支线"主要体现为**双主角章节切换**、**与《生化危机：爆发》的串联**、**浣熊市回归线**与**系列 30 年 callback**。本文件与 `01_生化危机9_主线剧情.md` 互补。

---

## 一、双主角章节切换（结构核心）

| 项目 | 内容 |
|------|------|
| **叙事结构** | **一条完整统一的叙事主线**；玩家可在**里昂与格蕾丝**两位角色的剧情章节间**自由切换** |
| **占比** | **两人的可操作内容占比完全均等**（相当） |
| **结构参考** | **《生化危机：启示录》**的双线并行模式——"在节奏与氛围上实现双线并行的体验" |
| **风格对比** | **格蕾丝部分侧重传统恐怖氛围营造**；**里昂章节更偏向动作导向**——"两者相互补充，构成整体节奏的平衡" |
| **设计意图** | 让玩家在**格蕾丝章节的压抑感后**，能在**里昂的剧情中获得强烈的释放感**，形成独特的"**游戏韵律**" |

**证据等级：【已核实】（九游、御三家）。**

---

## 二、与《生化危机：爆发》的串联（系列暗线）

- 本作剧情**将串联《生化危机：爆发》（Outbreak）的旧有故事线**；
- **格蕾丝之母艾丽莎·阿什克罗夫特正是《生化危机：爆发》的角色**——她是**浣熊市事件幸存者**、**新闻记者**；
- 这意味着**《爆发》系列（长期以来被视为支线 / 外传）的人物与线索，在本作被纳入正史主线**；
- 本作将"**揭开浣熊市事件未曝光的深层秘密**，让新老玩家都能找到共鸣"。

**证据等级：【已核实】（御三家、ZURCS）。**

---

## 三、浣熊市回归线（系列 30 年情怀）

| 项目 | 内容 |
|------|------|
| **回归意义** | **自《生化危机2》之后，主线剧情首次回归浣熊市**——"一切故事开始的地方" |
| **里昂的反应** | "**成年后的心态变化与对旧地的反应成为剧情一大看点**" |
| **舞台形态** | **灭菌作战后化为废墟的浣熊市**——"雨水滑腻的街道、血染的医院、闪烁的灯光，让每一道阴影都可疑" |
| **叙事主题** | "**予生者恐惧。给尸者安魂。**"——为浣熊市的亡魂奏响安魂曲 |

**证据等级：【已核实】（Capcom 官网、九游、ZURCS）。**

## 四、玩法系统（双主角差异化）

### 4.1 格蕾丝（生存恐怖 ·《生化危机2》蓝本）

| 系统 | 说明 |
|------|------|
| **资源限制** | 物资与可携带数量**十分有限**；"该击倒哪些敌人，又该避开哪些敌人？抉择也将决定生死" |
| **物品合成** | 可**利用感染者的血液合成治疗物品与弹药**，甚至制作**一击必杀的特殊注射器** |
| **动作** | **移动缓慢**、有踉跄动画——"让你感到脆弱" |
| **视角** | 默认**第一人称**（幽闭恐惧式紧张感） |
| **解谜** | 保险箱密码、**石英块（quartz blocks）**等 |

### 4.2 里昂（动作 ·《生化危机4》蓝本）

| 系统 | 说明 |
|------|------|
| **战斗** | 枪械 + **斧头**；**体术、招架**；甚至**利用敌人的武器攻击** |
| **武器强化** | 可用**特制零件改造并强化武器** |
| **手提箱** | 整理治疗物品与弹药 |
| **视角** | 第三人称 glory；战斗环节可切**第一人称**精准操作 |
| **名场面** | **机车穿越丧尸群**、**电锯对决** |

**证据等级：【已核实】（Capcom 官网、ZURCS）。**

## 五、视角自由切换

- **格蕾丝和里昂均可自由切换第一视角与第三视角**；
- "**根据自己的游玩风格选择，直面恐惧**"；
- 里昂的战斗环节**允许第一人称精准操作**，提升沉浸感与战术灵活性。

**证据等级：【已核实】（Capcom 官网、九游）。**
