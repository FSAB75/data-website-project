# 04 生化危机9 角色档案

> 对应游戏：《生化危机9：安魂曲》（Resident Evil Requiem, 2026）
> 收录范围：**双主角** + **格蕾丝的旧案相关人物** + **嫌疑人**。
> 说明：本作是 2026 年 2 月新作，角色信息公开有限，本文件以官方已公布内容为主。
> 证据标注：【已核实】【推测】【未明确】。

## 一、双主角

### 1.1 格蕾丝·阿什克罗夫特（Grace Ashcroft）

| 项目 | 内容 |
|------|------|
| 身份 | **FBI 分析员**；本作双主角之一 |
| 能力 | 拥有**卓越的洞察力与推理能力** |
| 性格 | **母亲的离世给她带来深重打击，从此沉默寡言**，将所有精力投入工作 |
| 设定 | 被定义为"**生化危机系列史上最胆小的角色**" |
| 动机 | **为解开过往的心结，毅然（独自）前往案发现场**——调查废弃旅馆中神秘的死亡事件 |
| 玩法定位 | **《生化危机2》蓝本**——生存恐怖；资源极度有限；**血液合成系统**；默认第一人称 |
| 人物弧线 | "**从恐慌到力量的成长弧线感觉非常真实**"（评测） |

**证据等级：【已核实】（Capcom 官网、九游、ZURCS）。**

### 1.2 里昂·S·肯尼迪（Leon S. Kennedy）

| 项目 | 内容 |
|------|------|
| 身份 | **浣熊市事件幸存者之一**；反生物恐怖组织 **DSO 资深特工** |
| 形象 | "**帅气迷人的成熟男性**"（中年）；身经百战 |
| 本作任务 | 着力调查**发生在美国中西部的一系列离奇死亡事件**；接通报后**火速赶往旅馆现场** |
| 回归 | **自《生化危机2》后首次重返浣熊市**——"**成年后的心态变化与对旧地的反应是剧情一大看点**" |
| 极限 | "**将面临前所未有的心理与体能极限**" |
| 玩法定位 | **《生化危机4》蓝本**——武术与近身格斗；枪械 + 斧头；体术、招架、夺取敌人武器；第三人称 |
| 载具 | **保时捷卡宴 Turbo GT** |

**证据等级：【已核实】（Capcom 官网、九游、御三家）。**

## 二、格蕾丝的旧案相关人物

### 2.1 艾丽莎·阿什克罗夫特（Alyssa Ashcroft）

| 项目 | 内容 |
|------|------|
| 身份 | **格蕾丝的母亲**；**浣熊市事件幸存者之一** |
| 职业 | 事件发生时是一名**新闻记者** |
| 性格 | **个性刚强**，怀着**新闻工作者的使命感** |
| 事件后 | **仍锲而不舍地追查保护伞幕后的真相**，直到…… |
| 结局 | **八年前在同一家旅馆遇害**——格蕾丝此次调查的正是该旅馆 |
| **系列渊源** | **《生化危机：爆发》（Outbreak）系列的角色**——本作将《爆发》旧有故事线**串联进正史主线** |

**证据等级：【已核实】（Capcom 官网、御三家、ZURCS）。**

## 四、角色关系速览

```
八年前：艾丽莎·阿什克罗夫特（新闻记者 / 浣熊市幸存者 / 《爆发》角色）
         在追查保护伞幕后真相的过程中，于某废弃旅馆遇害
                    │
                    ▼
八年后：其女格蕾丝（FBI 分析员，因母丧而沉默寡言）
         受上司内森·登普西指派，独自调查该旅馆的神秘死亡事件
                    │
                    ├─ 遇见被隔离在疗养院的女孩艾米莉
          │
          └─ 与里昂（DSO 资深特工 / 浣熊市幸存者 / 正调查中西部离奇死亡）
                   命运交错
                    │
                    └─ 逐步逼近"浣熊市事件"背后隐藏的真相
                       并对抗嫌疑人维克多·基甸（前保护伞 T 病毒研究员）
```
