# 生化危机9：安魂曲（Resident Evil Requiem）主线剧情

- **作品名**：生化危机9：安魂曲（Resident Evil Requiem / バイオハザード レクイエム）
- **开发商**：Capcom（**RE 引擎**）
- **发售**：**2026 年 2 月 27 日**（PS5 / Xbox Series X|S / PC / **Nintendo Switch 2**）
- **销量**：**全球突破 800 万份**（官方）
- **评价**：Metacritic **89–90**；OpenCritic **90**；用户评分极高
- **类型**：生存恐怖 / **双主角（第一 / 第三人称可切换）**
- **主角**：**格蕾丝·阿什克罗夫特（Grace Ashcroft）** 与 **里昂·S·肯尼迪（Leon S. Kennedy）**
- **舞台**：美国中西部、**丧尸游荡的疗养院**、**灭菌作战后化为废墟的浣熊市**、废弃旅馆
- **游戏内时间**：**浣熊市毁灭约 30 年后**（约 **2028 年**）

---

## 一、作品定位：给浣熊市亡魂的安魂曲

- **官方标语**："**予生者恐惧。给尸者安魂。**"
- 本作被评价为"**系列 30 年不死浩劫的完美总结**（a requiem for Raccoon City's ghosts）"——**致敬 30 年系列历史的同时推动公式前进**；
- **自《生化危机2》之后，主线剧情首次回归浣熊市**；
- 结构上**参考《生化危机：启示录》的双线并行模式**。

**证据等级：【已核实】（Capcom 官网、九游、御三家、ZURCS）。**

---

## 二、故事背景

### 2.1 美国各地的离奇死亡事件

- **美国各地接连发生离奇死亡事件**；
- 近日，**又有一具尸体在某废弃旅馆内被发现**；
- 与此同时，**里昂**正着力调查**发生在美国中西部的一系列离奇死亡事件**。

### 2.2 格蕾丝的旧案

- 奉命调查旅馆现场的是 **FBI 分析员格蕾丝·阿什克罗夫特**；
- **八年前，她的母亲正是在同一家旅馆遇害**；
- **为解开过往的心结，她毅然（独自）前往现场**。

### 2.3 里昂的介入

- **负责此案的资深特工里昂·S·肯尼迪**也介入调查；
- 他接到通报，得知**有警员在旅馆失踪**后，便**火速赶往现场**。

### 2.4 命运交错

- 这起事件让**两人的命运开始交错**，并**逐步逼近曾震撼世界的"浣熊市事件"背后所隐藏的真相**；
- **面对那段充满阴霾的往事，他们将困于旧日的噩梦，还是能为逝者奏响安魂曲？**

**证据等级：【已核实】（Capcom 官网）。**

## 三、双主角：两种截然不同的体验

### 3.1 格蕾丝·阿什克罗夫特（Grace Ashcroft）

| 项目 | 内容 |
|------|------|
| 身份 | **FBI 分析员**；拥有**卓越的洞察力与推理能力** |
| 背景 | **母亲的离世给她带来深重打击，从此沉默寡言**，将所有精力投入工作 |
| 设定 | 被定义为"**生化危机系列史上最胆小的角色**" |
| 玩法蓝本 | **《生化危机2》**——经典生存恐怖的紧张感 |
| 资源 | **物资与可携带数量都十分有限**——"**该击倒哪些敌人，又该避开哪些敌人？抉择也将决定生死**" |
| 特色系统 | **物品合成**——可**利用感染者的血液合成治疗物品与弹药**，甚至能制作**一击必杀的特殊注射器** |
| 视角 | 默认**第一人称**（幽闭恐惧式紧张感） |
| 节奏 | 侧重**传统恐怖氛围营造**——潜行、 puzzles（保险箱密码、石英块）、资源管理 |

### 3.2 里昂·S·肯尼迪（Leon S. Kennedy）

| 项目 | 内容 |
|------|------|
| 身份 | **浣熊市事件幸存者之一**；反生物恐怖组织 **DSO 资深特工** |
| 形象 | "**帅气迷人的成熟男性**"（中年）；身经百战；将面临**前所未有的心理与体能极限** |
| 回归 | **自《生化危机2》后首次重返浣熊市**——"一切故事开始的地方"；**成年后的心态变化与对旧地的反应是剧情一大看点** |
| 玩法蓝本 | **《生化危机4》**——融入**武术与近身格斗**元素，新增多款专属动作 |
| 战斗 | 不仅能使用**枪械与斧头**，还能施展**体术、招架**，甚至**利用敌人的武器攻击** |
| 装备 | **丰富的武器与装备强化**——整理手提箱，并用**特制零件改造并强化武器** |
| 载具 | **保时捷卡宴 Turbo GT**（专属座驾） |
| 节奏 | 更偏向**动作导向**——在格蕾丝章节的压抑后获得"**强烈的释放感**" |

**证据等级：【已核实】（Capcom 官网、九游、御三家、ZURCS）。**

## 四、主要角色一览

| 角色 | 身份 | 关键作用 |
|------|------|---------|
| **格蕾丝·阿什克罗夫特（Grace Ashcroft）** | FBI 分析员 | 本作双主角之一；调查母亲旧案；系列最胆小角色 |
| **里昂·S·肯尼迪（Leon S. Kennedy）** | DSO 资深特工 | 本作双主角之一；浣熊市幸存者；自《生化危机2》后首度重返浣熊市 |
| **艾丽莎·阿什克罗夫特（Alyssa Ashcroft）** | **格蕾丝之母**；**浣熊市事件幸存者之一** | 事件发生时是一名**新闻记者**；个性刚强，怀新闻工作者使命感；事件后**仍锲而不舍追查保护伞幕后真相**，直到**八年前在同一家旅馆遇害** |
| **内森·登普西（Nathan Dempsey）** | **格蕾丝的上司** | 明知格蕾丝内心因母亲去世充满阴霾，仍指派其负责调查离奇死亡事件 |
| **艾米莉（Emily）** | 格蕾丝遇到的女孩 | **长期被隔离在疗养院中，皮肤苍白，身形消瘦** |
| **维克多·基甸（Victor Gideon）** | **与美国各地离奇死亡事件有关的嫌疑人** | **曾在造成了浣熊市事件的"保护伞公司"中从事 T 病毒的研究** |

## 六、剧情评价（发售后）

| 维度 | 内容 |
|------|------|
| **整体评价** | "**Requiem 带来真正的生存恐怖回归**"——被视为系列的"**完美综合**" |
| **叙事** | 交织**个人成长、系列 callback 与令人震惊的传说转折**；**将恐惧与黑暗幽默混合**（如丧尸嘟囔自己的"**主角综合征（main character syndrome）**"） |
| **彩蛋** | "**献给粉丝的情书**，充满复活节彩蛋；但对新玩家也友好" |
| **时长** | **约 10–12 小时**的紧凑战役——"没有填充内容" |
| **Boss 战** | **6 场核心 Boss 战**，两位主角**各负责 3 场** |
| **争议点** | **后半段动作偏重**（玩家更想要更多格蕾丝）；**后期 Boss 偏弱**；**没有佣兵模式** |
| **丧尸设计** | "**系列最佳丧尸**"——战斗中会变异、保留诡异的人性、爆炸成令人满意的碎块 |

**证据等级：【已核实】（ZURCS、御三家）。**
