## 三、剧情关键收集物

| 物品 | 说明 |
|------|------|
| **杰克的抗体（Antibody）** | **C 病毒的解药**；杰克靠**卖抗体维生**；西蒙斯想**利用 C 病毒 + 杰克的抗体**成为"救世主" |
| **杰克的医疗数据** | 雪莉**暗中交给里昂**以备被俘——终局关键 |
| **卡拉留下的文件** | 艾达在航母上调查——**揭示整件事来龙去脉** |
| **卡拉的手机** | 艾达**烧掉联络用手机**后离去 |
| **C 病毒导弹** | 气状 C 病毒导弹；使蓝祥大部分居民成为丧尸 |
| **艾达 / 卡拉的服装分辨** | **卡拉是蓝衣、艾达是红衣**——玩家分辨二人的**关键视觉线索** |

## 六、敌人图鉴

| 敌人 | 说明 |
|------|------|
| **丧尸（Zombies）** | **经典丧尸回归**（蓝祥被气状 C 病毒导弹攻击后大量出现） |

| **西蒙斯（多次变异）** | 感染 J'vo 后多次变异；被里昂与海莲娜、艾达联手击杀 |

## 七、玩法机制

| 机制 | 说明 |
|------|------|
| **四线并行** | 四条独立战役，互为拼图 |
| **动作系统** | 以《生化危机4》《5》精进后的战斗系统为基础 |
