## 一、四条战役主角

### 1.1 里昂·S·肯尼迪（Leon S. Kennedy）

| 项目 | 内容 |
|------|------|
| 身份 | **DSO 特工**；**浣熊市事件幸存者** |
| 搭档 | **海莲娜·哈珀（Helena Harper）** |
| 本作 | 高橡市袭击的**唯一幸存者之一**，被迫**亲手杀死已变异的美国总统** |
| 行动 | 与海莲娜**假死**追西蒙斯至蓝祥；**联手艾达杀死变异的海莲娜之妹黛博拉**；**击败变异西蒙斯**；**告知克里斯杰克的真实身份** |
| 结局 | 与海莲娜**洗清嫌疑、恢复职务** |

**证据等级：【已核实】（Wikipedia、天天百科）。**

**证据等级：【已核实】（Wikipedia、游戏232）。**

### 1.4 皮尔斯·尼凡斯（Piers Nivans）

**证据等级：【已核实】（Wikipedia、18183）。**

### 1.5 杰克·穆勒（Jake Muller）

| 项目 | 内容 |
|------|------|
| 身份 | **威斯克之子** |
| 特征 | **拥有威斯克的外貌，但无其老爸的邪气**，反生一股浩然正气 |
| 能力 | 体内有**抗体**——"**C 病毒的解药**"；靠**卖抗体维生** |
| 战斗风格 | **最后徒手迎敌**，"旋风般地了断，很是酷炫" |
| 情感 | 与**雪莉**感情升华；虽因体制被迫分离，但"**二人总有再次相遇的机会**" |
| 结局 | **在发展中国家对抗生化恐怖主义**；**身份由 BSAA 隐瞒**；"**戴上墨镜、驾着摩托车乘风而行，前往另一处生化危机爆发处，任侠除魔**"——被玩家称为"**生化游侠**" |

**证据等级：【已核实】（Wikipedia、巴哈姆特、18183）。**

### 1.7 艾达·王（Ada Wong）

| 项目 | 内容 |
|------|------|
| 身份 | **神秘特工** |
| 本作定位 | **一改过去亦正亦邪，基本以正面角色登场**——**整条主线由她的调查与揭露串联**，被视为"**艾达在生化系列中登场最出彩的一作**" |
| 形象 | 如"**蜘蛛人**"般四处跳跃、飞檐走壁；**解谜成分相对其他篇章较多**（如潜艇探险的**溺毙风险**） |
| 行动 | 揭穿**卡拉冒充西蒙斯**的把戏；**发现西蒙斯克隆自己的事**；追至航母查明真相；**联手里昂击杀西蒙斯** |
| 结局 | 发现**卡拉也找了个替身克隆西蒙斯**，认为已**超出人性的底线**，于是**摧毁实验室、烧掉联络用手机，扬长而去**；**接受新任务** |

**证据等级：【已核实】（Wikipedia、巴哈姆特、天天百科）。**

## 二、反派

### 2.1 德里克·西蒙斯（Derek Simmons）

| 项目 | 内容 |
|------|------|
| 身份 | **美国国家首席安全顾问**；**新安布雷拉（Neo-Umbrella）**关联者 |
| 过往 | **当年发射核弹摧毁浣熊市的决策人之一**；**1998 年艾达在其授意下潜入浣熊市**；因艾达不满其作为而断绝联系 |
| 动机 | **疯狂迷恋艾达**，追求无果后**利用生化病毒企图克隆艾达**；同时是"**极端的'新秩序'追求者**"——认为世界已腐朽，需通过恐惧和灾难重塑 |
| 罪行 | **为维持国家安全而刺杀了美国总统**；制造**高橡市事件**（**只想杀了总统、毁了城市了事，并无灭世之意**） |
| 结局 | **感染 J'vo 后多次变异**；先被里昂与海莲娜击败，后**在艾达协助下被彻底击杀** |

**证据等级：【已核实】（Wikipedia、游戏232、巴哈姆特、18183）。**

### 2.2 卡拉·拉德梅斯（Carla Radames）

| 项目 | 内容 |
|------|------|
| 身份 | **首席研究员** → **假艾达** |
| 过往 | **倾慕西蒙斯**；是**克隆艾达实验的首席研究员**；经历**十年失败**后，**西蒙斯诱骗她本人作试验体终于成功** |
| 变异后果 | **被改造成艾达后，原有记忆和性格全部丧失**；在西蒙斯刻意栽培下**一直认为自己是艾达**并忠心效力 |
| 觉醒 | **2012 年记忆有所恢复**，痛恨西蒙斯对自己所做的一切，**准备报复**；**铁了心要灭世**——**东欧、中国等世界各地的生化危机都是她制造的** |
| 诡计 | **制造东欧生化事件导致艾达被 BSAA 追捕**；**冒充西蒙斯**引诱艾达调查潜艇 |
| 结局 | 因事情败露**被西蒙斯背后的"家族"灭口**；**尸体从艾达眼前坠落**；**死前给自己注射加强的 C 病毒**，变异成怪物"**卡拉孢子**"追杀艾达，**最终仍死在真正的艾达手里** |

**证据等级：【已核实】（Wikipedia、游戏232、天天百科、巴哈姆特）。**

## 四、角色关系速览

```
西蒙斯（国家首席安全顾问，迷恋艾达）
   ├─ 1998年授意艾达潜入浣熊市 → 艾达因不满其毁灭浣熊市而断绝联系
   ├─ 十年克隆实验 → 首席研究员卡拉成试验体 → 成功克隆艾达（卡拉失忆成“假艾达”）
   ├─ 为掩盖国家丑闻刺杀美国总统、制造高橡市事件
   ├─ 背后组织“家族”灭口了要灭世的卡拉
   └─ 感染J'vo多次变异 → 被里昂与艾达彻底击杀

四条战役：
  里昂 + 海莲娜（假死追西蒙斯；联手艾达杀变异的黛博拉）
  克里斯 + 皮尔斯（失忆→恢复；摧毁C病毒导弹；皮尔斯注射C病毒牺牲自己）
  杰克（威斯克之子，有抗体）+ 雪莉（DSO，2代被救女孩）
  艾达（串联全线的调查者；最终摧毁实验室）

结局：里昂/海莲娜复职；克里斯留BSAA；雪莉续任DSO；杰克赴发展中国家；艾达潇洒离去
```
