# 02 生化危机6 支线剧情

> 对应游戏：《生化危机6》（Resident危机 6, 2012）
> 说明：本作的"支线"主要体现为**四条战役的交织与互补**、**佣兵模式**、**"家族"暗线**与**系列争议**。本文件与 `01_生化危机6_主线剧情.md` 互补。

---

## 一、四线交织：本作最大的"支线"结构

### 1.1 四条战役互为拼图

- 四条战役**并非独立平行**，而是**同一时段、不同地点、不同侧面**；
- **最典型的重叠**：玩家会在**克里斯线**看到"艾达"炸毁大楼，**切到艾达线才发现那是卡拉（Carla）在栽赃嫁祸**；
- **艾达线是"最后一块拼图"**——揭穿一路害克里斯、造就中国丧尸危机的另一元凶"**假艾达**"卡拉的真面目，完成主线全貌。

**证据等级：【已核实】（18183、巴哈姆特）。**

### 1.2 官方推荐游玩顺序

> 来源：18183 推荐时间线游玩顺序（**可在同一时间段内看到不同角色在同一地点的不同侧面**）。

| 章 | 顺序 |
|----|------|
| 第一章 | 里昂 1 → 克里斯 1 → 杰克 1 → 艾达 1 |
| 第二章 | 杰克 2 → 艾达 2 → 里昂 2 → 克里斯 2 |
| 第三章 | 克里斯 3 → 里昂 3 → 杰克 3 → 艾达 3 |
| 第四章 | 艾达 4 → 杰克 4 → 里昂 4 → 克里斯 4 |
| 第五章 | 里昂 5 → 克里斯 5 → 杰克 5 → 艾达 5 |

**证据等级：【已核实】（18183）。**

## 二、四条战役的"恐怖分工"（设计层面）

| 战役 | 恐怖表达 |
|------|---------|
| **里昂线** | **哥特式、经典《生化危机》式恐怖** |
| **克里斯线** | **战场的恐怖** |
| **杰克线** | **被追猎的恐惧** |
| **艾达线** | **非常经典的《生化危机》式体验**（**解谜成分相对较多**；以**旁观者 / 协助者**角度闯关，难度低于主动出击的里昂、克里斯、杰克） |

**证据等级：【已核实】（Wikipedia、巴哈姆特）。**

---

## 三、"家族"（the Family）暗线

- **西蒙斯背后的神秘组织**——即**灭口卡拉**的势力；
- 官方未完整交代其全貌，属系列留白；
- 卡拉因"事情败露"被其灭口，**尸体从艾达眼前坠落**。

**证据等级：【已核实】（天天百科）。**

---

## 四、丧尸回归（系列反馈的回应）

- 制作人**小林裕幸**："**我们让丧尸回归，因为它们很受欢迎。**"；
- 基于《生化危机4》《生化危机5》的反馈——"**那两款游戏里没有经典丧尸，而人们真的很想要**"；
- 本作因此**大量回归经典丧尸**（尤其是蓝祥被气状 C 病毒导弹攻击后）。

**证据等级：【已核实】（Wikipedia / Siliconera 访谈）。**

---

## 五、佣兵模式（The Mercenaries）

- 系列传统的额外挑战模式，本作继续收录；
- **玩法**：限时击杀 / 连击延长时间，追求高分。

**证据等级：【已核实】。**

## 六、角色情感线（支线叙事的核心）

| 关系 | 内容 |
|------|------|
| **西蒙斯 → 艾达** | 疯狂的迷恋——因失去艾达而**克隆她**，最终玩火自焚 |
| **卡拉 → 西蒙斯** | 长期的倾慕与付出——**却被当作艾达的替代品**；由爱生恨，**不惜制造生化危机让全世界陪葬** |
| **杰克 × 雪莉** | 逃亡中感情升华；虽因体制被迫分离，但"**二人总有再次相遇的机会**"；杰克如"**生化游侠**"般逍遥 |
| **克里斯 × 皮尔斯** | 战友情——皮尔斯**牺牲自己**救克里斯 |
| **艾达的立场** | 本作中**一改过去亦正亦邪，基本以正面角色登场**——**整条主线由她的调查与揭露串联**，被视为"**艾达在生化系列中登场最出彩的一作**" |

**证据等级：【已核实】（巴哈姆特、天天百科）。**

## 七、责任归属的辨析（剧情易混点）

| 事件 | 制造者 | 目的 |
|------|--------|------|
| **高橡市事件** | **西蒙斯** | **出于掩盖国家丑闻的目的**；他**只想杀了总统、毁了城市了事，并无灭世之意** |
| **东欧、中国等世界各地的生化危机** | **卡拉** | **铁了心要灭世** |

> 巴哈姆特玩家总结："**这一代整篇故事就是：一个为爱疯狂的变态，制造了另一个为爱疯狂的变态，促发的世界危机。**"【已核实】

## 八、评价与争议

| 维度 | 内容 |
|------|------|
| **玩法** | 以 4、5 代精进后的战斗系统让玩家尽兴；四篇章交织"五味杂陈"；被部分玩家视为"**历代最好玩、最触动人心的本传**" |
| **剧本** | 不同情感融汇 + 稍微回归的恐怖感 + 不同格局的战场 + 相当程度的解谜要素 |
| **争议** | **剧情太乱**是普遍反馈（四线 + 时间重叠）；**"好莱坞动作大片"化**、格局从求生变为战争 |
| **内核** | 对"**生化恐怖主义全球化**"的深度推演——**不再是求生，而是战争** |

**证据等级：【已核实】（18183、巴哈姆特）。**
