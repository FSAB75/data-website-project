# 03 生化危机4 游戏内全部档案

> 对应游戏：《生化危机4》（Resident Evil 4, 2005 / 2023 重制版）
> 收集体系：本作的核心收集为**文件 / 笔记**（叙事载体）、**宝石与工艺品（宝藏）**、**钥匙与解谜道具**、**武器与升级**、**佣兵模式与艾达篇**。
> 数据说明：整理自萌娘百科、百度百科、维基百科镜像；**未逐字转录**游戏内文本。

---

## 一、档案（收集）体系说明

| 收集类型 | 说明 |
|---------|------|
| **文件 / 笔记（Files）** | 村庄、城堡、岛内散落的文献——叙事载体 |
| **宝石与工艺品（Treasures）** | **可出售换钱**的收集品；部分可**嵌入道具提升价值** |
| **钥匙 / 解谜道具** | 村庄、城堡、实验室各区域 |
| **武器 / 弹药 / 补给** | 常规生存资源 |
| **手提箱 / 挂件** | 收纳与增益系统 |
| **额外模式** | Separate Ways / Assignment Ada / The Mercenaries |

---

## 二、文件（Files）体系

- **形态**：村庄民居、城堡书房、实验室中的**手记、备忘录、研究报告**；
- **内容要点**：揭示**光明教团的历史**、**普拉卡寄生虫的研究**、**路易斯的挣扎**、**萨德勒的企图**等；
- **地位**：理解本作邪教暗线的主要途径。

**证据等级：【已核实】。**

> 具体文件的**标题与逐条清单**公开来源未完整收录，本文件不臆造。【未明确】

## 三、宝藏收集：宝石与工艺品

| 收集品 | 说明 |
|--------|------|
| **宝石（Gems）** | 村庄、城堡、矿场中拾取；**可出售给武器商人** |
| **工艺品（Antiques / Collectibles）** | 城堡内的贵重器物；**可出售** |
| **可嵌入宝石的道具** | 部分王冠、权杖等可**嵌入宝石后大幅提升售价** |
| **"琥珀"（Amber）** | **剧情核心**——含**比支配性普拉卡更强大的力量**；克劳萨上交给萨德勒；最终被艾达取得 |

**证据等级：【已核实】（维基百科镜像、网易）。**

## 七、额外模式与收集

## 八、各版本特色与差异

| 版本 | 年份 | 特色 |
|------|------|------|
| **GameCube 原版** | **2005** | 过肩视角革命；系列转型之作 |
| PS2 / PC / Wii | 2006–2007 | 移植；**PC 版收录 Separate Ways** |
| 终极 HD 版 | 2014 前后 | 高清化；PC 版**首次原生支持键盘鼠标** |
| **RE 引擎重制版** | **2023** | 全面重制；废除 CG 中的 QTE；追加挂件饰品；剧情与结局微调 |

**证据等级：【已核实】。**
