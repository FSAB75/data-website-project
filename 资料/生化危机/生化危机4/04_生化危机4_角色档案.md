# 04 生化危机4 角色档案

> 对应游戏：《生化危机4》（Resident Evil 4, 2005 / 2023 重制版）
> 收录范围：**主角** + **光明教团** + **艾达与威斯克暗线**。
> 说明：本作角色是系列核心班底与最经典反派之一，其背景多在其他作品中补完。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、主角

### 1.1 里昂·斯科特·肯尼迪（Leon S. Kennedy）

| 项目 | 内容 |
|------|------|
| 身份 | **为美国总统直接统率的最高机密组织成员**；本作主角 |
| 履历 | 《生化危机2》的"新人警察"；后与雪莉一同**被美国政府拘捕**；如今刚**被委派为总统一家的护卫** |
| 任务 | 营救被绑架的**总统之女阿什莉** |
| 经历 | 被萨德勒注射普拉卡；救出阿什莉；击败门德斯、萨拉扎、克劳萨、萨德勒；**在实验室以激光手术清除体内普拉卡** |
| 结局 | 与阿什莉逃出爆炸的据点 |

**证据等级：【已核实】（百度百科、萌娘百科）。**

### 1.2 阿什莉·格拉汉姆（Ashley Graham）

| 项目 | 内容 |
|------|------|
| 身份 | **美国总统之女**；**大学生**；本作**营救目标** |
| 经历 | 被绑架到光明教团村庄，**被注射普拉卡寄生虫**；被关押在教堂深处；后被萨拉扎带往小岛准备"同化为寄生虫宿主的仪式" |
| 关键表现 | 在被萨德勒控制时，**强行以自己的意志力拒绝执行"射杀里昂"的指令** |
| 结局 | 与里昂一同清除寄生虫并逃出；询问是否愿继续当护卫，**被婉拒** |
| 玩法特色 | **无战斗能力**；会被敌人扛走、踩捕兽夹；生命归零（**含被里昂误伤**）即任务失败 |
| 玩家绰号 | 因谐音与"不绝于耳的尖叫呼救"被戏称"**碍事梨**" |
| 重制版造型 | **橙色外套 + 黑色连裤袜**；额外服装有**白色礼服**与**骑士盔甲套装**（后者可变无敌） |

**证据等级：【已核实】（萌娘百科、维基百科镜像）。**

## 二、光明教团（Los Illuminados）

### 2.1 奥斯蒙德·萨德勒（Osmund Saddler）

| 项目 | 内容 |
|------|------|
| 身份 | **光明教团教主**；**本作主要反派** |
| 阴谋 | 意图**把受感染的阿什莉送回美国、让总统感染，从而统治世界** |
| 手段 | 给里昂与阿什莉**注射普拉卡**；**以普拉卡控制里昂**，并试图利用阿什莉体内的普拉卡让她射杀里昂 |
| 结局 | 被里昂与艾达击败；**释放体内普拉卡力量变成巨大怪物**盘踞港口；最终被两人合力击杀 |

**证据等级：【已核实】（萌娘百科、维基百科镜像）。**

### 2.2 比特罗斯·门德斯（Bitores Mendez）

| 项目 | 内容 |
|------|------|
| 身份 | **村庄村长** |
| 行动 | 抓住并击晕里昂；将其交由萨德勒注射普拉卡 |
| 结局 | 被里昂消灭 |

**证据等级：【已核实】。**

### 2.3 拉蒙·萨拉扎（Ramon Salazar）

| 项目 | 内容 |
|------|------|
| 身份 | **古堡主人**；光明教团成员 |
| 行动 | 抓住与里昂重逢的阿什莉，**带往萨德勒的小岛准备仪式** |
| 结局 | 被里昂消灭 |

**证据等级：【已核实】。**

### 2.4 杰克·克劳萨（Jack Krauser）

| 项目 | 内容 |
|------|------|
| 身份 | 里昂的**前教官 / 战友**；**据报已死亡** |
| 真相 | 实为**光明教团效力**——原版为**听命于威斯克**（作为加入教团的"投名状"）；**重制版改为听命于萨德勒**（与威斯克**无交集**） |
| 动机 | 否认因"**哈维尔行动**"惨重伤亡而怨恨美国政府；称加入教团是"**为了获得更强大的力量**" |
| 结局 | 在人工岛上**受普拉卡影响变异**，被里昂击败；**尸体被神秘人带走** |

**证据等级：【已核实】（萌娘百科、维基百科镜像、网易）。**

## 三、艾达与威斯克暗线

### 3.1 艾达·王（Ada Wong）

| 项目 | 内容 |
|------|------|
| 身份 | **神秘间谍** |
| 雇主 | **威斯克**——雇佣她夺取"琥珀" |
| 行动 | **比里昂更早一天到达村庄**；与路易斯交易；关键时刻多次救里昂；终局**把萨德勒引走**以让里昂救阿什莉 |
| 关键抉择 | 得知威斯克要"**以数十亿人伤亡的代价迎接新的曙光**"后，**决定不把琥珀交给威斯克**，并**逼迫直升机驾驶员改变航向** |
| 情感线 | 原版中里昂**直球承认"艾达对自己很重要"** |

**证据等级：【已核实】（网易、维基百科镜像）。**

### 3.2 路易斯·塞拉（Luis Sera）

| 项目 | 内容 |
|------|------|
| 身份 | **萨德勒聘请的寄生虫研究员** |
| 出身 | **出生于这个小村庄**；长大后加入**安布雷拉**；安布雷拉被铲除后**回到村庄帮助萨德勒研究普拉卡的应用** |
| 转变 | 起初**不知自己的研究有多黑暗**；后来**良心发现、试图求助**；为逃出村子与艾达联系——**以帮艾达拿琥珀换取带他逃离** |
| 结局 | 找到解毒药物与样本，但**被萨德勒杀害**；临死前告知里昂**小岛上的实验室**位置 |

**证据等级：【已核实】（百度百科、网易）。**

### 3.3 阿尔伯特·威斯克（Albert Wesker）（幕后）

| 项目 | 内容 |
|------|------|
| 身份 | 艾达的"老板" |
| 图谋 | 夺取"琥珀"后，准备"**以数十亿人伤亡的代价迎接新的曙光**" |
| 结果 | **艾达拒绝交付**，计划受挫——为《生化危机5》的终局铺垫 |

**证据等级：【已核实】（维基百科镜像）。**

## 四、角色关系速览

```
威斯克（幕后）── 雇佣 ──→ 艾达（夺取琥珀）
                              │
里昂（总统直属组织）──── 相爱 / 协作 ────┘
   │  （里昂承认"艾达对自己很重要"）
   │
   └─ 护送 ── 阿什莉（总统之女，无战斗力）
                    │
光明教团（Los Illuminados）
   教主 萨德勒（主反派，欲统治世界）
    ├─ 村长 门德斯
    ├─ 堡主 萨拉扎
    └─ 克劳萨（里昂前教官，为"更强大的力量"而入教）

路易斯（萨德勒研究员 → 良心发现助里昂 → 被萨德勒杀害）
普拉卡寄生虫（Las Plagas）＝ 本作核心病原体
琥珀（Amber）＝ 比支配性普拉卡更强的力量 → 被艾达取得、未交威斯克
```
