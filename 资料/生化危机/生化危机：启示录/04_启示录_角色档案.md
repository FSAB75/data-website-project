# 04 启示录 角色档案

> 对应游戏：《生化危机：启示录》（Resident Evil: Revelations, 2012）
> 收录范围：**BSAA 双主角** + **阴谋各方** + **Veltro**。
> 说明：本作角色是《生化危机5》的直接前奏，其中数人的真实归属在片尾才揭晓。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、BSAA 特工

### 1.1 吉尔·瓦伦丁（Jill Valentine）

| 项目 | 内容 |
|------|------|
| 身份 | **前 S.T.A.R.S. 成员**；现为 **BSAA 特工** |
| 搭档 | **帕克·卢恰尼** |
| 本作任务 | 受命前往**克里斯与杰西卡最后已知的坐标**，调查"季诺碧亚女王号" |
| 结局 | 与克里斯揭露兰斯代尔；结尾走向**斯宾塞宅邸**（接《生化危机5》"Lost in Nightmares"） |
| 延伸 | 《生化危机5》中她被威斯克控制（系列后续重要剧情） |

**证据等级：【已核实】（Fandom、台湾环球药局）。**

### 1.2 帕克·卢恰尼（Parker Luciani）

| 项目 | 内容 |
|------|------|
| 身份 | **BSAA 特工**；吉尔搭档 |
| 性格 | **幽默且忠诚** |
| 经历 | 曾被杰西卡枪击；**雷蒙德为他挡下子弹**；被雷蒙德从爆炸中救出 |
| 结局 | 在**马耳他海岸**被发现漂流，一个月康复后**重返 BSAA 特勤干员岗位** |

**证据等级：【已核实】（Fandom、Shinchuck）。**

### 1.3 克里斯·雷德菲尔德（Chris Redfield）

| 项目 | 内容 |
|------|------|
| 身份 | **BSAA 资深特工**；吉尔老搭档 |
| 本作 | 因**调查 Veltro 组织**而"失踪"（实为任务）；与杰西卡在欧洲山区行动 |
| 结局 | 与吉尔击败诺曼、取得证据；结尾同赴斯宾塞宅邸 |

**证据等级：【已核实】。**

## 二、阴谋各方

### 2.1 杰西卡·谢拉瓦特（Jessica Sherawat）

| 项目 | 内容 |
|------|------|
| 身份 | 克里斯搭档；表面 BSAA 特工 |
| **真实身份** | **BSAA 内鬼**——实为 **FBC（联邦生化恐怖主义委员会）的卧底** |
| 行动 | **枪击帕克**、**启动船只自毁**以销毁证据 |
| 结局 | **未被揭穿地逃脱**；片尾与雷蒙德会面，收下 **T-Abyss 样本** |
| **最终归属** | 与雷蒙德实为 **TRICELL（三联制药）** 效力——《生化危机5》的幕后黑手 |

**证据等级：【已核实】（Fandom、Shinchuck、半官方情报）。**

### 2.2 雷蒙德·维斯特（Raymond Vester）

| 项目 | 内容 |
|------|------|
| 身份 | 表面为 FBC 人员、实为**卧底** |
| 行动 | 全程协助奥布莱恩；**为帕克挡子弹**（穿防弹背心）；从爆炸中**救出帕克** |
| 结局 | 片尾在咖啡馆接近杰西卡，递上 **T-Abyss 样本**；回答"**我有我的理由**"并摘下墨镜 |
| **最终归属** | 与杰西卡同属 **TRICELL** |

**证据等级：【已核实】（Fandom、Shinchuck）。**

### 2.3 克莱夫·R·奥布莱恩（Clive R. O'Brian）

| 项目 | 内容 |
|------|------|
| 身份 | **BSAA 主席** |
| 行动 | 与雷蒙德发现兰斯代尔与 Veltro 有关但缺证据，遂**策划"复活 Veltro"的局**以引出兰斯代尔 |
| 结局 | 兰斯代尔被捕后获释；**因策划整个局而辞去 BSAA 主席**以担责 |

**证据等级：【已核实】（Fandom、Shinchuck）。**

### 2.4 摩根·兰斯代尔（Morgan Lansdale）

| 项目 | 内容 |
|------|------|
| 身份 | **FBC 专员**；**本作幕后黑手** |
| 罪行 | 与 Veltro 合作；**击沉第三艘船（Queen Dido）以销毁罪证**；试图销毁其余船只 |
| 结局 | **被奥布莱恩逮捕** |

**证据等级：【已核实】（Fandom、IGN）。**

## 三、Veltro

### 3.1 杰克·诺曼（Jack Norman）

| 项目 | 内容 |
|------|------|
| 身份 | **Veltro 首领** |
| 状态 | 已**精神错乱**——曾靠**注射 T-深渊存活一年**，并**靠复仇欲望抵抗变异** |
| 结局 | **注入过量 T-Abyss**，误以为克里斯与吉尔是 FBC 派来杀他的人，**变异为"最终形态·深渊（Final Form Abyss）"**；被击败后**临终表示"终于能得到平静"** |

**证据等级：【已核实】（Fandom、Shinchuck）。**

## 五、角色关系速览

```
BSAA（奥布莱恩主席）
   ├─ 吉尔 + 帕克（邮轮线）
   └─ 克里斯 + 杰西卡（山区线）
            │
            └─ 杰西卡 = FBC 内鬼（枪击帕克、启动自毁）
                    │
                    └─ 实与雷蒙德同为 TRICELL 效力（片尾彩蛋）

FBC（兰斯代尔专员）── 与 ── Veltro（诺曼首领）合作
            │
            └─ 兰斯代尔被奥布莱恩设计引出 → 被捕 → FBC 解散

T-Abyss：能在水中感染的病毒；诺曼注入过量 → 变异为"最终形态·深渊"
```
