- **内容要点**：揭示**特拉格里亚惨案经过**、**T-Abyss 的研究**、**兰斯代尔与 Veltro 的关系**、**杰西卡的真实身份线索**等；

## 四、扫描仪（Genesis）系统

| 项目 | 说明 |
|------|------|
| **功能** | 自动扫描 **12 米内**的物品 |
| **用途 1** | **发现隐藏物品** |
| **用途 2** | **分析敌人弱点**——扫描后可看到敌人未覆盖部位，提升伤害 |
| **限制** | 消耗**电量**，需在场景中充电 |
| **战略地位** | 资源稀缺环境下的核心生存策略 |

**证据等级：【已核实】（IGN）。**
