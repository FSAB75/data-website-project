# 生化危机：启示录（Resident Evil: Revelations）主线剧情

- **作品名**：生化危机：启示录（Resident Evil: Revelations / バイオハザード リベレーションズ）
- **开发商**：Capcom（使用 MT Framework Mobile 引擎，专为 Nintendo 3DS 设计）
- **发售**：**2012 年**（Nintendo 3DS 首发）；后移植 Wii U / PS3 / Xbox 360 / PS4 / Xbox One / Switch / PC
- **类型**：生存恐怖 / 动作冒险
- **主角**：**吉尔·瓦伦丁** 与 **克里斯·雷德菲尔德**（BSAA 特工）
- **舞台**：**季诺碧亚女王号（Queen Zenobia）**邮轮、**地中海女王号（Queen Semiramis）**、**迪多女王号（Queen Dido）**、**特拉格里亚（Terragrigia）**、欧洲山区的 Veltro 据点
- **游戏内时间**：**2005 年**（介于《生化危机4》与《生化危机5》之间）

---

## 一、故事背景

### 1.1 特拉格里亚惨案

- **特拉格里亚（Terragrigia）**——一座建于海上的"**太阳能城市**"；
- 它遭到生化恐怖组织 **Veltro（Il Veltro，意为"猎犬"）**的**生化武器袭击**，城市被摧毁；
- 官方宣称的目的是"**引起公众对生化武器问题的关注**"，同时特拉格里亚也在研究一种新病毒——**T-深渊（T-Abyss）**。

### 1.2 新病毒：T-Abyss

- **T-Abyss** 能在**水中感染生物**，进而感染任何饮用受感染水源的人；
- 这是本作的核心生化威胁。

**证据等级：【已核实】（IGN、Fandom）。**

---

## 二、双线叙事：邮轮与山区

### 2.1 吉尔与帕克线（邮轮）

- **吉尔·瓦伦丁**与搭档**帕克·卢恰尼（Parker Luciani）**奉命前往 **克里斯与杰西卡最后已知的坐标**；
- 他们发现的是一艘废弃豪华邮轮"**季诺碧亚女王号（Queen Zenobia）**"；
- 两人在船上发现**大量被 T-深渊病毒感染的怪物**，并遭遇一名**戴防毒面具的神秘恐怖分子**伏击；
- 吉尔与帕克在船上探索，试图联系总部请求撤离。

### 2.2 克里斯与杰西卡线（欧洲山区）

- 与此同时，**克里斯·雷德菲尔德**与**杰西卡·谢拉瓦特（Jessica Sherawat）**在**欧洲山区**发现一个**疑似被 Veltro 占据的区域**；
- 他们被 **BSAA 总部的克莱夫·R·奥布莱恩（Clive R. O'Brian）**联系，得知吉尔与帕克失联；
- 两人为寻找吉尔与帕克，最终登上**女王号的姊妹船"地中海女王号（Queen Semiramis）"**，继而抵达**季诺碧亚女王号**。

### 2.3 汇合与换伴

- 两条线在女王号上交汇；
- **吉尔与克里斯**、**帕克与杰西卡**重新组队继续调查。

---

## 三、阴谋揭晓

### 3.1 奥布莱恩的"局"

- 奥布莱恩与雷蒙德发现**摩根·兰斯代尔（Morgan Lansdale，FBC 专员）**与 Veltro 有关，但**缺乏证据**；
- 于是两人**设了一个局**：**故意让 Veltro"复活"以引出兰斯代尔**；
  - 他们**搭建假据点**、派克里斯与杰西卡去调查以取得两艘现存船只的坐标；
  - 再由奥布莱恩告知吉尔与帕克"克里斯与杰西卡失联"，把两人引向另一艘船；
- 兰斯代尔则派出**蕾切尔（Rachel）**与**雷蒙德**登船——**蕾切尔在游戏初期即被杀**（全作**唯一非怪物死亡的角色**）。

### 3.2 内鬼：杰西卡

- **杰西卡被揭露为 BSAA 的内鬼**——实为 **FBC（联邦生化恐怖主义委员会）的卧底**；
- 她向帕克开枪，并**启动船只自毁**以销毁证据；
- **雷蒙德为帕克挡下子弹**（原来他穿着防弹背心），并告诉帕克"杰西卡要毁船以掩盖能牵连兰斯代尔的证据"。

### 3.3 决战：诺曼与"最终深渊形态"

- 奥布莱恩与雷蒙德的数据分析揭示：**特拉格里亚废墟下还有第三艘姊妹船"迪多女王号（Queen Dido）"**——它被兰斯代尔**击沉以销毁罪证**；
- 克里斯与吉尔登船寻找 **Veltro 首领杰克·诺曼（Jack Norman）**；
- 诺曼已**精神错乱**——他曾靠注射 T-深渊**存活一年**并靠复仇欲望抵抗变异；这次他**注入过量病毒**，误以为克里斯与吉尔是 FBC 派来杀他的人，**变异为新型暴君"最终形态·深渊（Final Form Abyss）"**；
- 经过长时间战斗，诺曼终于被击败，**临终表示"终于能得到平静"**。

## 四、结局与后续

| 项目 | 内容 |
|------|------|
| **证据公开** | 克里斯与吉尔通过诺曼的 PDA **播放录像**，**揭露兰斯代尔**；奥布莱恩获释并**逮捕兰斯代尔** |
| **FBC 解散** | 特拉格里亚真相公开，**FBC 被解散**（大部分人员与资源转入 BSAA） |
| **奥布莱恩** | 因策划整个"局"而**辞去 BSAA 主席**以担责 |
| **帕克** | 被雷蒙德从爆炸中救出；在**马耳他海岸**被发现漂流，一个月康复后**重返 BSAA 特勤干员岗位** |
| **昆特与基思** | 空袭中**幸存** |
| **衔接《生化危机5》** | 结尾展示克里斯与吉尔走向**斯宾塞宅邸**（即《生化危机5》"**迷失在噩梦**"篇章） |
| **片尾彩蛋** | 雷蒙德在咖啡馆接近**杰西卡**，递给她一份 **T-深渊病毒样本**；她问他为何救帕克，他答"**我有我的理由**"并摘下墨镜——**两人其实一直在为某个既非 FBC、BSAA、也非 Veltro 的组织效力** |

**半官方情报**：雷蒙德与杰西卡实为 **TRICELL（三联制药）** 工作——正是《生化危机5》事件的幕后黑手。

**证据等级：【已核实】（Fandom、IGN、Shinchuck）。**
