# 05 启示录 大事件时间线

> 对应游戏：《生化危机：启示录》（Resident Evil: Revelations, 2012）
> 说明：本作设定于**《生化危机4》与《生化危机5》之间**，以"**三艘邮轮 + 一座废城**"的阴谋为核心，并为《生化危机5》的 TRICELL 线直接埋线。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、本作在系列时间轴上的位置

```
1998 ─ 阿克雷/洋馆/浣熊市事件（0、1、2、3）
2000 ─ 洛克福特岛/南极事件（代号维罗妮卡）
        ↓
2004–2005 ─ 西班牙“光明教”事件（《生化危机4》）
        ↓
2005 ─ ★特拉格里亚阴谋与三艘邮轮事件（本作）
        ↓
2009 ─ 非洲事件；TRICELL与Uroboros；克里斯与威斯克终局（《生化危机5》）
```

## 七、要点与易混提示

1. **本作是《生化危机5》的直接前奏**：TRICELL、T-Abyss 的后续（Uroboros）都在《生化危机5》展开。
2. **"内鬼"有两个人**：**杰西卡（BSAA/FBC 内鬼）**与**雷蒙德（表面 FBC、实为反兰斯代尔的卧底）**——但片尾揭示雷蒙德最终也属于 **TRICELL**。
3. **整个事件是奥布莱恩设计的局**：为引出兰斯代尔而"复活 Veltro"——这让"谁是反派"成为本作最大反转。
4. **蕾切尔之死**：她是全作唯一"非怪物致死"的角色，其身份与任务在系列中仍是留白。
5. **三艘邮轮**：Zenobia（主舞台）、Semiramis（姊妹船）、Dido（被击沉的第三艘，藏有罪证）。
