# 04 生化危机8 角色档案

> 对应游戏：《生化危机8：村庄》（Resident危机 Village, 2021）
> 收录范围：**伊森一家** + **母神米兰达** + **四大领主** + **克里斯与公爵**。
> 说明：本作是"新三部曲"的第二部，也是**伊森线的终点**。
> 证据标注：【已核实】【推测】【未明确】。

## 一、伊森一家

### 1.1 伊森·温特斯（Ethan Winters）

| 项目 | 内容 |
|------|------|
| 身份 | **本作主角**；《生化危机7》生还者 |
| 生活 | 与米娅、女儿萝丝在 **BSAA 保护**下**隐居于罗马尼亚** |
| 经历 | 家被突袭、女儿被劫 → 困于冰雪村庄 → 击败四大领主 → **被米兰达刺穿心脏仍存活** → 得知自己是"菌丝人" → 与米兰达同归于尽 |
| **核心真相** | **他 3 年前在贝克家就被杰克杀死**；因感染霉菌苟延残喘，**早就是行尸走肉**；**米娅一直瞒着没告诉他** |
| 结局 | **将女儿托付给克里斯，自己留下断后，与米兰达同归于尽**；村庄被炸毁 |
| **后续（DLC）** | **肉体虽死，意识却通过巨菌幸存**；16 年后以"**米迦勒**"之名护佑女儿，最终**把结婚戒指送给回到现实的萝丝** |

**证据等级：【已核实】（萌娘百科、18183、今日头条）。**

### 1.2 萝丝玛丽·温特斯（Rose / Rosemary Winters）

| 项目 | 内容 |
|------|------|
| 身份 | **伊森与米娅之女**；婴儿时被劫 |
| **特殊性** | **拥有特殊霉菌体质**——正是米兰达复活女儿伊娃所需的"**完美容器**" |
| 经历 | **被切成四份装在四个瓶子中**，四大领主各持一份；终局被复原 |
| **后续（DLC）** | 16 年后上高中；**被骗"能消除力量"而进入巨菌领域**；在"米迦勒"（伊森）帮助下**彻底消灭米兰达残余**；**收到父亲的结婚戒指** |

**证据等级：【已核实】（萌娘百科、今日头条）。**

### 1.3 米娅·温特斯（Mia Winters）

| 项目 | 内容 |
|------|------|
| 身份 | 伊森之妻 |
| 本作 | **被米兰达借助菌主变成她的样子**潜伏伊森家（被克里斯射杀的"米娅"即是此伪装）；**真正的米娅被米兰达囚禁** |
| 结局 | **被克里斯救出**；结局乘直升机撤离 |

**证据等级：【已核实】（萌娘百科、今日头条）。**

## 二、主要反派

### 2.1 母神米兰达（Mother Miranda）

| 项目 | 内容 |
|------|------|
| 身份 | **村庄宗教领袖**；**本作主要反派** |
| 年龄 | **已活了百年**（实现长生不老） |
| 动机 | **1918 年西班牙流感中失去女儿伊娃**；此后的一切只为**复活女儿** |
| 关键发现 | 在**洞窟**发现"**菌主（Megamycete）**"——**具有储存死者意识的能力**的巨型霉菌 |
| 手段 | 用霉菌做人体实验；创造"**恩赐（Cadou）**"寄生体；**把村民当实验场**；**四大领主受恩赐变异** |
| 阴谋 | **利用拥有完美霉菌适应性的萝丝作为容器，复活女儿伊娃** |
| **与系列的联系** | **《生化危机7》中制造伊芙琳的 DNA 和霉菌，就是米兰达提供给犯罪组织"联盟"的**；**伊芙琳只是一个残次品** |
| **与安布雷拉的渊源** | **1953 年，年轻医学生奥斯威尔·E·斯宾塞曾师从米兰达**；斯宾塞受启发但**理念不同**（米兰达只为复活女儿，斯宾塞想用病毒"重塑人类"）；斯宾塞后来创立安布雷拉，**安布雷拉标志即源自米兰达村庄的古老符号** |
| 结局 | 被伊森击败；**与伊森同归于尽**；DLC 中其**残余设下陷阱**，最终被萝丝彻底消灭 |

**证据等级：【已核实】（萌娘百科、今日头条）。**

### 2.2 伊娃（Eva）

| 项目 | 内容 |
|------|------|
| 身份 | **米兰达之女** |
| 死亡 | **1918 年死于西班牙流感** |

## 五、角色关系速览

```
母神米兰达（百年不老）
   ├─ 1918年失去女儿伊娃 → 发现菌主（可存死者意识）
   ├─ 创造“恩赐”寄生体 → 四大领主变异 / 村民成狼人残次品
   ├─ 向“联盟”提供霉菌（→ 伊芙琳，残次品）
   ├─ 1953年：斯宾塞曾师从她 → 后创安布雷拉（标志源自其村庄符号）
   └─ 目标：用萝丝（完美霉菌体质）复活伊娃
          │
          └─ 假扮米娅潜伏伊森家 → 劫走萝丝（切成四份，四领主各持一份）

伊森（实为3年前被杰克杀死的“菌丝人”）
   ├─ 四大领主逐一击败 → 集齐四瓶
   ├─ 被米兰达刺穿心脏仍存活（得知自身真相）
   ├─ 与克里斯联手击败米兰达
   └─ 留下断后，与米兰达同归于尽（村庄被毁）
          └─ 意识经巨菌存活 → 16年后以“米迦勒”护佑萝丝

克里斯（BSAA）：突袭伊森家→救出真米娅→炸毁工厂与巨菌→受托照顾萝丝
```
