# 02 生化危机8 支线剧情

> 对应游戏：《生化危机8：村庄》（Resident Evil Village, 2021）
> 说明：本作的"支线"主要体现为**DLC《萝丝魅影》（Shadows of Rose）**、**四大领主支线**、**"恩赐"与村庄生态暗线**与**跨作品呼应**。本文件与 `01_生化危机8_主线剧情.md` 互补。

---

## 一、DLC《萝丝魅影》（Shadows of Rose）——16 年后的续章

| 项目 | 内容 |
|------|------|
| **时间点** | **主线 16 年后** |
| **主角** | **已上高中的萝丝** |
| **起因** | 萝丝每年在**伊森生日**时扫墓；某天**被欺骗"能够消除她的力量"**，**进入巨菌的领域** |
| **"米迦勒"（Michael）** | 一个自称"米迦勒"的存在与她联系——**不说话，仅通过书面形式交流**；提供武器但多次建议她离开 |
| **真相** | **"米迦勒"就是伊森本人**——他**肉体虽死，意识却通过巨菌幸存下来**；目的是把萝丝从**伊芙琳**手中救出 |
| **陷阱** | 所谓"**解药**"其实是**米兰达的残余设下的陷阱** |
| **高潮** | 伊森试图帮萝丝逃脱但身受重伤；**萝丝接受了伊森的力量，彻底消灭了米兰达** |
| **收尾** | 伊森表达自豪；萝丝回到现实时**收到他的结婚戒指** |

**证据等级：【已核实】（萌娘百科）。**

## 二、四大领主支线（各领主的"独立篇章"）

| 领主 | 场景风格 | 恐怖类型 |
|------|---------|---------|
| **蒂米特雷斯库夫人** | **城堡** | **老式哥特恐怖**——追逐、密室、近身压迫；吸血鬼式"需血维持" |
| **唐娜·贝内文托** | **宅邸** | **全作最心理恐怖的章节**——**几乎没有战斗**；人偶 + 幻觉；把"家人与亡者"主题压到最紧 |
| **萨尔瓦多·莫罗** | **水库** | 民间传说生物恐怖（鱼怪） |
| **卡尔·海森伯格** | **工厂** | 工业恐怖 + 金属操控；"**前实验体**"身份 |

> **意义**：**四大贵族不是单纯 BOSS，是理解剧情的钥匙**——理解他们，就知道**米兰达如何用菌主控制村庄**。【已核实】

## 三、"恩赐"（Cadou）与村庄生态暗线

| 要点 | 说明 |
|------|------|
| **恩赐（Cadou）** | 米兰达创造的**寄生体**；用**村子里的人**做实验 |
| **四大领主** | 都**受了"恩赐"影响变异成怪人**，拥有超乎寻常的能力 |
| **其他村民** | 获得"恩赐"后的**残次品**——变成**狼人**等怪物 |
| **村庄本质** | **整个村子都成了米兰达的实验场**；"**村庄本身像一个封闭培养皿**" |

**证据等级：【已核实】（今日头条、18183）。**

---

## 四、公爵（Duke）的商人线

| 要点 | 说明 |
|------|------|
| **身份** | 村庄的**当地商人**（系列"武器商人"传统的延续） |
| **关键情报** | 告知伊森"**找回四个瓶子就能复活萝丝**" |
| **终局作用** | 在伊森"起死回生"后，**用马车把他送到仪式现场** |
| **神秘性** | 其身份与立场在系列中保持神秘（与《生化危机4》的商人类似） |

**证据等级：【已核实】（萌娘百科、今日头条）。**

## 五、跨作品呼应（"支线"暗线）

| 呼应 | 内容 |
|------|------|
| **与《生化危机7》** | **伊森"早就死了"的伏笔在此正式揭晓**；**伊芙琳以幻觉形态登场**点破真相；**伊芙琳只是米兰达提供给"联盟"的残次品** |
| **与《生化危机1–3》** | **安布雷拉的标志源自米兰达村庄的古老符号**；**斯宾塞曾师从米兰达**——整个系列的病毒源头被上溯至菌主与米兰达 |
| **与《生化危机5》** | **克里斯**再次成为伊森的"接应者"（与《生化危机5》中克里斯救吉尔呼应） |
| **与后续** | 16 年后的萝丝线为系列新篇留门 |

**证据等级：【已核实】（今日头条、萌娘百科）。**

## 六、"伊森已死"的伏笔闭环（本作最大支线回收）

| 阶段 | 内容 |
|------|------|
| **《生化危机7》埋线** | 伊森**断手断脚都能接回**；伊芙琳说"**你也和我一样啊**"；文档提"霉菌感染越深越能保持意识与再生" |
| **《生化危机8》揭示** | **伊森 3 年前在贝克家就被杰克杀死**；他因感染霉菌苟延残喘，**早就是行尸走肉**；**米娅一直瞒着没告诉他** |
| **表现** | 被米兰达**刺穿心脏**后仍能行动（"起死回生"） |
| **收束** | 终局因**真菌再生能力耗尽**而牺牲；**意识经菌主存活**，16 年后仍能护佑女儿 |

**证据等级：【已核实】（18183、萌娘百科）。**
