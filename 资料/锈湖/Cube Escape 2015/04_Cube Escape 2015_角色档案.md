# Cube Escape 2015 — 角色档案

> 证据标注：【已核实】多源一致；【推测】合理推断；【未明确】来源冲突或公开资料缺失。

## 一、劳拉·范德布姆（Laura Vanderboom）

| 项目 | 内容 | 证据 |
|---|---|---|
| 身份 | 本组主线核心人物；《四季》与《湖泊》的视角 | 【已核实】 |
| 身世 | 1935 年由范德布姆家族献祭仪式产生的婴儿，被**罗斯**带离锈湖（详见《根源》） | 【已核实】 |
| 年代 | 1964（春）→ 1971（夏、秋）→ 1981（冬） | 【已核实】 |
| 状态 | 精神状态在 1971 年前后急剧恶化 | 【已核实】 |
| 死亡 | 于 1981 年（《四季》冬章）已死；1971–1972 年成为戴尔调查的案件 | 【已核实】 |
| 死后 | 尸体被送到磨坊，被提取记忆方块；因乌鸦先生提取负面记忆而化为**堕落灵魂** | 【已核实】 |
| 象征 | 黑方块——她痛苦的记忆 | 【已核实】 |
| 衣着 | 黄绿碎花裙（《根源》1933 年春由罗斯换上，即劳拉后来所穿的那条） | 【已核实】 |

## 二、戴尔·范德米尔（Dale Vandermeer）

| 项目 | 内容 | 证据 |
|---|---|---|
| 身份 | 凶杀案侦探；《案件23》视角 | 【已核实】 |
| 时间 | 1971–1972 | 【已核实】 |
| 案件 | 调查劳拉·范德布姆之死 | 【已核实】 |
| 异常 | 劳拉的尸体在其调查过程中凭空消失 | 【已核实】 |
| 逮捕 | 逮捕劳拉的男友鲍勃作为嫌疑人 | 【已核实】 |
| 遭遇 | 鲍勃化为堕落灵魂并挣脱；戴尔被神秘力量送往锈湖 | 【已核实】 |
| 在锈湖 | 遇见乌鸦先生，被带到劳拉住过的木屋；发现电梯并降入湖底 | 【已核实】 |
| 被利用 | 猫头鹰先生把他送到湖边，用他制造风暴以驱动磨坊 | 【已核实】 |
| 后续 | 进入自己的记忆（《生日》）、进入剧院（《剧院》）、被合成金色方块（《洞穴》）、困于时间循环（《悖论》） | 【已核实】 |

## 三、乌鸦先生（Mr. Crow）

| 项目 | 内容 | 证据 |
|---|---|---|
| 身份 | 锈湖管理者之一；《磨坊》视角 | 【已核实】 |
| 真身 | **阿道斯·范德布姆（Aldous Vanderboom）**——威廉之弟、炼金术师（详见《根源》） | 【已核实】 |
| 上级 | **猫头鹰先生** | 【已核实】 |
| 本组任务 | 在磨坊接收劳拉尸体，提取记忆方块并喂给湖 | 【已核实】 |
| 违令 | 无视猫头鹰先生的警告，提取了劳拉的**负面记忆** | 【已核实】 |
| 后果 | 劳拉尸体化为堕落灵魂；灵魂带走哈维逃走 | 【已核实】 |
| 性格 | 对兄长威廉的执念贯穿全系列，是其多次"私自行动"的动因 | 【推测】 |

| 项目 | 内容 | 证据 |
|---|---|---|
