# 锈湖：根源（Rusty Lake: Roots）— 大事件时间线

> 证据标注：【已核实】多源一致；【推测】合理推断；【未明确】来源冲突或公开资料缺失。
> 本文件按**故事内时间正序**排列；文末附发行沿革。

---

## 一、故事内时间线

| 时间 | 事件 | 证据 |
|---|---|---|
| 1859 年 | 阿道斯与威廉兄弟**炼成长生不老药** | 【已核实】 |
| 1859 年 | 威廉先饮，**当场猝死**；阿道斯随后饮下，**长生并化为乌鸦先生** | 【已核实】 |
| 1859 年 | 阿道斯从威廉体内**取出一枚种子** | 【已核实】 |
| 1860 年 | 威廉的侄子**詹姆斯继承宅邸**，**种下种子** | 【已核实】 |
| 1860 年后 | 种子长成巨树；家族在宅邸繁衍四代 | 【已核实】 |
| 1909 年 | 阿尔伯特用**自己与艾达的细胞制造出罗斯** | 【已核实】 |
| 童年（未明年份） | 阿尔伯特陷害**弗兰克落入井中** | 【已核实】 |
| 一战期间 | 莱纳德参战 | 【已核实】 |
| **1926 年秋** | 弗兰克与阿尔伯特下象棋，弗兰克赢并将他**杀害**，**取出大脑** | 【已核实】 |
| **1927 年冬** | 弗兰克洗热水澡、修理毛发，**一缕头发被保存** | 【已核实】 |
| **1929 年秋** | 莱纳德退役归来，在院子中发现**铜怀表** | 【已核实】 |
| **1930 年冬** | 弗兰克观星发现母亲艾玛多年前的留言，取得**银怀表** | 【已核实】 |
| **1932 年秋** | 罗斯在家族墓地挖出**金怀表** | 【已核实】 |
| **1933 年春** | 弗兰克与罗斯共舞；罗斯换上黄绿碎花裙，手被划破取血 | 【已核实】 |
| **1935 年春** | 莱纳德、弗兰克、罗斯在地下室**献祭自己与家族成员的血肉** | 【已核实】 |
| **1935 年春** | 巨大的树根吸收所有养分，**产生一个婴儿** | 【已核实】 |
| **1935 年春** | 罗斯带着婴儿**离开锈湖**——婴儿即日后的**劳拉·范德布姆** | 【已核实】 |
