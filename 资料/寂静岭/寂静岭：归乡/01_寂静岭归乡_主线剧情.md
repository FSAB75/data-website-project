# 寂静岭：归乡（Silent Hill: Homecoming）主线剧情

- **作品名**：寂静岭：归乡（Silent Hill: Homecoming / サイレントヒル：ホームカミング）
- **开发商**：**Double Helix Games**
- **发售**：**2008 年**（PS3 / Xbox 360 / PC）
- **类型**：生存恐怖 / 动作冒险
- **主角**：**亚历克斯·谢泼德（Alex Shepherd）**
- **舞台**：**谢泼德峡谷（Shepherd's Glen）**——寂静岭附近的小镇
- **Metacritic**：**70**
- **定位**：系列第六作；**故事难以纳入主线时间轴**

---

## 一、作品定位与核心命题

- 本作与《骤雨》类似，**故事独立、难以融入主时间轴**；
- **核心命题**："**寂静岭惩罚你对自己说的谎言，胜过任何罪行**"——亚历克斯的**整个身份都是一个谎言**；
- 舞台从寂静岭本镇转向"**谢泼德峡谷**"——但教团的影响力延伸至此。

**证据等级：【已核实】（Respawning、Radio Times、eathealthy365）。**

---

## 二、故事背景

- **亚历克斯·谢泼德**是一名**从海外战争归来的士兵**；
- 他回到家乡**谢泼德峡谷**——发现：
  - **弟弟乔舒亚失踪**；
  - **父母态度冷淡**；
  - **小镇正在崩坏**；
- **教团的影响力延伸至此**——**谢泼德峡谷由四个家族建立，他们与"神"订立契约**：**以定期的献祭换取繁荣**。

---

## 三、章节式主线剧情

### 3.1 归乡与异变

- 亚历克斯回到被浓雾笼罩的小镇；
- 弟弟失踪、父母行为异常；
- 他开始追查真相。

### 3.2 真相：身份是谎言

| 项目 | 内容 |
|------|------|
| **他以为的** | 自己是"从海外战争归来的士兵" |
| **真相** | **他从未参过军** |
| **真实经历** | **乔舒亚在一次亚历克斯未能阻止的划船事故中溺亡后，他被送进了收容机构** |
| **幻觉** | **他所谓的军旅生涯是一种妄想** |
| **父母的冷淡** | 是**被悲痛扭曲成的指责** |

### 3.3 终局

- 终局亚历克斯面对"**羊膜（Amnion）**"——**一个怪诞的昆虫状生物，体内装着乔舒亚的尸骸**；
- **依亚历克斯接受真相还是继续否认，产生不同结局**；
- **但真正的刺痛是那个真相的揭示**。

**证据等级：【已核实】（Respawning、Radio Times、eathealthy365）。**
