# 寂静岭2（Silent Hill 2）主线剧情

- **作品名**：寂静岭2（Silent Hill 2 / サイレントヒル2）
- **开发商**：**Team Silent**（科乐美）
- **发售**：**2001 年 9 月**（日本，PlayStation 2）；扩展版 2002–2003
- **类型**：生存恐怖 / 第三人称冒险
- **主角**：**詹姆士·桑达兰德（James Sunderland）**
- **舞台**：寂静岭（托卢卡湖畔小镇、溪港医院、**湖景酒店**）
- **Metacritic**：**89**（**全系列最高**）
- **重制版**：**2024 年**由 **Bloober Team** 制作（Metacritic 86）

---

## 一、作品地位

- 《寂静岭2》被广泛认为是**全系列最优秀的作品**，也是"**生存恐怖**"类型的巅峰之一；
- 本作**剧情与前作同在寂静岭发生，但两者没有直接关系**——它是**完全独立的故事**；
- 正是这种独立性，确立了系列的"**个人创伤（personal trauma）支柱**"——**与正史邪教 lore 无关，却同样有力**；
- **三角头（Pyramid Head）**在本作中诞生，并成为系列**最具标志性的怪物**。

**证据等级：【已核实】（hackcn 中文维基、eathealthy365、framesgames）。**

---

## 二、故事背景

- **詹姆士·桑达兰德**，29 岁，公务员，个性沉默木讷但爱好轻松，深爱妻子；
- 他收到**三年前去世之妻子玛莉**的来信，信中写道："**我在与你有着共同回忆的地方等你……**"；
- 为寻求真相，詹姆士前往他与玛莉曾旅行之地——**寂静岭**。

---

## 三、章节式主线剧情

### 3.1 公园：与玛丽亚相遇

- 詹姆士在镇上探索，先后遇到：
  - **安洁拉·欧拉斯寇（Angela Orosco）**——自称寻找母亲的年轻女性；
  - **艾迪·唐柏斯基（Eddie Dombrowski）**——因体型肥胖而极度自卑、有被害妄想倾向的年轻男子；
  - **劳拉（Laura）**——与玛莉交好的**八岁女孩**；
  - **玛利亚（Maria）**——长相与玛莉**非常相似**的女性（在酒吧"天堂之夜"驻唱）。
- 玛利亚向詹姆士表示**不认识玛莉**，并因感到害怕而与他同行；
- 二人在**医院**寻找玛莉期间被怪物"**三角头（Pyramid Head）**"袭击，**只有詹姆士成功逃脱**。

### 3.2 酒店调查：玛丽亚之死

- 詹姆士决定前往他与玛莉度假之**酒店**调查；
- 路上却发现**玛利亚生还但被囚禁**，且对被袭一事没有印象；
- 詹姆士欲寻找方法救出玛利亚，但**返回后她已死去**。

### 3.3 众人的罪恶

- 詹姆士在一怪物手下救出安洁拉，获悉她**曾被父亲性侵**（镇上一则新闻剪报暗示她**自卫下杀死了父亲**）；
- 重遇艾迪后，获悉他曾**重创一名欺凌者**并**杀死了一头小狗**；
- 艾迪发动攻击，**詹姆士把他杀死**——由此他开始怀疑玛莉是否真的在三年前死了。

### 3.4 录像带：真相

- 詹姆士撑船穿过**托卢卡湖**来到**湖景酒店（Lakeview Hotel）**；
- 在那里他终于见到劳拉，并了解到：**玛莉并没有在三年前死去**，她确实和劳拉认识、**且打算收养她**；
- 他拿到玛利亚提到的**录像带**，进入他和玛莉曾经逗留过的 **312 房**；
- **透过录像带，他终于明白：患了不治之症的玛莉是在数天前被他亲手杀死的——他用枕头闷死了她**；
- 劳拉走进来，詹姆士向她承认杀了玛丽；**劳拉非常生气，哭着捶打他**，随后离开。

### 3.5 安洁拉之死

- 詹姆士决定给自己的罪孽来了断；
- 走出 312 房时，酒店变得残破不堪，雨水不停从天花板落下；
- 在楼梯间他遇到安吉拉——**原本金属的楼梯变成木制，周围一片火焰**；
- 安吉拉**因无法面对内心之罪恶而走进火炎中放弃生命**；
- 她告诉詹姆士："**我的世界一直都是一片炎热的火海。**"

### 3.6 三角头的真意

- 继续前行，詹姆士**再次见到玛利亚**——这一次她**被倒立着固定在一个铁架上，最后被两个三角头刺死**；
- 詹姆士终于明白：**三角头是詹姆士创造出来惩罚自己所犯的罪的**（他自己希望受罚之投射）；
- **在知道了真相之后，他不再需要他们了**——**两个三角头随即自尽**。

### 3.7 终局

- 詹姆士进入一条长长走廊，回荡着他和玛丽的声音（他曾带花探望玛丽，却因她的负面宣泄而生气离去，玛丽哀求他回来）；
- 他走过铁楼梯来到酒店天台，终于见到等着他的人；
- **最后，他打败了怪物化的玛丽 / 玛利亚**（视乎玩家于游戏中的决定）；
- **之后，再也没人见过他……**

## 四、结局（共 5 个 + 隐藏结局）

| 结局 | 说明 |
|------|------|
| **投湖（In Water）** | 詹姆士直面自己杀害玛丽的事实；**驾车载着玛丽的遗体投湖** |
| **玛利亚（Maria）** | 詹姆士选择与玛利亚离开；**沉溺于自己幻想出的完美爱人**（彩蛋暗示悲剧循环） |
| **离开（Leave）** | 詹姆士放下愧疚与幻想；**带劳拉一起离开**，承担照顾她的责任——最光明的结局 |
| **UFO 结局** | 恶搞向隐藏结局——**詹姆士被外星人抓走**，寂静岭的怪物都是外星人实验品 |
| **狗结局（Dog）** | 恶搞向隐藏结局——**整个事件都是一只狗操控的** |

## 六、主要角色一览

| 角色 | 身份 | 作用 |

| **詹姆士·桑达兰德** | 主角；29 岁公务员 | 收到亡妻来信；最终发现自己**亲手闷死了病危的玛莉** |
