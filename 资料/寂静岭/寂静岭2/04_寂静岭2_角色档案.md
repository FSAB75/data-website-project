# 04 寂静岭2 角色档案

> 对应游戏：《寂静岭2》（2001，系列第 2 部）
> 收录范围：**主角夫妇** + **四位遭遇者** + **三角头**。
> 说明：本作角色**与正史邪教线无关**，是"**个人创伤**"支柱的载体——**每个角色的怪物都是其精神世界的具现**。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、主角

### 1.1 詹姆士·桑达兰德（James Sunderland）

| 项目 | 内容 |
|------|------|
| 身份 | **本作主角**；29 岁公务员 |
| 性格 | 个性沉默木讷但爱好轻松，**深爱玛莉** |
| 起点 | 收到 3 年前病逝妻子玛莉的来信，造访回忆之地寂静岭 |
| 罪行 | **亲手闷死了病危的玛莉**（患不治之症的她）——通过 312 房录像带揭示 |
| 自我惩罚 | **创造出三角头**来惩罚自己所犯的罪（他自己"希望受罚之投射"） |
| 终局 | 天台击败怪物化的玛丽 / 玛利亚；**之后，再也没人见过他** |

**证据等级：【已核实】（中文维基、百度百科、eathealthy365）。**

### 1.2 玛莉·雪帕·桑达兰德（Mary Shepherd-Sunderland）

| 项目 | 内容 |
|------|------|
| 身份 | 詹姆士之妻；25 岁；个性沉静温柔的贤妻良母 |
| 经历 | 与丈夫从寂静岭旅游回来后**身体日渐不适**；在"溪港医院"认识劳拉 |
| "死亡"真相 | **并未在三年前死去**——**数天前被詹姆士用枕头闷死**；且**打算收养劳拉** |
| 情绪爆发 | 曾因得知自己活不久而把负面情绪发泄到詹姆士身上，说了难听的话要他滚；后**哀求他回来安慰她** |
| 终局 | 化为怪物（或由玛利亚代行），被詹姆士击败 |

**证据等级：【已核实】（中文维基、百度百科）。**

---

## 二、玛利亚（Maria）

| 项目 | 内容 |
|------|------|
| 身份 | 詹姆士在寂静岭公园遇到的女性；26 岁；在酒吧"**天堂之夜**"驻唱 |
| 外貌 | **长相与玛莉十分神似** |
| 关键差异 | 具有**玛莉自患病后失去的性感及大方** |
| 本质 | **詹姆士幻想的产物**（扩展版《Born from a Wish》补完） |
| 经历 | 多次"死亡"——医院被三角头袭击、被囚禁后死去、**被倒立固定于铁架上被两只三角头刺死** |
| 终局 | 化为怪物被詹姆士击败（"玛利亚"结局中与他离开） |

**证据等级：【已核实】（中文维基、Wikiwand）。**

---

## 三、其他遭遇者

### 3.1 安洁拉·欧拉斯寇（Angela Orosco）

| 项目 | 内容 |
|------|------|
| 身份 | **自称寻找母亲**而来的年轻女性 |
| 创伤 | **曾被父亲性侵**（镇上一则新闻剪报暗示她**自卫下杀死了父亲**） |
| 结局 | **因无法面对内心之罪恶而走进火炎中放弃生命**；她告诉詹姆士："**我的世界一直都是一片炎热的火海**" |

**证据等级：【已核实】（中文维基、百度百科）。**

### 3.2 艾迪·唐柏斯基（Eddie Dombrowski）

| 项目 | 内容 |
|------|------|
| 身份 | **因体型肥胖而极度自卑、有被害妄想倾向**的年轻男子 |
| 罪行 | 从小因肥胖被嘲笑欺负；有一天**忍无可忍开枪杀了一个橄榄球运动员的狗，再打伤狗主的膝盖**，然后逃出 |
| 信念 | "既然我们两人都被寂静岭召唤到了这里，那么我们就是同一类人" |
| 结局 | 对詹姆士发动攻击，**被詹姆士杀死** |

**证据等级：【已核实】（中文维基、百度百科）。**

### 3.3 劳拉（Laura）

| 项目 | 内容 |
|------|------|
| 身份 | **与玛莉交好的八岁女孩** |
| 特殊性 | **唯一知道"玛莉没有死"的人**——玛莉确实和她认识、且打算收养她 |
| 行动 | 对詹姆士杀玛丽**非常生气，哭着捶打他**，随后离开 |
| 结局关联 | "**离开**"结局中詹姆士**带她一起离开**，承担照顾责任 |

**证据等级：【已核实】（中文维基、百度百科）。**

## 四、三角头（Pyramid Head）

| 项目 | 内容 |
|------|------|
| 身份 | 怪物；**本作诞生的系列标志性存在** |
| **本质** | **詹姆士"希望受罚之投射"**——为惩罚他的罪孽而生 |
| 行为 | 追杀 / 刺死玛利亚；**两只三角头在詹姆士明了真相后随即自尽** |
| 系列地位 | 被视为"**系列心理恐怖的完美具现**"——**他不是随机怪物，而是詹姆士 psyche 的专属折磨者** |

**证据等级：【已核实】（中文维基、eathealthy365）。**
