# 02 破碎记忆 支线剧情

> 对应游戏：《寂静岭：破碎记忆》（2009，系列再构作）
> 说明：本作的"支线"主要体现为**心理治疗选择改变人格 / 环境**、**多周目差异**、**"无法对抗的恐怖"设计**与**非主线定位**。本文件与 `01_破碎记忆_主线剧情.md` 互补。

---

## 一、心理治疗选择系统（本作"支线"核心）

| 项目 | 说明 |
|------|------|
| **形式** | 章节之间穿插**心理治疗（therapy sessions）**环节 |
| **效果 1** | **环境会改变** |
| **效果 2** | **哈利的性格也会有所变化** |
| **本质** | 一套**对玩家进行心理侧写（psychologically profiling the player）**的系统 |

**证据等级：【已核实】（Wikiwand、Radio Times）。**

---

## 二、多周目差异（本作重玩价值）

| 项目 | 说明 |
|------|------|
| **核心** | **每次游玩都会改变雪柔记忆中的父亲**——无论是**奉献的父亲**、**有缺陷的男人**，还是**完全缺席的人** |
| **叙事层** | 玩家既是"操控哈利"，也在**参与雪柔的记忆重构** |

**证据等级：【已核实】（Respawning）。**

---

## 三、"无法对抗的恐怖"（设计理念）

| 项目 | 说明 |
|------|------|
| **系列主题** | 本作主题为"**无法对抗的恐怖**" |
| **机制** | **玩家控制的主角不能作出任何攻击，只能不断地逃避怪物们的追逐** |
| **转向** | **《寂静岭》被剥离了战斗**——转而聚焦**故事、追逐段落与心理学** |
| **与前作的差异** | 前作以"浓雾 + 铁管 + 收音机"为核心；本作以"冰雪 + 逃亡 + 治疗"为核心 |

**证据等级：【已核实】（Wikiwand、Respawning、Radio Times）。**

---

## 四、非主线定位

| 项目 | 说明 |
|------|------|
| **性质** | **1 代的"再构"（reimagining）** |
| **时间轴** | **不属于游戏的主时间轴** |
| **影响** | 但其改动"**对 1 代与 3 代的事件有重大影响**" |
| **评价** | Radio Times 认为"**因其剧情值得提及**" |

**证据等级：【已核实】（Radio Times、Wikiwand）。**

## 五、与 1 代的关系对照

| 维度 | 《寂静岭1》（1999） | 《破碎记忆》（2009） |
|------|-------------------|---------------------|
| **主角** | 哈利·梅森 | 哈利·梅森（同名） |
| **舞台氛围** | 浓雾、铁锈 | **冰雪覆盖** |
| **战斗** | 有（铁管等） | **无——只能逃避** |
| **核心机制** | 收音机杂音预警 | **心理治疗侧写玩家** |
| **真相** | 雪柔 = 阿蕾莎的另一半 | **哈利早已死于车祸；一切是成年雪柔的重构** |

**证据等级：【已核实】（Wikipedia、Wikiwand、Respawning）。**
