# 04 破碎记忆 角色档案

> 对应游戏：《寂静岭：破碎记忆》（2009，系列再构作）
> 收录范围：**哈利·梅森** + **雪柔**。
> 说明：本作是 1 代的"再构"，其角色**在结局被彻底颠覆**——这是理解本作的关键。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、主角（及其颠覆）

### 1.1 哈利·梅森（Harry Mason）

| 项目 | 内容 |
|------|------|
| 身份 | **本作主角**；与 1 代同名 |
| 表层 | 在冰雪寂静岭中寻找女儿**雪柔** |
| **颠覆真相** | **他在开场车祸中就已死亡——那是多年前的事** |
| **本质** | **玩家操控的哈利，是成年雪柔对父亲的重构** |
| 可变性 | **根据玩家在治疗中的选择，哈利的性格也会有所变化** |
| 多周目 | **每次游玩改变她记忆中的他**——**奉献的父亲 / 有缺陷的男人 / 完全缺席的人** |

**证据等级：【已核实】（Respawning、Wikiwand）。**

---

## 二、雪柔（Cheryl）

| 项目 | 内容 |
|------|------|
| 身份 | 哈利的女儿 |
| 表层 | 被寻找的对象 |
| **颠覆真相** | **治疗的接受者其实是成年的她** |
| **行为** | 她在**努力接受父亲之死**——**玩家玩的游戏就是她的记忆重构** |
| 多周目差异 | **每次游玩，她记忆中的父亲都不同** |

**证据等级：【已核实】（Respawning、Wikiwand）。**

---

## 三、核心命题

> "**它之所以毁灭性，是因为怪物不是邪教、不是杀手。它就是悲伤本身（It is grief itself）。**"

**证据等级：【已核实】（Respawning）。**
