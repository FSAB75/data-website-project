# 04 寂静岭3 角色档案

> 对应游戏：《寂静岭3》（2003，系列第 3 部）
> 收录范围：**主角海瑟** + **教团阵营** + **盟友**。
> 说明：本作是 1 代的直接续作，核心主题是"**身份**"——海瑟选择作为自己而活。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、主角

### 1.1 海瑟（Heather Mason）

| 项目 | 内容 |
|------|------|
| 身份 | **本作主角**；**阿蕾莎的转世**（1 代中雪柔长大后） |
| 成长 | **哈利·梅森把她当作自己的女儿养大** |
| 本作 | **被引诱回寂静岭**；试图**彻底阻止教团** |
| 关键行动 | 使用**阿格劳菲提斯（aglaophotis）****强迫自己吐出在体内生长的"神"**，**夺走了克劳迪亚的计划** |
| 终局 | **杀死了那生物**；与道格拉斯一同**带着伤痕但未被击倒地离开** |
| **核心主题** | "**选择作为自己而活，而不是作为邪教的容器**"——这使她的胜利更具力量 |

**证据等级：【已核实】（Wikipedia、Radio Times、Respawning）。**

## 二、教团阵营

| 项目 | 内容 |
|------|------|
| 身份 | **教团重建者**；本作主要反派 |
| 行动 | **1 代后重建了教团**；企图借海瑟（完美容器）复活"神" |
| 结局 | 计划被海瑟夺走后，**被信仰吞噬，将"神"纳入自己体内，在诞下它时死去** |
