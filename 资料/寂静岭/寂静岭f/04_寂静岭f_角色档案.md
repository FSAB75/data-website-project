## 一、主要角色

### 深水雏子（Shimizu Hinako）

| 项目 | 内容 | 证据 |
|---|---|---|
| 身份 | 本作主角；居于日本乡村小镇戎之丘的高中生 | 【已核实】 |
| 配音 | 日语：加藤小夏（Konatsu Kato）；英语：Suzie Yeung | 【已核实】 |
| 家庭 | 与父母及姐姐顺子同住；母亲对施虐的父亲逆来顺受，姐姐婚后离家 | 【已核实】 |
| 心结 | 憎恨父母——恨母亲的顺从，恨父亲的暴虐 | 【已核实】 |
| 恐惧 | 恐惧"长大成人"与"结婚" | 【已核实】 |
| 友人 | 修、凛子、咲子 | 【已核实】 |
| 药物 | 修给她红色胶囊以缓解剧烈的紧张性头痛 | 【已核实】 |
| 异变 | 与父母争吵后与友人会合；白无垢怪物现身，戎之丘被浓雾与红色彼岸花吞没，咲子死亡 | 【已核实】 |
| 暗神社 | 失去意识后于暗神社醒来，遇见狐面；附身其童年人偶的灵体不断警告她不要相信狐面 | 【已核实】 |
| 三场仪式 | ①右臂被切断换上狐臂 ②背部被烙铁烙印 ③上半张脸被削去换上狐面 | 【已核实】 |
| 劝诱 | 狐面说服她杀死修、凛子、咲子以"放下童年" | 【已核实】 |
| 自我分裂 | "戎之丘的雏子"（人之自我）与"暗神社的雏子"（狐之自我）合流：狐之自我以白无垢之姿杀死父母，人之自我寻求复仇 | 【已核实】 |
| 结局 | 共 5 种；首周目固定为"归巢"——揭示全作实为红色胶囊诱发的精神病性发作，真实的她是 20 多岁、因在自己的婚礼上杀死数人而逃亡的女性 | 【已核实】 |
