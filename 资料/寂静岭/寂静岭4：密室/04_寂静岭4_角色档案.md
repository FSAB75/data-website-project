# 04 寂静岭4 角色档案

> 对应游戏：《寂静岭4：密室》（2004，系列第 4 部）
> 收录范围：**主角** + **反派** + **关键邻居**。
> 说明：本作是 Team Silent 的最后一部作品，核心命题是"**如果你的家背叛了你，你还剩哪里可去？**"
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、主角

### 1.1 亨利·汤森（Henry Townshend）

| 项目 | 内容 |
|------|------|
| 身份 | **本作主角**；**302 室住户** |
| 处境 | **发现自己被锁在自己的公寓里**——门从内被链条锁住、窗户封死 |
| 行动 | 通过**浴室墙上的洞**进入异世界；在公寓闹鬼中求生 |
| 核心 | 大量围绕"**保住邻居艾琳的性命**"展开 |
| 结局 | 依"是否保护艾琳、是否净化房间"分歧 |

**证据等级：【已核实】（Wikipedia、Respawning）。**

---

## 二、反派

### 2.1 沃尔特·沙利文（Walter Sullivan）

| 项目 | 内容 |
|------|------|
| 身份 | **连环杀手**；本作反派 |
| 仪式 | 执行"**21 圣礼（21 Sacraments）**"仪式 |
| **核心动机** | 对沃尔特而言，**302 室就是他的"母亲"**——因为他**在这栋楼里出生、随后被遗弃**；他相信**杀死 21 名受害者就能与"母亲"重聚** |
| 背景 | **被教团抚养长大的孤儿** |
| 能力 | 他的"**异世界**"**并非源自小镇本身，而是从他的公寓向外投射** |
| 结局 | 被阻止，或**完成仪式**（依玩家行为） |

**证据等级：【已核实】（Respawning、eathealthy365、Wikipedia）。**

## 五、角色关系速览

```
南灰原公寓 302 室
   │
   ├── 亨利·汤森（主角，被困其中）
   │        └─ 唯一出口：浴室墙洞 → 异世界投影
   │
   ├── 艾琳·高尔文（邻居；最后的预定牺牲者之一）
   │        └─ 其生死影响结局
   │
   └── 沃尔特·沙利文（连环杀手；被教团抚养的孤儿）
            ├─ 302 室被他视为"母亲"（他出生于此并被遗弃）
            ├─ 相信"杀死 21 名受害者就能与母亲重聚"
            └─ 异世界从公寓向外投射
```
