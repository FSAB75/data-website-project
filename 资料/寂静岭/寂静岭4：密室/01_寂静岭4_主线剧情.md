# 寂静岭4：密室（Silent Hill 4: The Room）主线剧情

- **作品名**：寂静岭4：密室（Silent Hill 4: The Room / サイレントヒル4：ザ・ルーム）
- **开发商**：**Team Silent**（科乐美）
- **发售**：**2004 年**（PS2 / Xbox / Microsoft Windows）
- **类型**：生存恐怖 / 第一人称与第三人称混合冒险
- **主角**：**亨利·汤森（Henry Townshend）**
- **舞台**：**302 室**（南灰原公寓）及其"异世界"投影
- **Metacritic**：76
- **系列地位**：**标志着 Team Silent 在系列工作的终结**

---

## 一、作品地位与核心命题

- 本作是系列第四作，**标志着 Team Silent 在系列上工作的终结**；
- **核心命题**："**如果你的家背叛了你，你还剩哪里可去？**"——**把"家"变成恐怖**；
- 与前作最大的不同：**亨利并非在寂静岭的街道上探索——他被困在自己的公寓里**；
- 本作**在粉丝中评价分化**，但它捕捉到一种**普遍的恐惧**。

**证据等级：【已核实】（Wikipedia、Respawning）。**

---

## 二、故事背景

- **亨利·汤森**发现自己**被锁在自己的公寓（302 室）里**；
- **门从里面被链条锁住**，**窗户被封死**；
- 奇怪的异象开始在**他与其他住户**周围展开；
- **唯一的出口是浴室墙上的一个洞**——通往附近各地的扭曲版本。

---

## 三、章节式主线剧情

### 3.1 被困与异世界

- 亨利无法离开 302 室；
- 浴室墙上的洞成为通往"**异世界**"的入口——那是对附近地点（森林、学校、医院、监狱、水上世界等）的扭曲镜像。

### 3.2 沃尔特·沙利文与"21 圣礼"

| 项目 | 内容 |
|------|------|
| **反派** | **沃尔特·沙利文（Walter Sullivan）**——**连环杀手** |
| **仪式** | 执行"**21 圣礼（21 Sacraments）**"仪式 |
| **动机** | 对沃尔特而言，**302 室就是他的"母亲"**——因为他**在这栋楼里出生、随后被遗弃**；他相信**杀死 21 名受害者就能与"母亲"重聚** |
| **背景** | 沃尔特是**被教团抚养长大的孤儿**；他的"异世界"**并非源自小镇本身，而是从他的公寓向外投射** |
| **威胁** | 亨利的邻居**艾琳·高尔文（Eileen Galvin）**是**最后的预定牺牲者之一**；故事大量围绕"**在公寓闹鬼中求生并保住她的性命**"展开 |

### 3.3 结局

- **依玩家是否保护艾琳、是否净化房间**，产生不同结局：
  - **阻止沃尔特**；或
  - **看着他完成仪式**。

**证据等级：【已核实】（Wikipedia、Respawning）。**

## 四、核心设定的独创性

| 设定 | 说明 |
|------|------|
| **"家"即地狱** | "**你应该感到安全的地方，变得越来越糟**——幽灵般的人影、血迹、墙壁中传来的低语" |
| **异世界的新形态** | 沃尔特的异世界**不系于小镇，而是从公寓向外投射**——探索"**教团的影响力如何在镇界之外创造恐怖**" |
| **21 圣礼** | 以数字仪式构建的连环杀局 |
