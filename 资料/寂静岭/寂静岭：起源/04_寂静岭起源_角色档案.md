## 一、主角

### 1.1 特拉维斯·格雷迪（Travis Grady）

| 项目 | 内容 |
|------|------|
| 身份 | **本作主角**；**卡车司机** |
| 善举 | 在看到**一栋燃烧房屋中的女孩**后停下，**救出了她** |
| 代价 | **那个女孩就是阿蕾莎**——**通过救她，特拉维斯踏入了邪教之网**；**被困于寂静岭** |
| 行动 | 为查明那女孩的命运而 quest；探索**疗养院、剧院、汽车旅馆**；**翻转镜子**切换世界 |
| 遭遇 | 途中**遭遇 1 代中的角色** |
| 内心 | **被迫面对自己的过去**——包括**受虐待的父母**的记忆 |
| 结局 | **活着离开了小镇，但留下了伤痕** |
| **系列主题注脚** | "**寂静岭从不让善行不受惩罚**"——"**它有一种方式，会把任何敢于关心他人的人拉进来**" |

**证据等级：【已核实】（Wikipedia、Respawning）。**
