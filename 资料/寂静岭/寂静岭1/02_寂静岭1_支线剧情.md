# 02 寂静岭1 支线剧情

> 对应游戏：《寂静岭》（1999，系列第 1 部）
> 说明：本作的"支线"主要体现为**多结局分歧**、**隐藏结局（UFO 结局）**、**跨作品前传补完**与**系列通用的心理恐怖叙事手法**。本文件与 `01_寂静岭1_主线剧情.md` 互补。

## 一、多结局（本作"支线"核心）

| 项目 | 说明 |
|------|------|
| **机制** | **依玩家在游戏中的行为产生多个结局** |

## 二、UFO 结局（系列传统恶搞）

- 《寂静岭》系列的著名隐藏结局传统——以 **UFO** 乱入收场；
- 《寂静岭2》的扩展版亦追加了一个"**俗称的 UFO 结局**"；
- 属**非正史的娱乐性内容**，但已是系列标志性彩蛋。

**证据等级：【已核实】（Wikiwand）。**

## 三、前传补完（《起源》的支线意义）

| 补完项 | 内容 |
|--------|------|
| **时间** | 本作事件**前 7 年** |
| **核心** | **教团首次尝试"诞神"**；**阿蕾莎分裂灵魂创造出雪柔** |
| **意义** | 解释"雪柔是谁""阿蕾莎是谁"——本作最大的未解之谜 |
| **建议** | **按发行顺序游玩**（先 1 代后起源），以保留神秘感与冲击力 |

**证据等级：【已核实】（eathealthy365、IMDb）。**

## 四、阅读 lore 的正确方式（eathealthy365 的系列忠告）

| 忠告 | 说明 |
|------|------|
| **按发行顺序而非时间顺序** | 开发者意图让玩家"**按 lore 被揭示的顺序了解它**"——先玩 1 代再玩起源，能保留阿蕾莎故事的冲击力 |
| **读遍每一份备忘录与文件** | "**这是我的第一条建议**。过场动画给你剧情，**游戏内文档给你 lore**——真相总是藏在报纸剪贴、日记和医疗报告里" |
| **不要以为所有怪物含义相同** | "**我一开始以为'护士'只是'护士'。错了**"——怪物的设计、行为与位置都在揭示主角**破碎的精神世界** |
| **把暧昧当作特性** | "**lore 不是有唯一解的数学题**。开发者刻意留下许多开放解读——恐怖来自未知，完整 Definitive 解释会剥夺系列的力量" |
| **注意音乐与音效** | 山冈晃的音效设计是叙事的核心部分——**警告危险的收音机杂音、异世界的工业轰鸣，不只是背景音，而是小镇自己的声音** |

**证据等级：【已核实】（eathealthy365）。**

## 五、系列标志性机制（本作确立）

| 机制 | 说明 |
|------|------|
| **浓雾** | 探索受限；由硬件限制转化为风格 |
| **手电筒** | 探索必需，但**光也可能引来怪物**；有时**关灯"暗杀"**很重要 |
| **铁管** | 系列**象征性近战武器**——威力偏低但**距离长、易用** |
| **收音机杂音** | 敌人接近时发出静电噪音（系列标志性预警） |
| **异世界（Otherworld）** | **由小镇灵力创造的个性化交替现实**——将特定人的潜意识思维、恐惧与罪恶感具现化 |

**证据等级：【已核实】（Wikiwand、framesgames、eathealthy365）。**
