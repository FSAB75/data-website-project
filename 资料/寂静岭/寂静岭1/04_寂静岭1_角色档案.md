# 04 寂静岭1 角色档案

> 对应游戏：《寂静岭》（1999，系列第 1 部）
> 收录范围：**主角父女** + **同伴** + **教团阵营**。
> 说明：本作角色是"**寂静岭正史邪教线**"的核心班底，其真相多由《起源》与《寂静岭3》补完。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、主角

### 1.1 哈利·梅森（Harry Mason）

| 项目 | 内容 |
|------|------|
| 身份 | **本作主角**；雪柔的**养父** |
| 经历 | 休假时与养女开车前往寂静岭度假；深夜为闪避**突然出现的少女**而出车祸、失去意识 |
| 行动 | 醒来发现雪柔失踪，**在浓雾笼罩的小镇中四处寻找** |
| 真相 | 发现小镇是**邪教"教团"的据点**，教团企图**复活其崇拜的神**；并发现**雪柔的真实出身** |
| 结局 | **见证并击败了教团催生的"不成熟的神"**；依玩家行为产生**多个结局** |
| 后续 | 《寂静岭3》（17 年后）中他已逝；其女海瑟继承其意志 |

**证据等级：【已核实】（Wikipedia、Wikiwand）。**

### 1.2 雪柔·梅森（Cheryl Mason）

| 项目 | 内容 |
|------|------|
| 身份 | 哈利的**养女**；本作"被寻找的人" |
| **核心真相** | **她与阿蕾莎是同一灵魂的两半** |
| 起源 | 由**阿蕾莎分裂灵魂以自保**而创造（详见《寂静岭：起源》） |
| 后续 | 《寂静岭3》中**转世为海瑟（Heather）** |

**证据等级：【已核实】（eathealthy365、Wikipedia）。**
