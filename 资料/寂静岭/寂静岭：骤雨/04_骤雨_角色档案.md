# 寂静岭：骤雨（Silent Hill: Downpour）— 角色档案

> 证据标注：【已核实】多源一致；【推测】合理推断；【未明确】来源冲突或公开资料缺失。

## 一、主要角色

### 墨菲·潘道顿（Murphy Pendleton）

| 项目 | 内容 | 证据 |
|---|---|---|
| 身份 | 本作主角；囚犯编号 RS 273A | 【已核实】 |
| 前史 | 普通父亲，与妻子育有一子查理（Charlie） | 【已核实】 |
| 丧子 | 儿子查理被邻居、恋童癖帕特里克·奈培猥亵并杀害 | 【已核实】 |
| 入狱 | 凶手虽已入狱，墨菲仍无法释怀；故意犯罪（偷警车并长时间被警方追捕）入狱以接近奈培 | 【已核实】 |
| 交易 | 惩戒官乔治·休厄尔提出交易：帮他"处理"一名同僚，便安排墨菲与奈培独处 | 【已核实】 |
| 复仇 | 墨菲在淋浴间杀死奈培——他认为此人罪有应得 | 【已核实】 |
| 真正的罪 | 交易的第二部分：他将正直的惩戒官弗兰克·柯勒律治打得几乎致死；这段记忆被他自我封存 | 【已核实】 |
| 事故 | 转监途中囚车翻覆，醒来身处寂静岭 | 【已核实】 |
| 结局 | 依玩家选择共 6 种；官方向结局（Truth and Justice）中真相大白——最后一刻是休厄尔动手，墨菲被构陷 | 【已核实】 |
| 主题意义 | 寂静岭对墨菲是"审判场"：他必须直面被自己压抑的罪，而非他人的罪 | 【已核实】 |

### 安妮·柯勒律治 / 安妮·坎宁安（Anne Coleridge / Anne Cunningham）

| 项目 | 内容 | 证据 |
|---|---|---|
| 身份 | 负责本次转监的女惩戒官；囚车事故后同样生还 | 【已核实】 |
| 真实身份 | 弗兰克·柯勒律治的女儿 | 【已核实】 |
| 动机 | 认定墨菲是杀害父亲的凶手，一手安排转监，欲让墨菲进入自己管辖的监狱"处理"他 | 【已核实】 |
| 首次对峙 | 在寂静岭试图指控并射杀墨菲，但无法扣下扳机，放他离开 | 【已核实】 |
| 二次冲突 | 在墨菲启动快艇准备离开时现身开火 | 【已核实】 |
| 真相时刻 | 在里世界揭示：其父被墨菲袭击后成为植物人，靠轮椅与维生系统维持数年后死去 | 【已核实】 |
| 结局 | 依选择被墨菲杀死、杀死墨菲、或原谅墨菲并放其自由 | 【已核实】 |
| 备注 | 姓氏在来源中有 Coleridge 与 Cunningham 两说，本资料库并列标注 | 【未明确】 |

|---|---|---|

## 四、主题与人物设计
