# 03 宽恕我神父1 游戏内全部档案

> 对应游戏：《宽恕我神父》（Forgive Me Father, Byte Barrel）
> 收集体系：本作的核心叙事载体为**带 "story" 标签的文档与照片**；经典 FPS 的**彩色钥匙**、**秘密武器**；以及**经验值 / 技能树**成长系统。
> 数据说明：整理自 Wikipedia、Steam 官方页与多家评测；**未逐字转录**游戏内文本。

## 一、档案（收集）体系说明

| 收集类型 | 说明 |
|---------|------|
| **文档 / 照片（Documents & Photographs）** | 散布关卡中、带 **"story" 标签**的可选阅读物——**本作最主要的剧情收集品** |

## 三、武器清单与升级

### 3.1 常规枪械

| 武器 | 说明 |
|------|------|
| **左轮手枪（Revolver）** | 高伤害、首发精准；连射会失准、装填较慢 |
| **手枪（Pistol）** | 射速快、装填更快、精度好 |
| **冲锋枪（Machine Gun）** | 高射速杀伤机器，弹药不便宜 |
| **霰弹枪（Shotgun）** | 威力极强、近战极其有效 |
| **步枪 / 汤姆逊（Thompson）** | 常规枪械阵容成员 |
| **鱼叉枪（Harpoon Gun）** | 可升级为**多箭矢弩（multi-shot crossbow）** |
| **突击步枪（Assault Rifle）** | 可升级为**发射爆炸弹** |
| **闪电枪（Lightning Gun）** | 超自然枪械 |
| **外星火箭筒（Alien Rocket Launcher）** | 极具"异星感"的重武器 |

### 3.2 超自然 / 特殊武器

| 武器 | 说明 |
|------|------|
| **匕首（Knife）** | 灌注**黑暗恶魔触须**的投掷刀；用于处决弱小或受伤敌人并节省弹药 |

**证据等级：【已核实】（Wikipedia、junegloom3d、Big Boss Battle、Steam 商店页）。**

> 说明：部分武器**依所选主角而异**（如女记者的相机、神父的圣水/十字架）；不同来源对武器命名的译法不一，本表保留英文原名以便核对。

## 四、技能树与升级分支

| 项目 | 说明 |
|------|------|
| **技能点来源** | 击杀敌人 + 发现秘密 |
| **可升级项** | **武器**、**被动与主动能力**、**生命 / 护甲 / 移速**、**经验获取速度**、**照明用的油灯** |
| **互斥分支** | 每把武器常面临"**无聊但直白的常规升级**" vs "**把武器改装为异星弹药的古怪升级**"的二选一 |
| **代价权衡** | 有的分支是"更强的武器变体但弹药掉落更稀少"；有的是"总弹药量 / 生命 / 护甲的被动加成" |

**证据等级：【已核实】（GamingDeputy、GameBlur）。**

## 五、疯狂值（Madness）系统

| 项目 | 说明 |
|------|------|
| **积累方式** | **击杀敌人**、**饮酒** |
| **效果** | 画面**转为灰度（除红色外色彩尽失）**；获得**伤害与防御增益**；提供更多能力使用次数 |
| **风险** | 同时产生**干扰性视觉特效**；持续不击杀则**计量表回落** |
| **性质** | 本质是"**不断消耗的连击计量表**"——奖励激进打法 |

**证据等级：【已核实】（Wikipedia、GameBlur、Big Boss Battle）。**

## 六、敌人图鉴（敌人即"收集"的一部分）

| 敌人类型 | 特征 |
|---------|------|
| **丧尸镇民（Zombified townsfolk）** | **携带断头**——若被爆头，会把手中的头接回脖子（除非先打掉它手中的头） |
| **断肢仍能爬行的丧尸** | 重伤后仍会爬行，持续构成威胁 |
| **触手士兵（Tentacle-sprouting soldiers）** | 长出触持的人形敌人 |
| **甲壳 / 人形混种（Crustacean-human hybrids）** | 其中包括**巨大蟹怪** |
| **邪教徒（Cultists）** | 含**传送型**——会瞬移到玩家身后，极难应付 |
| **恶魔（Demons）** | 常规地狱系敌人 |
| **炸药桶模仿者** | 伪装成炸药桶并向玩家冲锋的敌人 |

**证据等级：【已核实】（Wikipedia、Big Boss Battle、GameBlur）。**
