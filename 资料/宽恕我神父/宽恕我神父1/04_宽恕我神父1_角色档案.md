# 04 宽恕我神父1 角色档案

> 对应游戏：《宽恕我神父》（Forgive Me Father, Byte Barrel）
> 收录范围：**可玩主角** + **剧情关键人物** + **首领**。
> 说明：本作角色数量不多，但每个角色的"能力定位"即是其角色定位。本文件聚焦已公开信息的角色。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、可玩主角

### 1.1 神父（The Priest）

| 项目 | 内容 |
|------|------|
| 身份 | 可玩主角之一；与**佩斯提斯维尔有渊源** |
| 定位 | 擅长**一对一**遭遇战；**防御与攻击更高** |
| 弱点 | **易被人海淹没**（群体战吃力） |
| 专属能力 | **十字架**（回复生命）、**死灵之书（Necronomicon）**（短暂无敌）、**圣水**（短时间麻痹敌人） |
| 能力评价 | 明显强于女记者——"回复是自动发生的" |

**事迹经历**：应路易斯·马丁之邀前往佩斯提斯维尔调查邪教，从住宅区一路杀至深渊，最终击败克苏鲁（而后在精神病院醒来）。**证据等级：【已核实】。**

### 1.2 女记者（The Journalist）

| 项目 | 内容 |
|------|------|
| 身份 | 可玩主角之一；**路易斯·马丁的表妹（cousin）** |
| 定位 | 更擅长**群体作战**（群体敌人处理更优） |
| 代价 | **单体威力略低**；玩家常视其为"**困难模式**" |
| 专属能力 | **相机**（震慑 / 眩晕敌人）、**爆炸巫毒娃娃（voodoo doll）**、**时间减缓** |
| 能力评价 | 需"精准命中敌人"才能触发效果，与神父的自动回复形成对比 |

**事迹经历**：与神父共享同一主线（收到表兄求助→抵达→失踪→瘟疫小镇→击败克苏鲁→精神病院醒来），但**结局依所选主角而异**。**证据等级：【已核实】。**

## 二、剧情关键人物

### 2.1 路易斯·马丁（Louis Martin）

| 项目 | 内容 |
|------|------|
| 身份 | **佩斯提斯维尔居民**；女记者的**表兄** |
| 行动 | 调查镇上新兴邪教；因**担忧自身性命**而**向神父 / 女记者写信求助** |
| 结局 | **失踪**——主角抵达其 1920 年代风格公寓时他已不见，随后主角即遭丧尸袭击 |

**说明**：他是整起事件的"引线人物"——正是他的求助信把主角带入了佩斯提斯维尔。**证据等级：【已核实】。**

### 2.2 镇上邪教的关键人物（背景）

- 据 CheatCC 概述："**数十年前，镇上若干关键人物聚集，播下了一尊伟大而恐怖之物苏醒的种子**"；
- 这些人最终导致了**邪教的形成**与一系列离奇惨剧；
- **具体姓名与身份**在公开来源中未完整收录——本文件不臆造。【未明确】

## 三、首领（Boss）档案

| # | 首领 | 世界 | 形象与能力 |
|---|------|------|-----------|
| 1 | **巨型愤怒触手怪** | 第 1 世界 | 占据整面墙的巨型存在；闪避其攻击并射击"丑陋大脸" |
| 2 | **黄衣之王（Hastur）的仿者** | 第 2 世界 | **全作最难**；护盾由**水晶**维持（水晶**会再生**）；身边有源源不绝的"**黄衣教士（Yellow Priests）**"；后期生成**疼痛能量墙**（旋转逼位，迫使玩家抉择"留在狭小空间"还是"强闯"） |
| 3 | **巨型丑鱼** | 第 3 世界 | 从水中跃出、掀起浪涌并召唤小怪；中段有**涨落岛屿**，身处水中极其危险 |
| 4 | **高速首领与克隆体** | 第 4 世界 | 阳光明媚的清晨竞技场中的**追逐战**；高速移动且会分身——被认为"**最有意思**"的一场 |
| 5 | **克苏鲁（Cthulhu）** | 第 5 世界 | **最终首领**；弹幕式火球波次 + 范围攻击 |

**证据等级：【已核实】（junegloom3d 对五首领战有逐场详解）。**

## 五、角色关系速览

```
表兄路易斯·马丁（调查邪教 → 写信求助 → 失踪）
        │
        ├──→ 神父（单人强、防御高、群体弱）
        │       能力：十字架 / 死灵之书(无敌) / 圣水(麻痹)
        │
        └──→ 女记者（群体强、单体弱 = 困难模式）
                能力：相机(震慑) / 爆炸巫毒娃娃 / 时间减缓

主线终点：深渊 → 击败克苏鲁 → 精神病院醒来（一切都是幻觉）
```
