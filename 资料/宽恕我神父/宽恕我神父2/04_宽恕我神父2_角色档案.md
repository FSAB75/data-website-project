# 04 宽恕我神父2 角色档案

> 对应游戏：《宽恕我神父2》（Forgive Me Father 2, Byte Barrel）
> 收录范围：**主角** + **最终首领与幕后** + **敌人谱系**。
> 说明：本作**主角固定为神父**（第 1 作的女记者未登场）。角色数量精简，但主角的背景被大幅深化。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、主角

### 1.1 神父（The Priest）

| 项目 | 内容 |
|------|------|
| 身份 | **本作唯一主角**；一战退伍军人；精神病院病患 |
| 外貌变化 | **已长出胡须**（自第 1 作事件后）——" asylum 里剃须刀不是常见商品" |
| 处境 | 因**被克苏鲁蛊惑而屠杀整座佩斯提斯维尔**，被送进精神病院 |
| 叙事功能 | 每一层关卡环境都是**他本人扭曲的记忆倒影**；沙哑独白是主要叙事载体 |
| 主题 | **战争创伤（PTSD）**、信仰崩塌、自我宽恕 |

**事迹经历**：从病院枢纽出发，穿过**扭曲的记忆之地**（大学、大教堂、一战战壕、战场、宅邸、植物园、废弃地铁、噩梦之地），在前三场首领战后反复接受**道德试炼**，最终面对**克苏鲁的人形化身"疯狂边缘"**，并依其取向走向**牺牲**或**解放**两种结局之一。

**证据等级：【已核实】（TV Tropes、KeenGamer、TheXboxHub）。**

---

## 二、核心存在

### 2.1 克苏鲁（Cthulhu）

| 项目 | 内容 |
|------|------|
| 身份 | 旧日支配者；**最终幕后** |
| 在本作中的姿态 | 最终战里"**只是待在背景里**"，身边盘绕**数十条外凸触手** |
| 与主角的关系 | 曾**蛊惑神父屠杀整座小镇**（承接第 1 作结局）；其存在构成对神父心智的长期占据 |

**说明**：与前作"正面对决克苏鲁"不同，本作把克苏鲁"背景化"，交由**人形化身**承担决战——这是一种刻意的降格处理。【已核实】

### 2.2 疯狂边缘（Edge of Madness）

| 项目 | 内容 |
|------|------|
| 身份 | **克苏鲁的人形化身** |
| 定位 | **本作最终首领** |
| 战阶 | 最终 Boss 战 |

**证据等级：【已核实】（TV Tropes）。**

### 2.3 前三场首领（道德试炼的触发者）

- 每场首领战之后，神父都会面临一次**道德品性试炼**；
- 试炼的两个取向（**信赖信仰** / **让行为定义自己**）累计决定终局；
- **具体首领名称与形象**在公开来源中未完整收录，本文件不臆造。【未明确】

## 三、敌人谱系（战斗叙事的主体）

| 敌人 | 特征 |
|------|------|
| **德军士兵（German Soldiers）** | 本作**招牌敌人**；"如坦克般难以击杀"；实为披着德军制服的**邪恐怖憎体（eldritch abominations）** |
| **丧尸般杂兵** | 只会无脑冲向玩家 |
| **携带同伴残骸的食尸鬼受害者** | 扛着战友遗骸的骇人存在 |
| **重甲蛮兽（Brutes）** | 需多次命中才能击倒 |
| **还击型敌人** | 会向玩家开火 |
| **盾牌兵** | 躲在小盾后；须瞄准**狭小窗口**才能击杀 |
| **榴弹兵** | 投掷榴弹 |
| **飞行敌人** | 空中扰袭 |
| **脑叶切除患者 / 侦探** | 场景与叙事型意象 |

**证据等级：【已核实】（TheXboxHub、KeenGamer）。**

## 四、致敬对象（场景中的"无声角色"）

- 场景美术中藏有**对启发者的致敬画像**：**H·P·洛夫克拉夫特、埃德加·爱伦·坡、阿尔·卡彭**等"熟悉面孔"的肖像；
- 官方称本作是"**献给 90 年代经典射击游戏与宇宙恐怖的血腥情书**"。

**证据等级：【已核实】（KeenGamer、SaveGameVault）。**

## 五、角色关系速览

```
神父（一战老兵 / 病患 / 本作唯一主角）
   │  被克苏鲁蛊惑屠杀小镇 → 送入精神病院
   │
   ├─ 病院枢纽（休息、升级、装备变体）
   ├─ 扭曲记忆之地（大学 / 大教堂 / 战壕 / 宅邸 / 植物园 / 地铁 / 噩梦之地）
   │      └─ 前三场首领 → 三次道德试炼（信仰 vs 行为）
   │
   └─ 最终：疯狂边缘（克苏鲁人形化身）
          ├─ 结局A「牺牲」：接受信仰、拒绝腐蚀、自愿回院封印克苏鲁
          └─ 结局B「解放」：抛弃道德、拥抱腐蚀、令世界更危险
```
