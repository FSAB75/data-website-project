# 03 宽恕我神父2 游戏内全部档案

> 对应游戏：《宽恕我神父2》（Forgive Me Father 2, Byte Barrel）
> 收集体系：本作的核心收集为**武器 + 变体**、**《暗黑之典》增益**、**秘密与隐藏补给**，以及**Steam 成就**；叙事由**场景独白、传单与书籍**承载。
> 数据说明：整理自 Steam 官方页、TV Tropes、KeenGamer、TheXboxHub 等；**未逐字转录**游戏内文本。

---

## 一、档案（收集）体系说明

| 收集类型 | 说明 |
|---------|------|
| **武器（10 种）** | 近战 / 手枪 / 霰弹 / 步枪 / 爆炸 / 异星六大类 |
| **武器变体** | 每类有**更强力的变体版本**；在**枢纽解锁与装备** |
| **《暗黑之典》增益** | 可自定义最多 **3 种**增益（代价是常驻被动增益减少） |
| **疯狂技能（4 种）** | 抗性 / 疾速 / 汲血 / 威能 |
| **秘密与隐藏补给** | 各关隐藏秘藏；弹药与生命**跨关卡继承** |
| **Steam 成就** | **32 项** |
| **叙事物** | 传单、被遗忘的书籍等 |

> 与第 1 作的差异：**本作没有"story 标签文档"**的明示收集；叙事更多依赖**场景独白与环境美术**。

## 三、"活体武器"（Living Weapons）——本作视觉特色

多数续作武器由**某种异星能量驱动、看起来是活的**——在你射击时它们会自行蠕动。 notable 者包括：

| 武器 | 形象 |
|------|------|
| **血泵（Blood Pumper）** | 心脏形状的器官，外露管子与阀门以射出弹丸 |
| **永恒之鱼（Eternal Fish）** | 一条被念珠链锁住的鱼 |
| **卡拉贝尔（Calaber）** | 枪托是一只鱿鱼状生物 |
| **海葵（Anemone）** | 巨型海葵造型的炮 |
| **眼镜蛇枪（Cobber Gun）** | 由触手与眼柄构成 |
| **迫击炮（Mortar）** | 巨型鹦鹉螺壳，吐出爆炸物 |
| **方尖碑（Obelisk）** | 百度百科提及的特殊武器 |

**证据等级：【已核实】（TV Tropes、百度百科）。**

## 四、《暗黑之典》（The Dark Tome）——能力系统

| 项目 | 说明 |
|------|------|
| **定位** | 本作**唯一的" Limit Break "**（前作是多个疯狂能力） |
| **驱动** | 由屏幕底部计量条充能——**通过造成伤害（在能力之外）积累** |
| **自定义** | 在**枢纽（精神病院）**可给它最多 **3 种增益** |
| **代价** | 增益越多，**常驻被动增益越少** |
| **能力效果类型** | 大量**汲血（lifesteal）**、**伤害增益**、强力**范围攻击** |

**证据等级：【已核实】（Steam 官方页、TV Tropes）。**

## 五、疯狂技能（4 种 Madness Skills）

| 技能 | 效果 |
|------|------|
| **抗性（Resistance）** | "疯狂让你的痛楚消失"，几乎不可摧毁——大幅降低所有来源伤害 |
| **疾速（Haste）** | 让你成为宇宙中最快的枪手——大幅提升射速与装填速度 |
| **汲血（Lifesteal）** | "有了它谁还需要医疗包"——你造成的伤害按百分比治疗自身 |
| **威能（Might）** | 让你感觉空前强大——疯狂充盈你的身体与武器，造成额外伤害 |

**证据等级：【已核实】（官方新闻稿）。**

## 六、其他收集要素

| 要素 | 说明 |
|------|------|
| **手摇手电筒** | 需不时上发条；可与武器同时使用 |
| **钥匙 / 推进目标** | 每关主要目标是从 A 到 B，常需沿途收集**特殊代币（tokens）** |
| **隐藏秘藏** | 类 Doom 隐藏房；因弹药/生命跨关继承，收益被放大 |
| **补给品** | 医疗包、护甲、弹药（稀缺） |
| **"HEADSHOT" 状声字** | 爆头时屏幕弹出字样（战斗反馈彩蛋） |

**证据等级：【已核实】（TheXboxHub、KeenGamer、TV Tropes）。**
