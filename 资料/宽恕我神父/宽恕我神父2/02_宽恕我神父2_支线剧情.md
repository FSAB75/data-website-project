# 02 宽恕我神父2 支线剧情

> 对应游戏：《宽恕我神父2》（Forgive Me Father 2, Byte Barrel）
> 说明：本作是**线性流程的复古 FPS**，无"额外章节"式支线篇章；其"支线"主要体现为**双结局与道德试炼、枢纽升级、隐藏区域与可选叙事物**。本文件与 `01_宽恕我神父2_主线剧情.md` 互补。

---

## 一、双结局与道德试炼（本作核心"支线"结构）

### 1.1 机制

- 在**前三场首领战之后**，神父都会面临一次**道德品性的试炼**；
- 两个取向：
  - **信赖信仰（trust in faith）**；
  - **让行为定义自己（let deeds define him）**。
- **累计取向占比更高者，决定最终抉择**——这是**机制化的多结局**，而非单纯的分支选项。

### 1.2 两个结局

| 结局 | 判定条件 | 内容 | 性质 |
|------|---------|------|------|
| **牺牲（Sacrifice）** | 选"信赖信仰"更多 | 神父接受信仰、拒绝克苏鲁腐蚀；**自愿回到病院**把克苏鲁**困在自己心智中** | **好结局（仍苦涩）** |
| **解放（Liberation）** | 选"让行为定义自己"更多 | 神父抛弃道德、**拥抱克苏鲁的腐蚀**；仍正面迎战克苏鲁，却**令世界更危险** | **坏结局** |

- 官方对"真结局"的说明：**两个结局都不被视为绝对"真/正史"**——它们是"**同一枚虚无硬币的两面**"，共同强化"面对宇宙级存在，人类没有好下场"的主题。
- **第 2 作没有前作的女记者主角**——本作主角固定为神父。

**证据等级：【已核实】（TV Tropes 对结局机制有详细记载）。**

---

## 二、枢纽（Hub）：精神病院

- **精神病院是本作的游戏枢纽**——神父在此休息、升级能力；
- 枢纽内可进行：
  - **《暗黑之典（The Dark Tome）》**的**自定义**（最多 3 种增益，代价是被动增益减少）；
  - **武器变体的解锁与装备**。

**证据等级：【已核实】（官方商店页、TheXboxHub、TV Tropes）。**

---

## 三、隐藏区域与可选叙事

### 3.1 秘密与谜题

- 每关有**可供发现的秘密**与**小型环境谜题**；
- **隐藏的秘藏补给点**散布各关——由于**弹药与生命跨关卡继承**、回血道具稀缺，"知道去哪里找"能长期占据优势（类 Doom 隐藏房设计）。

**证据等级：【已核实】（TheXboxHub、KeenGamer）。**

### 3.2 叙事物（可选阅读）

- 关卡中可拾获**散落的传单、被遗忘的书籍**等物品以补充剧情；
- 神父的**沙哑独白**是主要的叙事载体——**每一层环境都被明确为"他本人扭曲的倒影"**。

**证据等级：【已核实】（TheXboxHub、KeenGamer）。**

### 3.3 致敬与彩蛋

- 场景美术中藏有**对 genre 启发者的致敬画像**——**洛夫克拉夫特、埃德加·爱伦·坡、阿尔·卡彭**等"熟悉面孔"的肖像"道出无声的真相"；
- 官方自述本作是"**献给 90 年代经典射击游戏与宇宙恐怖的、血腥而极富风格的情书**"。

**证据等级：【已核实】（KeenGamer、SaveGameVault）。**

## 四、疯狂（Madness）系统的支线化运用

- 本作中疯狂"**既是最大的敌人也是最好的朋友**"：
  - 累计疯狂可释放**《暗黑之典》**的强大能力（大量吸血、伤害增益、范围攻击等）；
  - **危险在于它同时是必须应对的威胁**——玩家须在"释放"与"被吞噬"之间取舍。
- **4 类疯狂技能（Madness Skills）**：抗性（Resistance，减伤）、疾速（Haste，提升射速与装填）、汲血（Lifesteal，伤害转为治疗）、威能（Might，附加伤害）。

**证据等级：【已核实】（官方商店页与新闻稿）。**

## 五、敌人谱系（战斗叙事的"支线"内容）

| 敌人类型 | 特征 |
|---------|------|
| **丧尸般杂兵（Zombie-like grunts）** | 只会无脑冲向玩家 |
| **德军士兵（German Soldiers）** | 本作**招牌敌人**；"如坦克般难以击杀"；邪恐怖憎体披着德军制服 |
| **携带同伴残骸的食尸鬼受害者** | 肩上扛着战友遗骸的骇人存在 |
| **重甲蛮兽（Brutes）** | 需要多次命中才能击倒 |
| **还击型敌人** | 会向玩家开火 |
| **盾牌兵** | 躲在小盾后，须瞄准**狭小窗口**才能击杀 |
| **榴弹兵** | 向玩家投掷榴弹 |
| **飞行敌人** | 在空中扰袭 |
| **脑叶切除患者 / 侦探** | 场景与叙事型敌人意象 |

**证据等级：【已核实】（TheXboxHub、KeenGamer）。**

## 七、本作支线内容在系列中的意义

1. **把"多结局"从叙事升级为机制**：前三场首领的道德试炼累积决定终局，玩家"**如何战斗**"而非"**如何选择**"塑造了结局；
2. **枢纽化设计**：精神病院枢纽让升级与武器变体选择成为"关与关之间"的策略层；
3. **为系列留下开放余地**：两个结局均非"好结局"，且"解放"结局明确把世界置于更大危险中。
