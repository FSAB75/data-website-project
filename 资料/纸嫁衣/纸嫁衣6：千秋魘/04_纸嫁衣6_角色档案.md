## 一、双主角

### 1.1 肖驰（Xiao Chi）

| 项目 | 内容 |
|------|------|
| 身份 | **男主** |
| 本作经历 | **犯病在精神病院伤人后逃跑**；被奚月瑶跟踪尾随 |
| 关键行动 | 与奚月瑶一路拌嘴解谜骗老头；在**灵哥灵妹**帮助下打开**铜门** |
| 结局 | **为解除奚月瑶家世代的诅咒，选择留在秘境**——**生死不知** |

**证据等级：【已核实】（TapTap、九游）。**

### 1.2 奚月瑶（Xi Yuemiao；另译"奚月遥"）

| 项目 | 内容 |
|------|------|
| 身份 | **女主** |
| 本作经历 | **跟踪尾随逃跑的肖驰**，一路回到奘铃村；与肖驰拌嘴解谜 |
| 关键 | 身上背负"**家世代的诅咒**" |
| 结局 | 打开铜门后**逃走**；肖驰为解其诅咒留在秘境 |

**证据等级：【已核实】（TapTap、九游）。**
