# 03 纸嫁衣1 游戏内全部档案

> 对应游戏：《纸嫁衣》（2021，系列第 1 部）
> 收集体系：本作的核心收集为**线索（头脑风暴五层）**、**民俗解谜道具与对照表**、**隐藏彩蛋与成就**、**提示系统**。
> 数据说明：整理自萌娘百科、guhive、九游等；**未逐字转录**游戏内文本。

---

## 一、收集体系说明

| 收集类型 | 说明 |
|---------|------|
| **线索（头脑风暴）** | 收集到的线索可在右上角"**头脑风暴**"查看；**界面分五层**，**层数越高的线索越重要** |
| **民俗解谜道具** | 旧纸条、民俗手册、道具详情描述——**规则都会提前给出** |
| **五行 / 八卦 / 时辰对照表** | 每部道具里都会出现的通用解谜依据 |
| **隐藏彩蛋 / 成就** | 与"非必要互动"和"特定道具收集"有关 |
| **提示** | 每天 3 次免费（看 15 秒广告） |

---

## 二、头脑风暴系统（线索收集核心）

| 项目 | 说明 |
|------|------|
| **入口** | 右上角"**头脑风暴**" |
| **结构** | **五层**——可通过点击左上**金字塔**翻页 |
| **层级逻辑** | **层数越高的线索越重要** |
| **详情查看** | 可查看已收集线索的**详情** |

**证据等级：【已核实】（中文百科）。**

---

## 三、民俗解谜收集品

| 收集品 | 用途 |
|--------|------|
| **旧纸条** | 记录解谜规则 |
| **民俗手册** | 五行 / 八卦 / 时辰等规则 |
| **道具详情描述** | 对应规则会提前给出 |
| **五行对照表** | **东木、西金、南火、北水、中土** |
| **十二生肖 / 十二地支对照表** | 时辰类解谜依据 |
| **祭品四样** | "早生贵子"＝**红枣、花生、桂圆、莲子** |

**证据等级：【已核实】（guhive）。**

---

## 四、隐藏彩蛋与成就

| 项目 | 说明 |
|------|------|
| **触发对象** | **纸人耳朵、供桌上的散装糖果、墙角的旧风车、树上的红丝带**等不起眼道具 |
| **操作** | 点 **3–5 次**大概率触发隐藏成就 |
| **数量** | 每部一般有 **3–5 个**这类隐藏彩蛋 |
| **隐藏结局** | 多与**特定道具收集**有关 |

**证据等级：【已核实】（guhive）。**

## 五、提示系统

| 项目 | 说明 |
|------|------|
| **免费次数** | 每天 **3 次** |
| **获取方式** | 看完 **15 秒广告**解锁 |
| **性质** | **只给解题思路，不会直接报答案**，不影响游戏体验 |

**证据等级：【已核实】（guhive）。**
