## 二、隐藏彩蛋与成就（支线收集）

| 类型 | 说明 |
|------|------|
| **触发方式** | 隐藏成就大多与"**非必要互动**"有关——如点场景里不起眼的**纸人耳朵、供桌上的散装糖果、墙角的旧风车、树上的红丝带**等 |
| **操作要点** | 这类**不需要用来解谜的道具，点 3–5 次大概率触发隐藏成就**；每部一般有 **3–5 个**这类隐藏彩蛋 |
| **隐藏结局** | 解锁条件大多与"**特定道具收集**"有关 |

**证据等级：【已核实】（guhive）。**

## 三、民俗解谜支线（通用逻辑）

| 解谜类型 | 通用解法 |
|---------|---------|
| **五行类** | **东木、西金、南火、北水、中土** |
| **八卦 / 时辰类** | **十二生肖对应十二时辰**的对照表在每部道具里都会出现 |
| **祭品 / 食物类** | 多往**民俗谐音**上靠——"**早生贵子**"对应**红枣、花生、桂圆、莲子**四种祭品；**90% 的食物类解谜**都能用这个逻辑破解 |
| **通用技巧** | 遇到五行、八卦、时辰类解谜，**先翻背包里的旧纸条、民俗手册、道具详情描述**——对应规则都会提前给出 |

**证据等级：【已核实】（guhive）。**
