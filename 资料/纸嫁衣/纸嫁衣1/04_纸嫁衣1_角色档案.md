# 04 纸嫁衣1 角色档案

> 对应游戏：《纸嫁衣》（2021，系列第 1 部）
> 收录范围：**主角夫妇** + **反派与邪教阵营** + **协助者**。
> 说明：本作角色是"纸嫁衣宇宙"的奠基班底，其中**聂莫黎**为贯穿全系列的大反派。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、主角

### 1.1 宁子服（Ning Zifu）

| 项目 | 内容 |
|------|------|
| 身份 | **男主**；宁家之子 |
| 关系 | 与聂莫琪**两家指腹为婚**，相识后**坠入爱河** |
| 本作经历 | 婚礼当天未婚妻被抓，**一路追查至奘铃村**，凭智慧与勇气**成功救出聂莫琪** |
| 后续 | 《纸嫁衣8：千子树》中与聂莫琪一同回归 |

**证据等级：【已核实】（九游、TapTap、百度百科）。**

### 1.2 聂莫琪（Nie Moqi）

| 项目 | 内容 |
|------|------|
| 身份 | **女主**；聂家之女 |
| 关系 | 宁子服的未婚妻；**聂莫黎之妹**（双胞胎） |
| 本作经历 | 结婚当天**被抓去奘铃村做"纸新娘"**；后被宁子服救出 |
| 后续 | 《纸嫁衣8：千子树》中回归，与**双胞胎姐姐聂莫黎对决** |

**证据等级：【已核实】（九游、TapTap、百度百科）。**

---

## 二、反派与邪教阵营

### 2.1 聂莫黎（Nie Moli）——**系列大反派**

| 项目 | 内容 |
|------|------|
| 身份 | **聂莫琪的双胞胎姐姐**；**贯穿全系列的大反派** |
| 本作结局 | **因黑无常变得神智痴呆**；警察赶到后**被送去精神病院** |
| 系列定位 | "**大反派聂莫黎的阴谋贯穿始终，所有主角团最后都在联手对抗她的计划**" |
| 后续行动 | 《纸嫁衣3》中**报复帮聂莫琪破局的老道士**，设计针对道士的外甥申墨卿与王娇彤 |
| 《纸嫁衣8》 | 与双胞胎妹妹**聂莫琪对决** |

**争议提示**：另有单一来源称"莫黎被送走后利用邪术操控妹妹，企图借冥婚复活自己"——该说法与三份一致来源冲突（后者仅记其"因黑无常变痴呆"），标注【未明确】。

**证据等级：【已核实】（九游、TapTap、guhive）。**

### 2.2 奘铃村邪教阵营

| 角色 | 身份 |
|------|------|
| **大巫贤** | 奘铃村邪教高层 |
| **藏老六** | 村民 / 邪教相关（《纸嫁衣2》中亦有登场） |
| **屠老四** | **木偶师**——民国时期**斩首梁少平**者（《纸嫁衣2》核心反派） |

**证据等级：【已核实】（九游、UpToGo）。**
