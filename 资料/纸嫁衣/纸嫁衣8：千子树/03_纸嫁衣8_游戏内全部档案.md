# 03 纸嫁衣8 游戏内全部档案

> 对应游戏：《纸嫁衣8：千子树》（2025，系列第 8 部）
> 收集体系：系列通用（线索 / 民俗解谜 / 彩蛋）**+ 本作三大新机制（纸灵童 / 因果镜 / 声控解谜）**与**动态结局分支**。
> 数据说明：整理自百度百科、萌娘百科、guhive；**未逐字转录**游戏内文本。

---

## 一、收集体系说明

| 收集类型 | 说明 |
|---------|------|
| **线索（头脑风暴）** | 系列通用——右上角入口；**分五层**，**层数越高越重要** |
| **民俗解谜道具** | 系列通用——旧纸条、民俗手册、道具详情 |
| **本作新机制** | **纸灵童系统 / 因果镜 / 声控解谜** |
| **结局分支** | **动态结局分支**——关键选择影响剧情走向 |
| **隐藏彩蛋** | 系列通用——非必要互动 + 特定道具收集 |

---

## 二、本作三大新机制（核心收集 / 玩法）

| 机制 | 功能 | 备注 |
|------|------|------|
| **纸灵童系统（Paper Spirit Child）** | **辅助玩家探索** | **其行为可能受恶鬼影响发生反转**——既是助手也可能是陷阱 |
| **因果镜（Karma Mirror）** | 可**回看并修正记忆片段**的系统 | 与"记忆 / 前世"主题直接相关 |
| **声控解谜（Voice-Controlled Puzzle）** | 需**对环境麦克风念咒语**触发的解谜 | 本作标志性创新 |

**证据等级：【已核实】（百度百科）。**
