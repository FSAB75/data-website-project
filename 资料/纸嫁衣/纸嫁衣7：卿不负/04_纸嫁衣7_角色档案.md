# 04 纸嫁衣7 角色档案

> 对应游戏：《纸嫁衣7：卿不负》（2024，系列第 7 部）
> 收录范围：**金童玉女双主角** + **前作客串角色** + **八不郎**。
> 说明：本作主角为全新组合，但《纸嫁衣3》主角客串登场。
> 证据标注：【已核实】【推测】【未明确】。

## 一、金童玉女双主角

### 1.1 李逢泽（Li Fengze；另作"柳逢泽"）

| 项目 | 内容 |
|------|------|
| 身份 | **男主**；拥有"**金童玉女**"命格 |
| 目的 | **各怀目的**——试图**献祭对方来补齐自身命格** |
| 关键道具 | **无字谶**——用于**寻找魂魄消失的杜言她** |
| 结局 | 与杜言她**互相摊牌**后，**成为新的"八不郎"** |

**证据等级：【已核实】（百度百科、TapTap、九游）。**

### 1.2 杜言她（Du Yanta）

| 项目 | 内容 |
|------|------|
| 身份 | **女主**；拥有"**金童玉女**"命格 |
| 开局 | **魂魄消失**——由李逢泽以无字谶寻找 |
| 目的 | 同李逢泽——**各怀目的** |
| 结局 | 与李逢泽**发现双方互相隐瞒的事暴露**、**互相摊牌**；**成为新的"八不郎"** |

**证据等级：【已核实】（TapTap、九游、百度百科）。**
