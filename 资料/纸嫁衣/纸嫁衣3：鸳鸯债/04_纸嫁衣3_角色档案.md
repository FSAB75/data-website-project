# 04 纸嫁衣3 角色档案

> 对应游戏：《纸嫁衣3：鸳鸯债》（2022，系列第 3 部）
> 收录范围：**主角情侣** + **反派与旧怨线** + **家族长辈**。
> 说明：本作角色承接《纸嫁衣1》的后果，并把"**老道士的旧怨**"这条线推向台前。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、主角情侣

### 1.1 申墨卿（Shen Moqing）

| 项目 | 内容 |
|------|------|
| 身份 | **男主**；**老道士的外甥** |
| 家乡 | **奘铃村** |
| 本作经历 | 与王娇彤谈恋爱、见家长；王娇彤魂魄离体后，**为救她不惜与鬼差交易** |
| 牺牲 | 据 guhive，为救王娇彤**愿意折寿（十年）**换阴阳相会的机会 |
| 结局 | 二爷爷不再反对二人，但**两人最终阴阳相隔** |
| 后续 | 《纸嫁衣7：卿不负》中与王娇彤一同登场 |

**证据等级：【已核实】（九游、TapTap、guhive）。**

### 1.2 王娇彤（Wang Jiaotong）

| 项目 | 内容 |
|------|------|
| 身份 | **女主**；申墨卿的女友 |
| 本作经历 | 见家长途中**魂魄离体**；成为**纸新娘回阳的载体** |
| 关键行动 | 以"**傻人有傻福的聪明才智**"，**成功把自己和纸新娘封进鬼门关** |
| 结局 | 与申墨卿**阴阳相隔** |
| 后续 | 《纸嫁衣7》中与申墨卿一同登场 |

**证据等级：【已核实】（九游、TapTap）。**

---

## 二、反派与旧怨线

### 2.1 聂莫黎（Nie Moli）——系列大反派

| 项目 | 内容 |
|------|------|
| 本作行动 | **报复帮聂莫琪破局的老道士**，设计针对**道士的外甥申墨卿**与王娇彤 |
| 系列定位 | "**大反派聂莫黎的阴谋贯穿始终，所有主角团最后都在联手对抗她的计划**" |

**证据等级：【已核实】（guhive、九游）。**

### 2.2 老道士（The Old Taoist）

| 项目 | 内容 |
|------|------|
| 身份 | **申墨卿的舅舅** |
| 前作 | 《纸嫁衣1》中协助宁子服破局 |
| 本作 | 成为**聂莫黎报复的导火索**——其外甥申墨卿被设计针对 |

**证据等级：【已核实】（九游、guhive）。**

---

## 三、家族长辈

### 3.1 二爷爷（Second Grand-Uncle）

| 项目 | 内容 |
|------|------|
| 身份 | 申墨卿的**二爷爷** |
| 态度转变 | **起初反对二人在一起**；看到一路上小两口各种恩爱后，**不再反对** |

**证据等级：【已核实】（九游、TapTap）。**
