## 一、"债"的多层结构（本作叙事核心）

| 债 | 内容 |
|----|------|
| **上一辈的冥婚债** | "**上一辈欠下的冥婚债，要由后代偿还**"——本作核心命题 |
| **老道士的旧怨** | 老道士协助宁子服破局 → 聂莫黎**报复**，针对其外甥申墨卿 |
| **申墨卿的偿债** | 为救王娇彤，**与鬼差交易、折寿（十年）**换阴阳相会 |

> 这三层"债"构成本作"鸳鸯债"之名的完整含义。

## 二、民俗解谜支线

| 解谜 | 解法 |
|------|------|
| **罗盘解谜（本作高频）** | **子=正北、午=正南、卯=正东、酉=正西**；对照场景里**老黄历上的生辰八字**调整指针 |
| **五行通用** | 东木、西金、南火、北水、中土 |
| **时辰类** | 十二生肖对应十二时辰 |
| **食物 / 祭品类** | "早生贵子"＝红枣、花生、桂圆、莲子 |

**证据等级：【已核实】（guhive）。**
