# 04 纸嫁衣2 角色档案

> 对应游戏：《纸嫁衣2：奘铃村》（2021，系列第 2 部）
> 收录范围：**今生主角** + **民国前史双主角** + **邪教阵营**。
> 说明：本作角色几乎全部更换，但**民国篇的梁少平与祝小红是系列最重要的情感线源头**。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、今生主角

### 1.1 陶梦嫣（Tao Mengyan）

| 项目 | 内容 |
|------|------|
| 身份 | **本作女主**（**本作无男主**） |
| 前世 | **祝小红的转世** |
| 困扰 | **老是做同一个梦** |
| 经历 | 机缘巧合到奘铃村 → **被村里人抓住当纸新娘** → 在梁少平残魂帮助下解谜觉醒 |
| 结局 | **离开奘铃村**；**向警方举报奘铃村邪教头子**，使其受到制裁 |
| 后续 | 《纸嫁衣5：来生戏》中与**梁少平转世荀元丰**再续前缘 |

**证据等级：【已核实】（九游、TapTap、芯域矩阵）。**

---

## 二、民国前史双主角（系列情感线核心）

### 2.1 祝小红（Zhu Xiaohong）

| 项目 | 内容 |
|------|------|
| 身份 | **民国时期的"纸新娘"** |
| 恋情 | 与**戏子梁少平**相恋 |
| 结局 | 梁少平劫祭被杀后，**绝望跳崖殉情** |
| 转世 | **陶梦嫣** |

**证据等级：【已核实】（UpToGo、guhive）。**

### 2.2 梁少平（Liang Shaoping）

| 项目 | 内容 |
|------|------|
| 身份 | **戏子**；祝小红前世爱人 |
| 义举 | 为救小红免于被活祭，**大闹祭典** |
| 惨死 | **被木偶师屠老四斩首**，化为厉鬼"**煞金刚**" |
| 滞留 | **魂滞奘铃村百年** |
| 守护 | 以**残魂**帮助陶梦嫣解开噩梦之谜；"**百年后转世仍守在对方身边**" |
| 转世 | **荀元丰**（《纸嫁衣5》男主） |

> 据 guhive："**戏子梁少平为救祝小红身死，百年后转世仍守在对方身边**"是系列**破圈的核心情感线**。

**证据等级：【已核实】（UpToGo、guhive）。**
