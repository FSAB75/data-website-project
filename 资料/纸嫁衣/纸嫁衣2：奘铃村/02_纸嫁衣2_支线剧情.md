# 02 纸嫁衣2 支线剧情

> 对应游戏：《纸嫁衣2：奘铃村》（2021，系列第 2 部）
> 说明：本作为**单主线 + 5 章结构**，无独立支线篇章。其"支线"主要体现为**前世 / 今生双线叙事**、**隐藏彩蛋与成就**、**民俗解谜支线**与**跨作伏笔**。本文件与 `01_纸嫁衣2_主线剧情.md` 互补。

---

## 一、前世 / 今生双线（本作叙事核心）

| 线 | 内容 |
|----|------|
| **今生线（现代）** | 陶梦嫣反复做同一个梦 → 到奘铃村 → 被抓为纸新娘 → 解谜觉醒 |
| **前世线（民国）** | 祝小红（纸新娘）与梁少平（戏子）相恋 → 梁少平劫祭被屠老四斩首化为"煞金刚" → 祝小红跳崖殉情 |
| **交织点** | 陶梦嫣即**祝小红转世**；**梁少平的残魂**帮助她解开噩梦之谜 |

> 本作由此深化"**纸嫁衣**"意象——**嫁衣不仅是婚服，更是囚禁灵魂的枷锁**。

**证据等级：【已核实】（芯域矩阵、UpToGo）。**

## 二、隐藏彩蛋与成就（系列通用机制）

| 项目 | 说明 |
|------|------|
| **触发方式** | 与"**非必要互动**"有关——纸人耳朵、供桌糖果、旧风车、红丝带等 |
| **操作** | 点 **3–5 次**大概率触发；每部约 **3–5 个** |
| **隐藏结局** | 多与"**特定道具收集**"有关 |

**证据等级：【已核实】（guhive，系列通用）。**

## 三、民俗解谜支线

| 解谜 | 解法 |
|------|------|
| **脸谱解谜（本作高频）** | **赤（红）＝火、黄＝土、白＝金、黑＝水、绿＝木**；按场景给出的五行顺序摆放 |
| **五行通用** | 东木、西金、南火、北水、中土 |
| **时辰类** | 十二生肖对应十二时辰（对照表在道具里） |
| **食物 / 祭品类** | "早生贵子"＝红枣、花生、桂圆、莲子 |

**证据等级：【已核实】（guhive）。**

## 四、跨作伏笔（本作"支线"的深层意义）

| 伏笔 | 补完于 |
|------|--------|
| **梁少平的魂滞留奘铃村百年** | 《纸嫁衣5：来生戏》（荀元丰即梁少平转世） |
| **陶梦嫣的前世心结** | 《纸嫁衣5》中与荀元丰再续 |
| **奘铃村邪教被举报** | 为系列"反封建迷信"主题定调 |

> 据 guhive：**"戏子梁少平为救祝小红身死，百年后转世仍守在对方身边"**是系列**破圈的核心情感线**之一——很多不怕恐怖的玩家是被这条线吸引的。

**证据等级：【已核实】（guhive、UpToGo）。**
