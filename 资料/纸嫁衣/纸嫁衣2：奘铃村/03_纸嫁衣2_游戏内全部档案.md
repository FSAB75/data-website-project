# 03 纸嫁衣2 游戏内全部档案

> 对应游戏：《纸嫁衣2：奘铃村》（2021，系列第 2 部）
> 收集体系：与系列一致——**线索（头脑风暴五层）**、**民俗解谜道具与对照表**、**隐藏彩蛋与成就**、**提示系统**。本作新增**脸谱解谜**与**六葬灵塔**场景收集。
> 数据说明：整理自萌娘百科、guhive 等；**未逐字转录**游戏内文本。

## 一、收集体系说明（系列通用）

| 收集类型 | 说明 |
|---------|------|
| **线索（头脑风暴）** | 右上角入口；**分五层**，**层数越高的线索越重要** |
| **民俗解谜道具** | 旧纸条、民俗手册、道具详情描述（规则提前给出） |
| **五行 / 时辰对照表** | 每部道具里都会出现 |
| **隐藏彩蛋 / 成就** | 与"非必要互动"和"特定道具收集"有关 |
| **提示** | 每天 3 次免费（看 15 秒广告） |
