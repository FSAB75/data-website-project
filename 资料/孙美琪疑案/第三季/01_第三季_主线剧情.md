|---|---|---|
| 前情 | **郎冥其因叛变被南书房处死**；其兄**郎威**将原因归结于【李斯文绑架刘青春】与【刘青春坚持查案】两件事 | 【已核实】 |
| 复仇 | 郎威决定杀掉李斯文与刘青春为弟报仇，先雇佣墨西哥食人族**卡洛斯**杀死并吃掉李斯文，将尸体悬挂在延庆野长城烽火台外墙 | 【已核实】 |
| 劝阻 | 曾学仁（曾学正之弟，郎威的合伙人）写信给卡洛斯让其劝郎威不要再杀第二人，并建议他去广东做生意；郎威未听 | 【已核实】 |
| 圈套 | 郎威把假人悬挂在烽火台内、涂抹李斯文的血液伪造成命案现场，引诱刘青春前来；他伪造了周芳与随大同的痕迹以迷惑刘青春 | 【已核实】 |
| 炸弹 | 他事先在烽火台安装炸弹，想让刘青春自行触发机关被炸死 | 【已核实】 |
| 出警 | 警方接报，局长派出**刘青春与王勇**；二人分头行动：刘青春调查烽火台，王勇调查附近小木屋 | 【已核实】 |
| 慌乱 | 藏身小木屋的郎威没料到王勇会来，慌忙把本应放在烽火台的急救箱放到小木屋床上后逃窜 | 【已核实】 |
| 配合 | 二人通过对讲机交流、配合默契，各自发挥所长互补推理，还原案情 | 【已核实】 |

| 彩蛋 | 最后的彩蛋显示：压住刘青春的废墟中有一个与汉墓中类似的**胶囊** | 【已核实】 |

### E02 金凤凰（郎冥其案后 2 周）

| 阶段 | 内容 | 证据 |
|---|---|---|
| 背景 | 刘青春在烽火台倒塌事件中失踪，市局立案调查；王勇被局长要求放长假在家待命 | 【已核实】 |
| 两周后 | 广东佛山发生命案，王勇听线人说在现场看到了刘青春，于是偷偷来到佛山 | 【已核实】 |
| 现场 | 位于佛山南海的一个大排档街区，死者**林咏欣**死于金凤凰商贸公司门前，她本人也是该公司实习生 | 【已核实】 |
| 封锁 | 王勇到达时现场已被封锁；他趁晚上当地警方不在开始查案 | 【已核实】 |
| 谜底 | 王勇通过刘青春的"暗中帮助"找到了刘青春养的兔子**谜底**和一封信；刘青春在信上将谜底委托给他饲养，并嘱咐"**一定要相信兄弟**" | 【已核实】 |
| 金凤凰商贸 | 一家黑社会性质的集团，黑白两道通吃，实为**卧底公司**，与女心医师会、南书房等多个组织都有联系；创始人金凤凰本人扑朔迷离 | 【已核实】 |
| B 计划 | 女心医师会想脱离苏联总部控制，头目杜翠兰亲自部署成员与金凤凰贸易公司合作实行"**B 计划**"——制作"**水银少女心**"送给一个"人" | 【已核实】 |
| 死者 | 实习生林咏欣被选为目标，在大排档街区被凶手杀死并**全身灌入水银**，心脏被取出后经女心医师会特殊处理制成"水银少女心"，尸体被从天台推下 | 【已核实】 |
| 伪装 | 整条大排档街其实都是金凤凰商贸公司的地盘；隔壁冯记云吞面的店主冯俊文与儿子冯小于负责给出假证词；当地民警**郑隆**也是金凤凰公司的卧底 | 【已核实】 |
| 若非王勇 | 如果不是王勇来查案，该案大概率会以自杀结案 | 【已核实】 |
| 反转 | 金凤凰公司的**金三**目击行凶过程，却因私人恩怨背叛公司，在现场留下线索揭示凶手体貌特征。王勇据此推理出一个难以置信的真相：**凶手就是刘青春** | 【已核实】 |

> 结合后续周芳篇补充：在大排档血案中，金凤凰组织与女心医师会取出林咏欣的水银少女心后，**刘青春将林咏欣的尸体推下了楼**；他本以为可以以"自己人"身份搞清案情，事实上并不顺利。【已核实】

### E03 周芳（1991 年，接金凤凰篇后）

| 阶段 | 内容 | 证据 |
|---|---|---|
| 亲缘 | 周芳的邻居曾学正与金凤凰桑蚕贸易公司的**曾学仁**是一对兄弟；周静与周芳已故的父亲**周文灵**生前从事的研究可能与生门一号有关（此处存疑） | 【已核实 / 存疑】 |
| 金凤凰身世 | 文革期间金凤凰的父母**金太吉**与**邓桂平**因出身问题受极大影响，将年仅两岁的金凤凰过继给战友**曾学正**；曾学正与周静关系很好、视如亲女，故金凤凰与周静情同姐妹、认了干姐妹 | 【已核实】 |
| 1981 年 | 17 岁的金凤凰来到广东成立金凤凰商贸有限公司，势力颇大，掌握各黑暗势力的卧底并令他们暗中为她服务，包括女心医师会、南书房、全神教等 | 【已核实】 |
| 异能 | 传说金凤凰可以通过某种方法**修改人的记忆**——从你看到她的那一刻，所见场景与接触的文字都会成为她修改你记忆和认知的方法；只要与她对话就无法反驳她的观点，使人陷入痛苦 | 【已核实】 |
| 曾学仁 | 曾学正之弟，也为金凤凰办事且颇受器重，并把郎威介绍给了她 | 【已核实】 |
| 周静之死 | 金凤凰曾写信给周静让她来广东帮忙（提到周文灵的实验），然而周静被女心医师会杀死；其后金凤凰派出郎威去做掉女心医师会 | 【已核实】 |
| 赵惠英 | 可能也曾是金凤凰手下；她为保护茉莉，生生撕下纹有圣火纹身的一块皮肤，退出金凤凰组织 | 【已核实】 |
| 1990 年 | 曾学正家失火，被接到广东金凤凰家 | 【已核实】 |
| 1991 年 | 废墟中的刘青春为保命喝下斯克罗素，生命垂危；出来后遇见处理郎威事务的金凤凰——她不仅爱上了刘青春，还告诉他只有她能帮他弄清真相 | 【已核实】 |
| 卧底 | 刘青春跟着金凤凰来到广东，手臂纹上**圣火纹身**；本以为可以"自己人"身份搞清案情，但并不顺利 | 【已核实】 |
| 毒素 | 斯克罗素的毒素开始蔓延到心脏；刘青春收到周芳电话，对方声称有解药 | 【已核实】 |
| 顺德墓地 | 刘青春来到顺德一处墓地——这是金凤凰给自己信任或曾经信任的人立的**活人碑**；朱孝坤曾在此遇到脱离金凤凰的郎威并被挖出眼睛 | 【已核实】 |
| 收获 | 刘青春在周芳留下的线索帮助下了解金凤凰、得到解药（**斯克罗素的原虫生门一号**，此处存疑），并误打误撞发现金凤凰的密室——一扇有两个机关的门，机关正是夏小梅与茉莉的**真子飞霜镜** | 【已核实】 |

### E04 宋明朝（1991 年）

| 阶段 | 内容 | 证据 |
|---|---|---|
| 强峰初创 | 早在刘青春出生之前，其父刘峰便与另一个"人"创立了**强峰实验室**；实验室多年来做了很多机密研究，如斯克罗素原虫与 **107 研究项目** | 【已核实】 |
| 宋明朝 | 他不仅是金凤凰手下；当年**早于**朱孝坤一行进入四号墓坑，得到一种神秘物质"**蓝蜡**"，点燃后可使黄金隐形，并借此带走大量黄金——此物质即强峰实验室的 107 研究项目 | 【已核实】 |
| 修塔 | 宋明朝回乡后修建**乘澜塔**，虔诚修佛；直到遇见金凤凰，虽对其言听计从、与郎威称兄道弟，但可能还有更不为人知的秘密 | 【已核实】 |
| 张强 | 宋明朝将强峰实验室研究员**张强**关入塔中，令其进行斯克罗素原虫与神秘物质的实验 | 【已核实】 |
| 研究成果 | 张强得出：用**石猫**可抑制原虫，用**蓝灯**可使其孵化；有一只原虫可能已孵化成功，理论上成为身形巨大的生物 | 【已核实】 |
| 1991 年 | 刘青春被金凤凰关入乘澜塔，被告知若能出去就可回北京 | 【已核实】 |
| 强峰档案 | 刘青春在塔中发现张强留下的强峰档案，得知：斯克罗素需特殊方法才能感染人（方法未知），感染后可通过某种方法恢复，恢复后有特殊体香且雌雄不同（即周芳与周静之父周文灵当年的研究） | 【已核实】 |
| 三个讯息 | 刘青春发现金凤凰留给他的三个讯息：**不能见王勇、去新疆、找茉莉**；且强峰实验室可能与南书房还有关系 | 【已核实】 |
| 结局 | 金凤凰最终决定放走刘青春，并将父亲曾学正托付给他照顾；刘青春带曾学正先回北京，寻找新的答案 | 【已核实】 |

> 注：斯克罗素原虫的本质尚不能做定论；刘青春在金凤凰身上闻到过奇怪体香，同样的香味也在王勇身上闻到过（余仁仁篇章）。【已核实】

### E05 嬴雪儿（1978 年 12 月 30 日案发 / 1991 年调查）

| 阶段 | 内容 | 证据 |

| 1978-12-30 | 为完成**七星杀人仪式**，孙美琪教唆年仅 5 岁的茉莉（**嬴雪儿**）在水缸里下白色曼陀罗的毒，毒死大杂院的七个人（七人代表七个星宿），其中包括宗大宝的儿子 | 【已核实】 |
| 顶罪 | 赵惠英母女的邻居**郑泽**为了她们的人生牺牲自己，顶替入狱 | 【已核实】 |
| 之后 | 多年后孙美琪放弃仪式自杀身亡；然而为完成此仪式，需有人代替已死的孙美琪，在**十四年后**杀死茉莉 | 【已核实】 |
| 十四年间 | 喜欢郑泽的**蒋玉萍**想为他洗清罪名；茉莉则天天白天带着吉他出门，不知所踪 | 【已核实】 |

| 带走 | **随大同**为了保护茉莉，带走了她和赵惠英，中途失手砸晕了前来调查的刘青春 | 【已核实】 |
