|---|---|---|

| 晕倒 | 在罗布泊戈壁滩上触碰到一根奇怪的金属棒后晕倒在地 | 【已核实】 |
| 哈朵相救 | "金凤凰"的手下、维族姑娘**哈朵**发现了他，把他带到**卡乌留克塔格**——罗布泊地区一处磁力异常的区域，安置在住处后离开 | 【已核实】 |
| 疑团 | 刘青春在此发现大量难以理解的信息：陈庭君、兰芝、杜翠兰、金凤凰都来过这里；那个"人"是谁 | 【已核实】 |
| 见到"那个人" | 在哈朵留下的大量信息帮助下，成功见到了传说中的那个"人" | 【已核实】 |

| 当年合谋 | 当年南书房与**罗刹国（沙俄）**合谋迫害夏小梅与蝶儿，夏辛酉借此得到了一对**真子飞霜镜**和**督春** | 【已核实】 |

| 赏赐规则 | 从此只要谁在卡乌留克塔格与夏辛酉对话，就会得到稀世珍宝作为赏赐；得到赏赐的人也会为他办事，且**不会背叛他** | 【已核实】 |
| 神像 | 夏辛酉每见一人，就会将名字记录在神像上 | 【已核实】 |

| 强峰缘起 | 夏辛酉为消除"永生"的副作用恢复原状（**第一目的**），与刘峰策划了"强峰实验室" | 【已核实】 |
| 刘峰的代价 | 刘峰参与后付出了代价——他**渐渐失去了记忆** | 【已核实】 |
| 陈庭君 | 1976 年，陈庭君根据汉墓的信息瞒着朱孝坤独自前往新疆，却被困在卡乌留克塔格，也见到了夏辛酉 | 【已核实】 |
| 关键意义 | 陈庭君的出现让夏辛酉知道：**答案在更加遥远的时期** | 【已核实】 |

| 中村福山 | 汇仁社的中村福山也找过夏辛酉，夏没有见他；但夏觉得汇仁社好像掌握着很多他不知道的东西 | 【已核实】 |

### E05 阿加塔（1991 年 4 月，金凤凰篇章后、4 月 16 日前；此时刘青春仍在广东未归队）

| 阶段 | 内容 | 证据 |
|---|---|---|
| 神秘人安排 | 神秘人再次出现，安排王勇来到一个秘密实验室，在那里王勇可以了解刘青春的幻境；王勇答应接受这项危险的实验 | 【已核实】 |
| 实验原理 | 地下秘密实验：用**毒气影响人的思维**，使人回忆起一些眼睛看到过但迅速被大脑忘记的细节 | 【已核实】 |
| 流程 | 实验者首先接听电话确认实验开始，毒气从气窗进入，开始产生**真实幻觉**；若在幻觉中想自杀，可服用一旁的**镇静胶囊**恢复正常；幻觉依个体情况不同 | 【已核实】 |
| 幻觉一：八七纵火案 | 陈双十升任局长后的第一个案子：出租屋被人纵火，**10 人身亡**，房间内全是纸质资料；一直无法破案，直到一个人来自首，口供与案情完全吻合，于是结案 | 【已核实】 |
| 幻觉二：挖眼女 | 一个女子对着镜子挖出自己的眼球，经抢救最终活了下来；现场发现了一个**金属三角形**，后来不知去向 | 【已核实】 |
| 指向 | 两条线索联系起来**全部指向他的上司——陈双十局长** | 【已核实】 |
| 判断 | 王勇清楚幻觉是大脑底层的猜测，这至少证明他确实一直怀疑陈双十是黑幕 | 【已核实】 |
| 大楼照片 | 王勇吃药恢复后在地上看到那张大楼照片；捡起后房间里出现楼房模型，他听见枪声和哭泣，看见一个女人的脸，还有反复出现的名字：**Агата** | 【已核实】 |
| 1985 跨国贩毒案 | 刘青春与王勇刚进入刑警队，被派往苏联解决一起跨国贩毒案；照片里正是毒贩窝点 | 【已核实】 |
| 案情 | 歹徒在每一层都安置了一个人质并安装了好几个炸弹；两人潜入第一栋楼，救下一个女孩——她父母被毒贩杀死，自己一直被囚禁在这里 | 【已核实】 |
| 遇险 | 在第三栋楼走到三楼时两人被困；王勇分析出这一切都是圈套，然而为时已晚，整栋楼都被炸毁，二人险些丧命 | 【已核实】 |
| 救命 | 老刑警在配楼楼顶与毒贩血战，一个毒贩对王勇开枪，**刘青春推了他一把救了他一命** | 【已核实】 |
| 结果 | 最终他们没能救下所有人质 | 【已核实】 |
| 兄弟 | 此案后王勇真正认识了这位过命的好兄弟；刘青春回京后养了一只叫"**谜底**"的兔子，说血腥和残暴会让他失去理智 | 【已核实】 |
| 揭晓 | 王勇意识到：一直用寻呼机帮助刘青春、现在正在帮助他的这个神秘人，就是当年他们救下的那个女孩——**阿加塔（Агата）** | 【已核实】 |
| 阿加塔的自述 | 当年二人走后，她并不信任当时的警方；幸得一个**明斯克**（白俄罗斯首都）人的资助，她了解了一切真相 | 【已核实】 |
| 线索 | 她用寻呼机留下了一个线索——"**去 老地方 医院**"；而在随大同家发现的方婷婷的套娃，或许与阿加塔有关 | 【已核实】 |
| 迷宫 | 王勇转动房门把手，身体突然缩小，走进了一个迷宫——他当年在警校出国训练时的迷宫 | 【已核实】 |
| 所见之物 | 一张外国女人合影、卡乌留克塔格的牌子、金属棒、沙子、一本有关幻境的书——有人利用这些东西制定了"**沙漠计划**"，目的未知 | 【已核实】 |
| 金凤凰标志 | 他看见硕大的金凤凰标志，以及金凤凰留下的三个线索："**抓郎威**""**调查陈双十**""**不要见刘青春**" | 【已核实】 |
| 心声 | 王勇变小后看见花瓣语和日历语，那是他的心声：他知道死亡一旦发生，就再也无可挽回 | 【已核实】 |
| 两句话 | 邓局曾说"你想好了吗，说不定哪天就离开这个世界了"；刘青春办完贩毒案后问他"你怕死吗"，他答"我怕死得没有价值" | 【已核实】 |
| 清醒判断 | 若幻境实验可以传递他人意志甚至改变人的行为，那它提供的线索**全都是有目的性的**：金凤凰不可信，阿加塔的话有一半可信，**陈双十肯定有问题** | 【已核实】 |
| 决定 | 调查局长，抓住郎威——不为正义，为了兄弟 | 【已核实】 |
