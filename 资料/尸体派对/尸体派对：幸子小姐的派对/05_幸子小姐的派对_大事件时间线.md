# 05 幸子小姐的派对 大事件时间线

> 对应游戏：《尸体派对：幸子小姐的派对》（Corpse Party: Sweet Sachiko's Hysteric Birthday Bash / 2U）
> 说明：本作是**"中传（midquel）"**——故事发生在《血色笼罩》《影之书》**事件期间的一个轮回夹缝**中，时间点特殊（**发生在"轮回之内"而非之外**），需结合系列主时间轴理解。
> 证据标注：【已核实】【推测】【未明确】。

## 一、本作在系列时间轴上的位置

```
1952 ─ 天神小学开校

1975 ─ 废校 / 校长自杀
1978 ─ 如月学园在原址开校
2008-10-27 ─ 如月学园文化祭·主线事件（天神小学，多次轮回）
   │
   └─ ★《幸子小姐的派对》★ ← 发生在 BC/BoS 期间的“轮回夹缝”中
       （幸子生日当天，诅咒减弱，给予“死者”24 小时大赦）
   │
2008-11-11 ─ 《影之书》序章（真结局两周后）
2009-01-11 ─ 《驭血》开端
```

## 二、本作时间点的特殊性

| 要点 | 说明 | 证据 |
|------|------|------|
| **属"中传"** | 官方定位为《血色笼罩》与《影之书》的**"（意外地）正统中传"**，发生在两作**剧情进行期间** | 【已核实】 |
| **发生在"轮回夹缝"** | 众人脑中融合了**多个平行轮回世界的未来**（对"坏结局"的记忆模糊），说明本作时间点**嵌套在轮回之内** | 【已核实】 |
| **触发条件** | **幸子生日当天**，天神小学的**诅咒会短暂减弱**，幸子借此举办派对 | 【已核实】 |
| **"24 小时大赦"** | 幸子给予死者们**24 小时的免罪期**——这一天内他们能"不断死去活来"（多数人的死亡记忆模糊，如世以子般"必死命运"者则记得） | 【已核实】 |
| **一天结束即"回档"** | 派对结束时，**所有人失去这一天的记忆**，幸子**重新被诅咒侵蚀**——仅骸骨项链留存 | 【已核实】 |

## 五、要点与易混提示

1. **不要把它当"番外"忽略**：官方定位为**中传**，且为《驭血》预埋了关键人物。
2. **时间点特殊**：它是**唯一发生在"轮回夹缝"中**的作品——众人"不断死去活来"正是**轮回记忆**的体现。
3. **幸子生日的日期**：据《血色笼罩》设定，幸子生日为 **7 月 17 日**（另有资料将 1953 年 7 月 19 日记为"幸子生日当天"的事件日）——本作派对即设定在其生日当天。【部分为【未明确】（日期在不同来源间存在出入）】
4. **"奇迹没有发生"**：终章的伤感恰是本作与正传一脉相承之处——**即使是搞笑的番外，落点仍是悲剧**。
