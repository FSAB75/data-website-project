# 02 幸子小姐的派对 支线剧情

> 对应游戏：《尸体派对：幸子小姐的派对》（Corpse Party: Sweet Sachiko's Hysteric Birthday Bash / 2U）
> 说明：本作本体即"短篇集 + 结局收集"，所谓"支线"主要体现为**各章坏结局（Wrong Ends）**、**结局收集**与**额外章节**。本文件与 `01_幸子小姐的派对_主线剧情.md` 互补。

---

## 一、结局体系（共 30 个）

### 1.1 结构

- 本作共有 **30 个结局**，包含：
  - **额外章节的 2 个结局**；
  - **每章 1 个 Clear End（通关结局）**；
  - 其余为**坏结局（Wrong Ends）**。
- **只有达成某章的 Clear End**，才能推进到下一章。
- 亦有资料将"剧情结局"记为 **28 个**（不含额外章节），两说并存。【已核实】

### 1.2 坏结局的"荒诞死法"（系列一绝）

被评论者与玩家概括的**代表性死法**包括（**均为恶搞猎奇**）：

| 死法 | 说明 |
|------|------|
| **钢琴线腰斩** | 被细而利的东西拦腰截断 |
| **头被吃掉** | "学姐的死法"——被怪物吞头 |
| **被朋友以各种方法杀死** | 黑化后的同伴互杀 |
| **黑化四连击** | 连续的黑化致死桥段 |
| **羞愧死（BL 剧情）** | 非常"神奇"的分支，成为本作的梗之一 |
| **挖出内脏死** | 内脏被剜出 |
| **被美臀憋死** | 荒诞到极点的搞笑死法 |

> 上述为本作"换装 / 名场面"式的恶搞死亡，**非恐怖正剧**。【已核实】

## 二、各章坏结局示例（第 1–2 章）

> 来源：Fandom「Hysteric Birthday Bash/Endings」。以下为**具体示例**。

### 第 1 章『战场上的耻辱』（吃面包大赛）

| 结局 | 达成条件 | 内容 |
|------|---------|------|
| **"早就料到了（orz）"** | 选择"保持沉默，继续为她加油" | 世以子吃下藏有陷阱的面包，天花板上垂下的"面包怪"将她吞食，直美惨叫；幸子揭示这既是"吃面包比赛"、面包也会吃人，狂笑 |
| **"我无怨无悔！"** | 选"制止她"→"别信她，继续观察" | 黑崎健介、袋井雅人、山本美月在独木桥环节遭触手袭击；黑崎拒不道歉，山本最终将他推下深渊（因以为他在享受自己受辱） |
| **"新娘难为"** | 选"制止她"→"就信她一次"→"穿上选定的服装" | 换装类恶搞结局 |
| **Clear End** | 选"制止她"→"就信她一次"→"和森繁交换" | 世以子避开陷阱面包，却误触利线**身首分离**；直美自责痛哭 |

### 第 2 章『聚光灯下的陌生人』（舞台剧）

| 结局 | 达成条件 |
|------|---------|
| **"我衷心的梦想"** | 连续三次选择"全都糟糕"以外的选项 |
| **"我到底干了什么？！"** | 选"全都糟糕"→每次都选"反抗剧本" |
| **Clear End** | 选"一切都糟糕"→至少一次不选"反抗剧本" |

> 上述仅列**第 1–2 章**示例；第 3–7 章同样各有坏结局与 Clear End，逐条穷举以官方攻略为准，本文件不臆造。【部分为【未明确】】

## 三、额外章节（Extra Chapter）

- **解锁**：通关正篇后解锁。
- **风格**：**回归传统恐怖**（与正篇的搞笑基调形成强烈反差）。
- **内容**：详细讲述**新角色阿座见贵（Azusa Takai）**与**小林兰（Ran Kobayashi）**的**悲惨背景故事**——这两个角色在正篇中"突兀登场"，其来历在此获得**唯一**交代。
- **意义**：是理解"她们为何出现在幸子的派对上"的关键，也是本作**唯一的正剧章节**。

## 四、支线角色与"特别来宾"

### 4.1 幸子的"特别来宾"（Cameo）

## 五、本作支线在系列中的意义

1. **给出"反派也曾经是孩子"的一面**：终章幸子扑入母亲怀中恸哭，是全系列最动人的场景之一。
2. **补完配角与新人**：让大量"尸体角色"获得人格，也为《驭血》预埋了核心成员。
3. **唯一的正剧章**：额外章节承接了本作新人的悲剧背景，避免了整部作品沦为纯搞笑。
