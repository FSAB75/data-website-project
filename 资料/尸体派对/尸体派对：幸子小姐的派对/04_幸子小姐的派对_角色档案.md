# 04 幸子小姐的派对 角色档案

> 对应游戏：《尸体派对：幸子小姐的派对》（Corpse Party: Sweet Sachiko's Hysteric Birthday Bash / 2U）
> 收录范围：**本作重点新角色** + **回归的系列角色**。
> 说明：本作是"全员派对"，登场角色极多。本文件侧重记录**在本作首次正式登场或获得重要戏份的新角色**；基础档案请交叉参考 `../尸体派对：血色笼罩/04_血色笼罩_角色档案.md` 等。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、本作新登场 / 重点刻画角色

### 1.1 水原皐月（Satsuki Mizuhara）

| 项目 | 内容 |
|------|------|
| 身份 | 持田由香的**同班同学**（初中生） |
| 声优 | 原由实（Yumi Hara，亦为系列演唱主题曲的歌手之一） |
| 形象 | 性格**攻击性强、自信**；**走到哪都带着一袋"奇怪口味"的薯片**（据说能凭空掏出来） |
| 来源 | 是被取消的作品**《CORPSE-PARTY 2：Satsuki's Heart》**原主角的**"现代化重制"** |
| 后续 | 在《驭血》中成为**马尔托巴之墓成员**（爱狩部下），最终**咬死反派御帘徒** |

**说明**：本作让这个"本应消失在开发取消中的角色"以全新姿态复活，是系列的一大冷知识。【已核实】

### 1.2 二羽爱子（Aiko Niwa）

| 项目 | 内容 |
|------|------|
| 身份 | **桐章学园 3 年生** / **灵异情报商（执着于灵器与金钱）** |
| 声优 | 山口立花子 |
| 关系 | 与**冴之木七星**既是朋友也是对手；与**幸子意气相投** |
| 本作戏份 | 身为**幸子的跟班**，执行各种"生日派对任务" |
| 后续 | 在《驭血》中**升格为主角之一**（其姊为**二羽久远**） |
| 来源 | 轻小说《尸体派对 CEMETERY0》首登场 |

**说明**：外表是精明的"情报贩子"，实为"以利益掩饰关心"的角色（在《驭血》中与早矢香构成对照）。【已核实】

### 1.3 犬丸晴行（Haruyuki Inumaru）

| 项目 | 内容 |
|------|------|
| 身份 | **桐章学园学生** / 七星的同班同学 |
| 声优 | 山口智大 |
| 形象 | **滑稽、喜欢鱼**；与**大上早矢香是青梅竹马**，暗恋她、屡遭冷遇却不以为意 |
| 来源 | 轻小说《影之书》首登场 |
| 后续 | 在《驭血》正篇中**不再是滑稽的卡通式角色**，性格大幅收敛 |

**说明**：本作中他的"搞笑"基调最浓，是典型的"番外角色"。【已核实】

### 1.4 阿座见贵（Azusa Takai）

| 项目 | 内容 |
|------|------|
| 身份 | 本作**真正的全新角色**之一 |
| 戏份 | 正篇中作为"幸子的特别来宾"突兀登场；其来历**仅在额外章节**交代 |
| 背景 | 在**传统恐怖风格的额外章节**中被详细讲述（与马尔托巴之墓相关的悲惨背景） |

> 注：其名"Azusa Takai"与《驭血》中马尔托巴之墓第二号人物**阿座见贵**同名（英文同为 Azusa Takai）——两作中此人是**同一角色**，本作是其**首次登场与背景揭晓地**。【已核实】

### 1.5 小林兰（Ran Kobayashi）

| 项目 | 内容 |
|------|------|
| 身份 | 本作**真正的全新角色**之一 |
| 戏份 | 与阿座见贵一同在正篇中突兀登场 |
| 背景 | 其悲惨背景同样在**额外章节**中揭晓 |

**说明**：以上两位新人"在正篇中的角色定位是一个持续的谜"，但对后续影响有限。【已核实】

## 三、角色关系补注

- **桐章学园三人组**：二羽爱子、犬丸晴行、冴之木七星（大上早矢香亦同校）——本作让这条"另校线"大幅丰满。
- **水原皐月的双重身份**：本作中是由香的同学；《驭血》中则是马尔托巴的杀手。
- **阿座见贵**：本作与《驭血》中的**同名同人**，是连接两作的暗线之一。
