# 03 幸子小姐的派对 游戏内全部档案

> 对应游戏：《尸体派对：幸子小姐的派对》（Corpse Party: Sweet Sachiko's Hysteric Birthday Bash / 2U）
> 收集体系：本作为**纯视觉小说**，**没有名牌系统、没有地图探索**；其"收集"要素为**章节 Clear End + 坏结局（共 30 个）+ 额外章节 + 画廊（CG / 语音 / 音乐）**。
> 数据说明：整理自 Fandom「Endings」、Steam 官方页与玩家攻略；未逐字转录游戏内文本。

---

## 一、档案（收集）体系说明

| 收集类型 | 说明 |
|---------|------|
| **章节（Chapters）** | 本体共 **8 章 + 1 额外章节** |
| **Clear End** | 每章 1 个，达成后才能推进到下一章 |
| **坏结局（Wrong Ends）** | 大量荒诞猎奇死亡结局 |
| **结局总数** | **30 个**（含额外章节 2 个 + 每章 Clear End；另有资料记为 28 个剧情结局） |
| **额外章节** | 传统恐怖风格，补完新角色背景 |
| **画廊（Gallery）** | CG / 语音 / 音乐（随进程解锁） |

- **与正传的差异**：本作**无"尸体名牌"**（名牌是《血色笼罩》《驭血》的收集特色），收集重心完全落在**结局**上。
- **选项提示**：游戏会把**已看过的分支标蓝**，辅助"结局全收集"，但坏结局众多，提示作用有限。
