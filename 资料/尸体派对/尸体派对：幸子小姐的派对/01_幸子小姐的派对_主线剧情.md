## 一、核心设定：幸子生日当天的"24 小时大赦"

### 1.1 前提

- 每年**幸子生日当天**，天神小学的诅咒会**短暂减弱**；
- 于是，**幸子**（天神小学诅咒的元凶，本身也是被害者）决定举办一场**生日派对**——她召集了**此前游戏中死去的几乎所有角色**，给予**24 小时的"免罪大赦"**，让他们陪自己玩。
- 由于**时间轮回**的缘故，众人的脑中**融合了多个平行轮回世界的未来**（因此对"坏结局"的记忆模糊），而**刻命裕也**这类人则同时记得**好几份记忆**却毫不混乱。

### 1.2 舞台与主题

- 被幸子的能力"**重新安排命运**"的**持田哲志**及其同伴齐聚**天神小学讲堂**；
- 幸子突然现身，宣布要开办**"校园文化祭"**，主题是——**"Love Comedy（恋爱喜剧）"**；
- 于是，一场**有爱、有泪、有欢笑（也有猎奇死亡）的"幸子的恋爱游戏"**就此开始。

> 换言之：本作是一次**以幸子生日为名的"类型恶搞大乱斗"**——杀人鬼与被杀者被迫一起玩派对游戏。【已核实】

## 二、章节式剧情（8 章 + 1 额外章）

> 本作为**电视节目 / 活动式**的短篇集，各章对应一项"生日派对活动"。每章只有**一个 Clear End（通关结局）**会推进到下一章。

| 章 | 活动 / 主题 | 代表内容 |
|----|-----------|---------|
| **#0** | Hysteric Birthday（生日开幕） | 幸子登场、宣布文化祭与"恋爱喜剧"主题 |
| **#1** | 战场上的耻辱（Shame Upon the Battlefield） | **吃面包大赛**等体力搞笑游戏；多名角色在此以各种离谱方式死亡 |
| **#2** | 聚光灯下的陌生人（Stranger in the Spotlight） | **舞台剧 / 表演**类恶搞；剧情分歧复杂 |
| **#3** | （派对游戏·男女混合） | 交友 / 混合活动类 |
| **#4** | （料理 / 咖喱） | 烹饪对决类 |
| **#5** | （电影 / 实况） | 拍摄类恶搞 |
| **#6** | （赛跑 / 竞技） | 竞速类 |
| **#7 / 终章** | **幸子"想学游泳"** | 众人为幸子制作**生日礼物**（一条**骸骨项链**，寄托"死后也能自由"的愿望）；幸子实现心愿 |

> 各章标题的**官方中译**未统一，本表以活动内容描述为主，不臆造标题。【部分为【未明确】】

### 终章的情感落点

- 派对尾声，幸子**暂时从诅咒的包裹中剥离**，感受到一个 7 岁女孩与"朋友"分别的悲伤；
- 她**扑进母亲（篠崎芳惠）的怀里恸哭**，说出心声：**"妈妈，我不想再……"**；
- **然而就在此刻，这一天结束了**——所有人**失去这一天的记忆**，幸子**重新被诅咒侵蚀**；
- **只有那条骸骨项链，仍留在她的脖子上**。

> 这一结局被玩家评价为"**最令人心酸的番外**"：奇迹没有发生，但希望似乎总会到来。【已核实】

## 三、玩法与结构

### 3.1 玩法

- **传统视觉小说**：纯**选项**推进，无地图 / 调查环节；
- **选项提示**：游戏会**把已看过的选项分支标蓝**（帮助有限，因坏结局分支众多）；
- **死亡即常态**：选错就会导向**荒诞的死亡坏结局**（如"钢琴线腰斩""头被吃掉""被朋友以各种方法杀死""黑化四连击""羞愧死（BL 剧情）""挖出内脏""被美臀憋死"等）。

### 3.2 结局结构

- 结局总数：**30 个**（含**额外章节的 2 个结局** + **每章 1 个 Clear End**）；
  - 亦有资料记为 **28 个剧情结局**。两说差异在于是否把"额外章节"计入，本文件并存之。【已核实】
- 只有**正确的选项链**才能达成各章 Clear End，其余通向坏结局。

### 3.3 额外章节（Extra Chapter）

- **通关后解锁**；
- **回归传统恐怖风格**（与正篇的搞笑基调相反）；
- **内容**：补完全新角色**阿座见贵（Azusa Takai）**与**小林兰（Ran Kobayashi）**的**悲惨背景故事**——是理解"新角色从何而来"的关键。

## 五、本作的地位与评价

1. **基调反差**：把"最绝望的系列"做成"最欢乐的番外"，恐怖与搞笑并置，是系列的**解压阀**。
2. **角色补完**：让许多"只作为尸体出现"的学生**获得了丰满的形象**——越是这样，越能感到"被害者不断加害新被害者"的**怨念螺旋**之沉重。
3. **衔接作用**：新角色**二羽爱子、水原皐月、犬丸晴行**在《驭血》中有正式戏份，故本作**并非纯粹外传**。
4. **门槛**：大量恶搞**依赖对日式恋爱喜剧 / 2012 年前后动漫梗的熟悉**，对新玩家不友好。
