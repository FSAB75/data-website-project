# 03 驭血 游戏内全部档案

> 对应游戏：《尸体派对：驭血》（Corpse Party: Blood Drive, Team GrisGris × 5pb.）
> 收集体系：**名牌（Name Tag）系统回归**（本作由《血色笼罩》的"按学校分类"改为**按章节分类**，且发现时**直接显示全部内容**，无需再进菜单翻查）；另有**额外章节、画廊、语音访谈**等收集要素。
> 数据说明：整理自 Fandom「Corpse Party: Blood Drive/Name Tag List」与 Fuwanovel 全流程攻略；**名牌总数未见权威统计**，本文件收录已公开条目，未收录者不臆造。未逐字转录游戏内文本。

---

## 一、档案（收集）体系说明

| 收集类型 | 说明 |
|---------|------|
| **名牌（Name Tag）** | 散落在天神小学各处的尸体上，记录**姓名 / 年龄·性别 / 就读学校·班级 / 死因 / 发现位置**；本作**按章节排列**，发现即显示全部内容 |
| **额外章节（Extra Chapters）** | 共 8 个（视觉小说式），随进程解锁 |
| **画廊（Galleries）** | 收录美术（Art）、音乐（Music）、**声优访谈（Voice Actor Interviews）** |
| **结局（Endings）** | 每章真结局 + 多个坏结局，需重玩解锁 |

- **与《血色笼罩》的差异**：收集逻辑更人性化——不再按"学校"归档，而是**按章节**；这对"逐章全收集"的玩家更友好。
- **彩蛋名牌**：本作亦有制作组"自我致敬"的名牌（见下）。

## 四、各版本特色与差异

| 版本 | 特色 |
|------|------|
| **PS Vita 原版（2014，日）** | 本体；11 正篇章 + 8 额外章；Unity 3D |
| **国际版（2015，PSV）** | XSEED / Marvelous USA 发行；**追加"无限电池模式"**（按 Select 切换，缓解手电电池收集的繁琐） |
| **iOS / Android（2017）** | 手机移植版，内容基本一致 |
| **PC（Steam，2019）** | 移植版；修复了部分程序 BUG（空气墙、摇杆精度），画面提升 |
