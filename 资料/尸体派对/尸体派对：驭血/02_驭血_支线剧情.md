# 02 驭血 支线剧情

> 对应游戏：《尸体派对：驭血》（Corpse Party: Blood Drive, Team GrisGris × 5pb.）
> 说明：本作"支线"主要体现为 **8 个额外章节（Extra Chapters）**、**各章坏结局（Wrong Ends）** 与**支线角色的独立故事线**。本文件与 `01_驭血_主线剧情.md` 互补。

---

## 一、额外章节（Extra Chapters）总述

- **数量**：**8 个**（正篇 11 章之外）。
- **形式**：全部为**视觉小说式**（无探索玩法），仅含一条无关紧要的分支路径；篇幅从"一小时的短篇"到"不到一分钟的凑数章"不等。
- **价值**：部分额外章节**比以往更关键**——提供**重要背景信息**，或作为**已死角色的"最后遗言/落幕"**。
- **解锁**：随正篇进程逐步解锁。

> 关于额外章节的**具体标题**：公开来源未逐一给出官方译名，为避免编造，本文件**不臆造标题**，仅按"功能类型"归纳。【未明确】

### 1.1 额外章节的常见类型

| 类型 | 说明 |
|------|------|
| **已死角色的收束章** | 为在《血色笼罩》中死去的同伴补上"最后一幕"（如世以子、茧等） |
| **背景补完章** | 补充马尔托巴之墓、御跋如等组织的历史与设定 |
| **喜剧 / 番外章** | 基调更接近《幸子小姐的派对》（如二羽久远的喜剧副线） |
| **实验性 / 短篇** | 部分章极短（"一下肚"即结束） |

**证据等级：【已核实】（Hardcore Gaming 101 明确记载 8 个额外章节及其性质）。**

## 二、坏结局（Wrong Ends）

### 2.1 结构

- 每个正篇章节都有**真结局 + 多个坏结局**；
- **流程中若在限时选择处"不作选择"（计时耗尽），同样会触发坏结局**；
- 多数玩家**首次通关会以坏结局收场**，需重玩解锁好结局；
- 本作的坏结局**比以往更"干脆"**——多是**瞬间的死亡描写**（如被一分两断），而非冗长的猎奇铺陈。

### 2.2 触发方式一览（归纳）

| 触发类型 | 示例 |
|---------|------|
| 错误选项 | 在关键分支选错 |
| 限时选择超时 | 不作任何选择 |
| 踩中陷阱 | 玻璃碎片、塌陷地板、绊线 |
| 被敌人杀死 | Phantom 拖出柜子殴打、Golem 攻击 |
| 体力耗尽 | 奔跑后体力见底、被追上 |

**证据等级：【已核实】。**

## 三、支线角色的独立故事线

### 3.1 十三月爱狩（Magari Mizuki）——教团线

- **身份**：桐章学园高等部 2 年 1 组转学生（冴之木七星班上的转学生）；真实身份为黑魔术教团**马尔托巴之墓**的干部、教祖继承权第 4 位。
- **形象**：人偶般的外貌、双马尾山吹色头发、粉红缎带、白色哥德萝莉装，偶持巨大镰刀。
- **性格**：傲慢、毒舌、好战残忍，但对**冨之木七星**有强烈兴趣（视其为好对手），曾**杀害一名姓篠崎的女性**、并拆散七星与早矢香的友情。
- **本作线**：作为另一方"魔女"与步美**亦敌亦友**；教团在涅槃融合灾难中**几近覆灭**（教祖惊坠楼梯而死），爱狩**发誓重建教团**。
- **首次登场**：2011 年小说《尸体派对 CEMETERY0》——**本作是其游戏首次登场**。
- **证据等级：【已核实】。**

### 3.2 桐谷御帘徒（Misuto Kiriya）——反派线

- **身份**：**御跋如（Yagoura）**协会的**唯一幸存者**；本作主要反派。
- **线**：自称与**步美之姊**有渊源；以"夺回影之书即可复活死者"的谎言**诱骗步美收集六鬼柱**，妄图融合涅槃与现实、毁灭世界。
- **结局**：被黑化尸变的水原皐月**咬掉头颅**而死。
- **证据等级：【已核实】。**

### 3.3 篠崎幸（Sachi Shinozaki）——家族线

- **身份**：幸子的"**消失的双胞胎**"（实为幸子的姐姐，出生前被幸子吞并）；死后成为幽灵。
- **线**：成为"**天神小学为何在真结局后仍存在**"的补完解释；在终局**夺回结晶**、以感官承受核心之痛并**封印涅槃核心**。
- **评价**：被部分评论者视为"**从帽子里变出的设定**"，但确实收束了系列遗留问题。
- **证据等级：【已核实】。**

### 3.4 二羽久远（Kuon Niwa）——企业线

- **身份**：二羽爱子（2U 登场角色）之姊；灵异巨型企业的社长，同时**替任如月学园的英语教师**。
- **线**：其"完美"起初用于喜剧，后转为悲剧——**为摧毁"最后一柱"、借篠崎幸的灵力而牺牲自己**。
- **证据等级：【已核实】。**

### 3.5 马尔托巴之墓（Martuba's Tomb）——组织线

- **性质**：末日论黑魔术教团；与"御跋如"为**敌对关系**。
- **主要成员**：教祖（第 1 位，惊坠楼梯死亡）、阿座见贵（第 2 位，黑化）、十三月爱狩（第 4 位→灾后第 1 位）、水原皐月（成员）、沃尔多（管家）、及"灵手术 / PROJECT DOLLIES"等计划的执行者。
- **结局**：涅槃融合灾难中**大部分成员死亡或逃散**；教祖身亡，爱狩重建。
- **证据等级：【已核实】。**

## 四、本作支线在系列中的意义

1. **收束世界观**：额外章节与支线共同补完"涅槃 / 影之书 / 篠崎家 / 两大教团"的完整设定；
2. **为角色送别**：为《血色笼罩》中死去的同伴补上"最后一面"；
3. **过渡到新篇**：本作"天神小学篇完结"后，系列转向《尸体派对 2：死亡病患》等新线。
