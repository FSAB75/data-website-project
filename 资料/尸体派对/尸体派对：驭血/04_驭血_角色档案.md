# 04 驭血 角色档案

> 对应游戏：《尸体派对：驭血》（Corpse Party: Blood Drive, Team GrisGris × 5pb.）
> 收录范围：**如月学园生还者** + **本作新登场角色（魔女集团）** + **篠崎家血脉与核心存在**。
> 说明：基础角色档案请交叉参考 `../尸体派对：血色笼罩/04_血色笼罩_角色档案.md` 与 `../尸体派对：影之书/04_影之书_角色档案.md`。
> 证据标注：【已核实】【推测】【未明确】。

## 一、如月学园生还者（主角团）

### 1.1 篠崎步美（Ayumi Shinozaki）——**本作主角**

| 项目 | 内容 |
|------|------|
| 身份 | 如月学园 2-9 班长 / **篠崎家末裔** / 《影之书》守护者 |
| 状态 | 由"咒语发起者 → 自责的幸存者 → 世界拯救者"的完整弧光 |
| 结局 | **吞食涅槃**、将其重新封印；代价是**在现实世界中的存在被抹去**且**失去一只眼睛**；成为《影之书》的最后守护者 |

**事迹经历**：在《影之书》序章中因动用《影之书》复活同伴失败、**害死亲姊篠崎丙**而深陷自责。本作中被**十三月爱狩派来的山村未来**引导，获得**死后相逢之石**，重返天神小学；又受**桐谷御帘徒**欺骗而**收集六鬼柱**，酿成大祸。终局中，她以自身为代价封印涅槃。**证据等级：【已核实】。**

### 1.2 中嶋直美（Naomi Nakashima）

- 与步美一同行动的生还者；见证终局，是本作情感线索的重要支点。
- **证据等级：【已核实】。**

### 1.3 岸沼良树（Yoshiki Kishinuma）

- 生还者之一，暗恋步美。结局中**保有全部记忆**，借死后相逢之石**寻得步美**，两人一同前往**另一平行世界**。
- **证据等级：【已核实】。**

### 1.4 持田哲志（Satoshi Mochida）/ 持田由香（Yuka Mochida）

- 生还的兄妹；在本作中作为生还者群像出现，参与后续行动。
- **证据等级：【已核实】。**

## 二、本作新登场角色：魔女与教团

### 2.1 十三月爱狩（Magari Mizuki）

| 项目 | 内容 |
|------|------|
| 身份 | 桐章学园高等部 2 年 1 组转学生（七星班上）/ **马尔托巴之墓干部（教祖继承权第 4 位）** |
| 声优 | 内田真礼 |
| 形象 | 人偶般外貌、双马尾山吹色头发、粉红缎带、白色哥德萝莉装，偶持巨大镰刀 |
| 性格 | 傲慢、毒舌、好战残忍，对七星有强烈兴趣（视为好对手） |
| 结局 | 教团在灾难中几近覆灭，她**发誓重建教团**（成为第 1 位） |

**事迹经历**：曾杀害一名姓篠崎的女性、拆散七星与早矢香的友情。本作中作为另一方"魔女"与步美**亦敌亦友**：既利用她、也在关键时刻收手。**首次登场于 2011 年小说《尸体派对 CEMETERY0》，游戏首次登场即本作。**

**证据等级：【已核实】。**

### 2.2 桐谷御帘徒（Misuto Kiriya）——**本作主要反派**

| 项目 | 内容 |
|------|------|
| 身份 | **御跋如（Yagoura）**协会的**唯一幸存者** |
| 声优 | 大须贺纯 |
| 结局 | **死亡**——被黑化尸变的水原皐月**咬掉头颅**（吃头） |

**事迹经历**：突然出现在步美面前，谎称"夺回影之书即可复活死者"，**诱骗步美收集六鬼柱**，意图将其凝结为结晶、封印进"假影之书"，从而**掌控涅槃、让涅槃与现实融合、毁灭世界**。自称与**步美之姊**有渊源（此点为其操纵手段）。**证据等级：【已核实】。**

### 2.3 水原皐月（Satsuki Mizuhara）

- **身份**：马尔托巴之墓成员、爱狩的部下；经"**灵手术（Spiritual Surgery）**"获得**怪物化能力**。
- **结局**：**咬死御帘徒**（吃掉他的头），扭转战局。
- **证据等级：【已核实】。**

### 2.4 山村未来（Mirai Yamamura）

- **身份**：受十三月爱狩派遣，**引导步美**前往篠崎真纪公寓、获得死后相逢之石。
- **证据等级：【已核实】。**

### 2.5 沃尔多（Waldo Mizuki）

- **身份**：爱狩的**管家兼抚养者**；当年在教堂外捡到爱狩、将其引入教团。
- **证据等级：【已核实】。**

### 2.6 阿座见贵（Azusa Takai）

- **身份**：马尔托巴之墓**第二号人物**；前往天神小学寻找《影之书》后**因黑化而无法拯救**。
- **证据等级：【已核实】。**

### 2.7 马尔托巴之墓（Martuba's Tomb）教团

- **性质**：末日论黑魔术教团，与"御跋如"为敌对关系。
- **已知成员**：教祖（第 1 位，惊坠楼梯身亡）、阿座见贵（第 2 位）、十三月爱狩（第 4 位→灾后第 1 位）、水原皐月、沃尔多、以及"灵手术 / PROJECT DOLLIES"等计划的相关者。
- **结局**：涅槃融合灾难中大部分成员死亡或逃散；教祖坠楼身亡；爱狩重建。
- **证据等级：【已核实】。**

## 三、篠崎家血脉与核心存在

### 3.1 篠崎幸（Sachi Shinozaki）

| 项目 | 内容 |
|------|------|
| 身份 | 幸子的"**消失的双胞胎**"（实为幸子的姐姐，出生前被吞并）；死后成幽灵 |
| 作用 | 夺回六鬼柱结晶；以感官承受涅槃核心的酷刑（**被挖出眼球**）并**重新封印核心** |
| 评价 | 被部分评论视为"补完式"设定，但收束了"天神小学为何在真结局后仍存在"的遗留问题 |

**证据等级：【已核实】。**

### 3.2 篠崎幸子（Sachiko Shinozaki）

- 天神小学（涅槃）的**原主宰**；在本作中**牺牲自己**，把时间倒流回御帘徒即将毁灭世界之前，为众人争取机会。
- **证据等级：【已核实】。**

### 3.3 篠崎真纪（Makina Shinozaki）

- 篠崎芳惠的姑母、幸子的姑祖母；其**公寓**是步美获得**死后相逢之石**的关键地点。
- **证据等级：【已核实】。**

### 3.4 涅槃（Nirvana）——"角色化"的存在

- **本质**：中世纪欧洲**魔女狩猎**中被献祭女巫的**怨念集合体**，带**自我意识**，被封印于《影之书》。
- **在本作中的表现**：吞噬并融入现实世界、产生"实体之壁"，最终**被篠崎幸封印、被步美吞食收束**。
- **证据等级：【已核实】。**

## 五、角色关系速览

```
篠崎家血脉：芳惠 → 幸子 / 篠崎幸（双胞胎） → 步美（末裔）
两大教团：马尔托巴之墓（爱狩、皐月、沃尔多、阿座见贵）
         御跋如（御帘徒，唯一幸存者）
核心存在：涅槃（魔女怨念集合体）= 天神小学真身

本作冲突：步美（被两方利用）— 御帘徒（造世/灭世）— 爱狩（教团重建）
终局：幸子牺牲回溯 → 篠崎幸封印核心 → 步美吞食涅槃（代价：现实存在被抹去+失明）
```
