# 尸体派对（Corpse Party）系列作品总览

> 系列：尸体派对（コープスパーティー / Corpse Party）
> 原作 / 主要开发：Team GrisGris（チームグリグリ）
> 主笔 / 原作：祁答院慎（Makoto Kedōin）
> 商业发行：MAGES.（5pb.）；《尸体派对2》由 GrindHouse（同人团体）制作
> 整理时间：2026 年 10 月 15 日

---

## 一、系列概况

《尸体派对》是日本经典的**生存恐怖 / 文字冒险（AVG）**游戏系列，最初是 1996 年在 PC-9801 上以免费同人形式发布的独立作品，后经多次重制与续作发展为跨平台系列。

- **核心舞台**：**天神小学（天神小学校 / Heavenly Host Elementary School）**——一座现实中被废止、在异次元中以诅咒形态存在的学校。
- **核心诅咒**：**篠崎幸子（Sachiko Shinozaki）**与"**幸福的幸子小姐（Sachiko Ever After）**"咒语。一群如月学园的学生因施行该咒语而被拖入天神小学。
- **玩法特征**：俯视视角探索、环境互动、多结局（含大量"**误入结局 Wrong Endings**"）、以 RPG Maker 起家。
- **系列规模**：全球累计销量超过 100 万份（官方数据），衍生出漫画、小说、OVA、真人电影、主题乐园活动等。

## 五、资料收集标准（沿用"逃生"系列的 5 项）

每部作品计划收集：

1. **主线剧情** → `01_<作品>_主线剧情.md`
2. **支线剧情** → `02_<作品>_支线剧情.md`
3. **游戏内全部档案 / 收集要素** → `03_<作品>_游戏内全部档案.md` + `03_<作品>_档案清单.csv`
4. **角色档案与事迹经历** → `04_<作品>_角色档案.md` + `04_<作品>_角色清单.csv`
5. **大事件时间线** → `05_<作品>_大事件时间线.md`

**口径确立（已按本系列实际形态落地）**：本系列为文字冒险（AVG）游戏，其"支线"与"档案"的形态与《逃生》不同，实际整理时对应为——
- **"支线"** → **额外章节（Extra Chapters）**、**误入结局（Wrong Endings）**、**IF / 平行世界线**；
- **"档案 / 收集要素"** → **名牌（Name Tag，标注死者就读学校·年龄·死因）**、**牺牲者手记 / 病历 / 七星笔记**、**结局收集**、**画廊（CG / 语音 / 音乐）**。
