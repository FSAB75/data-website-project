# 02 死亡病患 支线剧情

> 对应游戏：《尸体派对2：死亡病患》（Corpse Party 2: Dead Patient, Team GrisGris）
> 说明：本作**目前仅有第一章 + 额外章节 1**，故"支线"主要体现为**第一章的坏结局（Wrong Ends）**、**额外章节 1**，以及**支线角色与场景细节点**。本文件与 `01_死亡病患_主线剧情.md` 互补。

---

## 一、结局结构（第一章）

### 1.1 结构特征

- 沿袭系列惯例：**每章多个坏结局 + 1 个"真结局"**；
- **"真结局"≠"好结局"**——本作第一章的真结局同样是**被捕 / 身份被揭穿**的黑暗收束。

### 1.2 坏结局（Wrong Ends）

| 结局 | 内容 |
|------|------|
| **被丧尸吞食** | 第一章的坏结局**全部以"被丧尸活活吃掉"告终** |
| **"虚假希望"坏结局** | 在目睹**里津子**与**千代美**死亡后，玩家**短暂重获操作权**——暗示"也许还能逃"；但丧尸**来得太快**，虽被提示"尝试逃跑"，**逃跑必然失败**，主角同样被吞没 |
| **斩首展示** | 某坏结局中，主角目睹一具丧尸**转身，口中还衔着里见（Satomi）残留的头颅**——辅以主角的"Heroic BSoD（精神崩溃）" |

**证据等级：【已核实】（TV Tropes 记载）。**

## 二、额外章节 1（Extra Chapter 1）

- **别名 / 定位**：《...NEUES;》重制版**新增**的章节；
- **视角**：**"一位天神小学旧识（an old Heavenly Host acquaintance）"**；
- **内容**：从另一视角**重述第一章的故事**——为系列老玩家准备的"呼应 / 对照"章节；
- **意义**：**在全新故事线中置入"天神小学篇"的怀旧锚点**，强化"两部作品血脉相连"。

**证据等级：【已核实】。**

## 三、支线角色与背景细节

### 3.1 事件缘起（第一章之前的支线背景）

- 主角**あやめ**住院，其**青梅竹马千代美**为让她开心，约了 **1-5 班的几名同学**一同探望；
- 探望期间发生**超常惨剧**：一名**母亲亲手残杀自己的女儿**，紧接着**女儿又起身尖叫**——这正是医院陷入"醒着的噩梦"的起点；
- **あやめ本人对此一无所知**（她苏醒时已错过这一切）——TV Tropes 称其为"**睡过了这场末日（Slept Through the Apocalypse）**"。

**证据等级：【已核实】。**

### 3.2 医院中的三类存在

| 类别 | 说明 |
|------|------|
| **伙伴** | 同样被困、愿查明真相的幸存者 |
| **敌人** | 把主角困在此处的人（含**全副武装的 SWAT 部队**） |
| **怪物** | 嗜血丧尸、超自然巨怪、怨恨的亡灵 |

**"幸存者内部并不团结（A House Divided）"**——并非所有幸存者的求存方式一致，人际冲突成为支线张力之一。【已核实】

### 3.3 场景细节（支线探索点）

| 地点 / 要素 | 说明 |
|------------|------|
| **护士站（Nurse's Office）** | 可通过**通风管道（Air-Vent）**逃离 |
| **上吊的女人** | 主角曾目睹一名**正在上吊自杀的女子** |
| **自制武器** | 拐杖、扫帚等**临时武器** |
| **躲藏点** | 柜子可用来躲避追杀者 |

**证据等级：【已核实】。**

## 四、与系列前作的联系（支线彩蛋）

- **时间**：设定在《驭血》**5 年后**；
- **人物**：以**全新人物群**为主，但**"有一些熟悉的名字"**，并有**"天神小学旧识"的客串章节**；
- **机制**：**名牌系统**（沿袭传统）、**存档蜡烛**（沿袭传统）、**多重结局**（系列惯例）——皆为新老玩家的连接点。

**证据等级：【已核实】。**
