# 04 死亡病患 角色档案

> 对应游戏：《尸体派对2：死亡病患》（Corpse Party 2: Dead Patient, Team GrisGris）
> 收录范围：**本作全新角色群**（"死亡病患"故事线的主舞台）。
> 说明：本作目前**仅有第一章**，角色信息有限；本文件收录已公开的角色，未公开者不臆造。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、主角与核心角色

### 1.1 伊藤あやめ（Ayame Itou）

| 项目 | 内容 |
|------|------|
| 身份 | 水无月学园高中（Minazuki Academy High School）**1 年 5 组**学生 / **本作主角** |
| 状态 | 在医院手术台上苏醒，**麻醉未退、记忆严重缺失**（连姓名都是靠病历才想起） |
| 处境 | 被困于被封锁的**阿玛蕾·帕特里亚卡·克鲁西斯医院** |
| 关键真相 | **真结局中被揭示为"死亡病患（dead patient）"**——她自身的存在即是谜团的一部分 |

**事迹经历**：醒来后靠自己逃离手术室，在满是丧尸、怪物与可疑人类的医院中求生；寻找同伴与出口，试图拼合"自己为何在此""医院里发生过什么"的真相。**证据等级：【已核实】。**

### 1.2 千代美（Chiyomi）

| 项目 | 内容 |
|------|------|
| 身份 | あやめ的**青梅竹马** |
| 行动 | 为给住院的あやめ解闷，**召集 1-5 班的同学一起来探望** |
| 结局 | **坏结局中被丧尸群吞没** |

**说明**：她是"事件缘起"的推动者，也是主角醒来后急于寻找的人之一。**证据等级：【已核实】。**

---

## 二、被困者与配角

### 2.1 里津子（Ritsuko）

- **身份**：被困于医院的幸存者之一。
- **结局**：**坏结局中死亡**（其死亡是主角"虚假希望"坏结局的前奏）。
- **证据等级：【已核实】。**

### 2.2 里见（Satomi）

- **身份**：被困者之一。
- **结局**：**某坏结局中被丧尸咬下头颅**（"斩首展示"名场面）。
- **证据等级：【已核实】。**

### 2.3 龙司（Ryuuji）

- **身份**：被困者之一。
- **名场面**：危难之际**举着扫帚冲来营救主角**（"英雄救场"），却被**甩飞、撞在门上把门卡住**——英雄行为功亏一篑。
- **证据等级：【已核实】。**

### 2.4 雅美（Masami）

- **身份**：本作中**性格相当疯狂**的角色。
- **关键作用**：**真结局中掀起あやめ的上衣**，向众人揭示主角是"**死亡病患**"——是主角身份谜团的关键揭穿者。
- **证据等级：【已核实】。**

---

## 三、敌对势力

### 3.1 SWAT 部队

- **形象**：全副武装（**蓝色与黑色防暴装备**）、戴防毒面具的武装人员；
- **态度**：**对幸存者并不友善**，属敌对势力；
- **关键作用**：**真结局中逮捕主角一行**。
- **证据等级：【已核实】。**

### 3.2 丧尸与怪物

| 类别 | 说明 |
|------|------|
| **丧尸（Zombie-like）** | 医院中游荡的嗜血尸群，最常见的死因来源 |
| **超自然巨怪** | 体型巨大、非同寻常的怪物 |
| **怨恨的亡灵** | 亡故者的怨念（"scornful shades of the departed"） |

**证据等级：【已核实】。**
