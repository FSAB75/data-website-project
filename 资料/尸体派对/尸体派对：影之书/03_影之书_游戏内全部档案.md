# 03 影之书 游戏内全部档案

> 对应游戏：《尸体派对：影之书》（Corpse Party: Book of Shadows, Team GrisGris × 5pb.）
> 收集体系：与《血色笼罩》"名牌 + 手记"的收集体系不同，本作的核心收集要素为 **结局（True End / Wrong End）** 与 **画廊（CG / 语音 / 音乐）**，并设有**章节选择与完成度追踪**。
> 数据说明：整理自 Fandom、GameFAQs 官方攻略与官方说明；未逐字转录游戏内文本。

---

## 一、档案（收集）体系说明

| 收集类型 | 说明 |
|---------|------|
| **章节（Episodes）** | 本体共 **8 个章节**（7 章 + 序章『血之辙』） |
| **真结局（True End）** | 每章 1 个，由正确选项路线达成 |
| **坏结局（Wrong End）** | 每章多个，由错误选项 / 检视尸体 / 超时等触发 |
| **CG 回廊** | 解锁的 CG 插画，可保存至 PSP 本体 |
| **语音 / 惨叫鉴赏** | 角色台词与惨叫录音 |
| **音乐鉴赏** | 游戏内 BGM |
| **完成度追踪** | 各章完成百分比，鼓励收集全部结局 |

- **与《血色笼罩》的差异**：本作**没有名牌系统**（名牌是《血色笼罩》与《驭血》的收集特色）；本作转向**视觉小说式的"结局 + 画廊"收集**。
- **解锁最终章的条件**：集齐各章结局（或继承《血色笼罩》PSP 存档）后开放序章『血之辙』。

## 四、各版本特色与差异

| 版本 | 特色 |
|------|------|
| **PSP 原版（2011，日）** | 本体；7 章 + 序章『血之辙』；含画廊与完成度系统 |
