# 03 血色笼罩 游戏内全部档案

> 对应游戏：《尸体派对：血色笼罩》（Corpse Party: Blood Covered, Team GrisGris）
> 收集体系：本作的核心收集要素为 **名牌（Name Tag / 名札）**、**牺牲者手记（Victim Memoir）** 与 **各类文档**，另有 **结局** 与 **CG** 的收集
> 数据说明：整理自尸体派对 Wiki（Fandom）Name Tag List、Steam 社区全收集攻略与公开资料；未逐字转录游戏内文本

## 档案体系说明

与《逃生》系列的"文档/录音"二分不同，《血色笼罩》的收集要素以**名牌**为核心特色：

| 收集类型 | 数量 | 说明 |
|---------|------|------|
| **名牌（Name Tag）** | **84 个** | 散落在天神小学各处的**尸体**上，记录该死者的**就读学校、年龄、姓名与死因（死法）**——即用户所关注的"尸体上的名牌" |
| **牺牲者手记（Victim Memoir）** | 每章 5 本 | 记录过往被卷入天神小学的其他学校学生的遭遇；**读满 5 本会触发坏结局** |
| **结局（Endings）** | 每章真结局 + 多个坏结局 | 见 `02_血色笼罩_支线剧情.md` |
| **CG / 额外章节** | 各版本不同 | EX 章与 CG 回廊 |

- **名牌的意义**：它是本作世界观的核心载体之一——**天神小学困住的远不止主角一行**。这 84 具尸体来自日本各地多所学校，名牌让每一具无名的尸体都有了"身份"与"死法记录"，构成整座学校的死亡群像。
- 全收集对应成就/奖杯（收集全部 84 个名牌）。

## 二、牺牲者手记（Victim Memoirs）

- **数量**：每章 5 本，共 25 本（各章一致）。
- **形态**：散落在各章场景中的文献，阅读后记录"过往被拖入天神小学的其他学生"的遭遇。
- **关键机制**：**读满 5 本即触发坏结局**——本作"求知者必死"的设计核心。
- **与名牌的关系**：手记讲"经历"，名牌讲"结局（死法）"，二者互补，共同还原出天神小学这座"死亡收集箱"的全貌。

**证据等级：【已核实】（攻略与 Fandom 收录）。**

## 四、各版本特色收集品差异

用户特别关注的"其他版本的特色收集品"，整理如下：

| 版本 | 特色收集品 / 追加内容 |
|------|---------------------|
| **1996 初代（PC-98）** | 无名牌系统（该机制为后续重制版引入）；以纯文本冒险为主 |
| **PC《Blood Covered》（2008–2011）** | 引入并逐步完善名牌系统；补丁追加 EX 章与 "Tooth（EX Preview）"；2008 限定版追加 EX Chapter 1 |
| **PSP《...Repeated Fear》（2010）** | **名牌系统定型（84 个）**；新增第 5 章与结局；全语音；EX 章扩充至 10 个 |
| **iOS（2012）** | 移植版，收集要素与 PSP 版基本一致 |
| **3DS（2015）** | **追加 PSP 版没有的新额外章节**，为收集要素增补了独家内容 |
| **2021 完整版（Switch / PS4 / Xbox / PC）** | **追加未收录语音与追加剧本**；新增名牌/结局相关补充；支持简繁中文 |

**证据等级：各版本差异为【已核实】（Wikipedia / PCGamingWiki / GameFAQs 收录）；名牌数量在各版本间的微小差异为【未明确】。**
