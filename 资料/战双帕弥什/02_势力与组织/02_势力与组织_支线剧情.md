# 势力与组织 — 暗线关系

> 证据标注：【已核实】多源一致；【推测】合理推断；【未明确】来源冲突或公开资料缺失。
> 本文件梳理势力之间的**暗线**：谁在利用谁、谁被谁放弃、谁的立场是假的。

---

## 一、暗线的构成

| 编号 | 暗线 | 核心问题 |
|---|---|---|
| SUB-01 | 黑野氏的操盘 | 一个企业凭什么接管军事部门，并独家生产全部构造体？ |
| SUB-02 | 遗忘者的被放弃 | 大撤离时被丢下的部队，为何至今不肯回头 |
| SUB-03 | 守林人的原罪 | 为什么整个组织由"罪人"的后代组成 |
| SUB-04 | 九龙的闭关 | 一个"自救计划"如何把国家变成密室 |
| SUB-05 | 黄金之涡的希望 | "能让病毒消失"是真相还是骗局 |
| SUB-06 | 阿迪莱的内裂 | 君主制与商业利益的结构性冲突 |
| SUB-07 | 北极航线的免疫孤岛 | 为什么那里病毒浓度长期偏低 |
| SUB-08 | 升格者的理念战 | 他们"传播理念"，而非单纯杀戮 |

## 二、逐条暗线

### SUB-01 黑野氏的操盘

| 项目 | 内容 | 证据 |
|---|---|---|
| 权力 | 帕弥什爆发后**接管整个军事部门** | 【已核实】 |
| 计划 | 制定夺回地球的"**黎明行动**" | 【已核实】 |
| 垄断 | 地球上行动的全部构造体的**生产与开发商** | 【已核实】 |
| 地位 | 世界政府掌权层的**核心之一** | 【已核实】 |
| 阴影 | 统治局（帕弥什爆发地）原为其处理**残次品智能机械**的暂存地 | 【已核实】 |
| 判断 | 世界的"反击"能力，在产业链上完全依赖一家企业——这是本作最大的结构性隐患 | 【推测】 |
