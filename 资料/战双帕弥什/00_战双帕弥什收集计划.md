# 《战双帕弥什》资料收集计划

> 制定时间：2026-10-18
> 状态：**待确认后执行**
> 说明：本作是长线运营手游（2019-12 上线，至今仍在更新），体量与结构完全不同于前 9 个系列，故不能沿用"一部作品一套文件"的旧办法，需改为**模块化分组**。

---

## 一、为什么必须换方法

| 维度 | 前 9 个系列（单机/短篇） | 战双帕弥什 |
|---|---|---|
| 作品形态 | 一部一个独立作品 | **单一持续运营的服务型游戏** |
| 剧情体量 | 单部 2–20 小时 | 主线 **序章 + 24 章**（且仍在增加），另有外篇、间章、浮点纪实、活动剧情 |
| 角色体量 | 十余人 | **构造体机体 100+**（同一角色的多个机体） |
| 版本数量 | 1–13 部 | **60+ 个版本**（2019-12 至今） |
| 叙事结构 | 线性 | **主线 + 外篇 + 间章 + 据点 + 活动** 五条平行线，且互相补完 |
| 官方完整度 | 单机剧情可完整获取 | 官方无统一剧情库，需跨 B 站 Wiki、萌娘百科、灰机 Wiki、玩家整理拼合 |

**结论**：以"篇章 / 势力 / 角色 / 版本"四个维度切分，做 **10 个模块 × 7 文件 + 1 总览 = 71 个文件**。

## 二、世界观骨架（决定分组的依据）

### 核心概念

| 概念 | 说明 |
|---|---|
| **帕弥什（Punishing）** | 同时感染机械与人类的病毒；新地球历 2079 年从第一座零点能反应堆真空腔体爆发，随大气环流蔓延全球 |
| **感染体** | 被帕弥什完全感染的个体总称（电子设备、机械体、构造体） |
| **构造体** | 半机械半生物体，由与**钽-193 共聚物**相性良好的人类改造而成；靠**意识海**网络维持人类意识 |
| **升格者** | 选择接纳帕弥什病毒、借其力量的组织；通过**升格网络**共享维持自我意识的能力 |
| **异合生物** | 帕弥什模拟地球生物进化、自**红潮**诞生的生物化存在 |
| **红潮** | 加百列用异聚核心培育，帕弥什生物化的开端；吞噬并分解生物与机械，可提取其中信息（如人类记忆） |
| **C.P.F. 离心式病毒过滤塔** | 城市中心过滤空气的塔；全球建成 351 座，多数幸存城市以塔号重新命名 |
| **万世铭** | 九龙首领**曲**根据华胥推演制定的自救计划：将九龙子民以数据样本保存于虚拟空间 |
| **格式塔 / 华胥** | 两套超级 AI：格式塔为空中花园最高管控 AI；华胥为九龙商会同源技术结晶 |
| **主线 28 章之后的关键揭示** | 帕弥什病毒本质上是一种"**信息**"的传递 |

### 主要势力（14+）

空中花园（伊甸级）／人类阵线／执行部队（灰鸦小队）／科学理事会／世界政府／黑野氏科技集团（C.T.G.C）／寰宇技师工会／北极航线联合／守林人／遗忘者（Forsaken）／黄金之涡／阿迪莱商业联盟／九龙联合共同体（商会·古都·夜航船）／统治局／升格者

## 四、每个模块的 7 文件标准（沿用统一 5 项）

1. `01_<模块>_主线剧情.md` —— 该模块的叙事主干（角色模块则为"角色事迹总述"）
2. `02_<模块>_支线剧情.md` —— 该模块的支线/旁支/隐藏内容
3. `03_<模块>_游戏内全部档案.md` + `03_<模块>_档案清单.csv`
4. `04_<模块>_角色档案.md` + `04_<模块>_角色清单.csv`
5. `05_<模块>_大事件时间线.md`

### "档案"在本系列的专门口径

手游没有传统"收集品"，本资料库把"档案"定义为以下六类：

| 类型 | 内容 |
|---|---|
| **剧情档案** | 主线/外篇/间章的剧情节点与解锁条件 |
| **构造体机体** | 每台机体的型号、属性、武器、登场版本 |
| **意识（意识套装）** | 装备系统，含套装名与来源 |
| **涂装** | 皮肤，含名称、所属机体、获取方式 |
| **敌方图鉴** | 感染体/BOSS/升格者/异合生物 |
| **据点与玩法** | 12 个据点章节、肉鸽（宣叙妄想）、常驻活动 |

## 六、资料来源与可信度策略

| 来源 | 用途 | 可信度 |
|---|---|---|
| **萌娘百科《战双帕弥什/世界观》** | 设定、势力、概念的核心文本 | 高（引官方文案） |
| **萌娘百科《剧情·故事模式》** | 序章至第 24 章章名与梗概 | 高 |
| **B 站专栏（剧情版本顺序 / 观看顺序）** | 版本与剧情的对应关系 | 中高（玩家整理，需交叉验证） |
| **游戏官网（pns.kurogames.com）** | 版本名、版本日期 | 高（一手） |
| **灰机 Wiki / B 站 Wiki** | 机体、意识、涂装等数据 | 中（社区维护） |

**处理原则（沿用已建立的规范）**：
- 证据三档标注：【已核实】/【推测】/【未明确】
- 专有名词用"中文译名（英文原名）"
- 来源冲突时并列标注，不强行统一（如鸣潮的版本日期已出现多处不一）
- **官方未公开的内容一律标注【未明确】，绝不臆造**

## 七、风险与对策

| 风险 | 说明 | 对策 |
|---|---|---|
| **体量失控** | 主线已 24 章且仍在增加，角色机体 100+ | 严格按 10 模块封顶；每模块只做"主干 + 关键节点"，不做逐句梳理 |
| **版本仍在更新** | 最新版本 2026-05「长路归航」，之后仍有新版本 | 在总览与年表中注明"截至 2026-10" |
| **机体命名混乱** | 同一角色多个机体（如露西亚·鸦羽 / 深红之渊） | 角色档案中以"角色"为主键、机体为子项 |
| **剧情散落多线** | 主线/外篇/间章/据点互相补完 | 在总览中给出**推荐阅读顺序**（已有 B 站成熟整理可参考） |
| **官方无统一剧情库** | 需跨 4–5 个来源拼合 | 每条关键结论标注来源；冲突处并列 |

## 八、需要你确认的三件事

1. **分组粒度**：10 模块 / 71 文件是否合适？若嫌多，可压缩为 6 模块（合并主线三组、合并角色两组）约 43 文件。
2. **角色收录范围**：只收**可操作机体**，还是也收 NPC（如多米尼克、哈桑、加百列等）？
3. **版本年表详细度**：每个版本只记"版本名 + 日期 + 新机体"，还是也记活动与卡池？

> 确认后我按"第 1 步 → 第 5 步"顺序执行，每完成一个阶段向你汇报。
