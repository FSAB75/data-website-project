# 外篇与浮点纪实 — 全貌

> 证据标注：【已核实】多源一致；【推测】合理推断；【未明确】来源冲突或公开资料缺失。
> 本模块收录主线之外的两条平行叙事线：**外篇（EX）** 与**浮点纪实（ER）**。

---

## 一、两条线的性质

| 线 | 编号 | 定位 | 与主线关系 |
|---|---|---|---|
| **外篇** | EX00–EX05 及后续 | 补充主线关键情节、交代角色去向 | **必看**——外篇剧情基本都"沾着主线" |
| **浮点纪实** | ER00 起 | "既不是主线，也不是外篇，就是一个故事" | 独立性强，但补完角色与世界观 |

> 玩家共识：**"外篇（EX）和主线剧情是联系的，所以一定要都看；间章是为了加深对角色理解，与主线关系不大。"**【已核实】

## 五、推荐观看顺序（综合玩家整理）

**第一段（1–12 章期间）**
前八章 → **EX00 极地暗流** → 露西亚·深红之渊间章 → 黄金之涡 → 艾拉间章 → 第九、十章 → 第十一章 → 库洛姆·弧光间章 → 第十二章

**第二段（12 章之后 – 17 章）**
露西亚·鸦羽间章 → **EX01 湛蓝曙日** → **EX02 重返极夜** → **EX03 古铭遗章（含隐藏线）** → 第十三章 → **EX04 咏叹回声** → 赛琳娜间章 → 第十四章 → 库洛姆·荣光间章 → **EX05 迷境刻痕** → 第十五章 → 第十六章 → 第十七章

**第三段（17 章之后）**
丽芙·极昼间章 → 第十八章 → **EX06 遥岸方舟** → 第十九章 → **EX07 枯朽为灯** → 第二十章及之后

**浮点纪实**：可独立观看，建议在对应版本之后补。
