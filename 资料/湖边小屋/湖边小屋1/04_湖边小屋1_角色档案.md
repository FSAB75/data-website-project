# 04 湖边小屋1 角色档案

> 对应游戏：《湖边小屋》（Lakeview Cabin, 2013）
> 收录范围：**主角** + **最终 BOSS**。
> 说明：本作**无文本、无角色姓名**，所有"角色"信息均来自制作者自述、媒体解析与系列后续补完。本文件严格区分【已核实】与【推测】。
> 证据标注：【已核实】【推测】【未明确】。

---

## 一、可操控角色

### 1.1 红发大叔（The Red-Haired Man / 主角）

| 项目 | 内容 |
|------|------|
| 身份 | **玩家唯一可操控角色**；湖边小屋的居住者 |
| 姓名 | **无**（本作无文本，未赋予姓名） |
| 形象 | **红发**中年男性 |
| 日常 | 修剪草坪、喝饮料、蒸桑拿、打猎 |
| 核心行为 | **把妻子（金发女鬼）杀害并扔进湖里**——岛右边水中的气泡即为其妻 |
| 命运 | 半夜独自面对前来"锁魂"的亡妻；"**命运似乎早已注定**" |

**说明**：其"杀妻"动机在初代**完全未交代**，直到 **2023 年的《湖边小屋2》（前传）**才揭晓——**因妻子身处邪教的过往而产生心魔**。

**证据等级：【已核实】（今日头条、萌娘百科、Wikipedia）。**

---

## 二、最终 BOSS

### 2.1 金发女鬼（The Blonde Ghost / 亡妻）

| 项目 | 内容 |
|------|------|
| 身份 | **本作最终 BOSS**；主角的**亡妻** |
| 形象 | **金发**女鬼；**怀孕**（制作者以其怀孕妻子为原型） |
| 来源 | 被丈夫杀害并**扔进湖里**；**岛右边水中的气泡**即其遗体所在 |
| 行为 | 半夜前来向主角"**锁魂**" |
| **系列地位** | **贯穿整个系列的 BOSS** |
| 原型 | **制作者 Roope Tamminen 自己怀孕的妻子**——因为他"完全没想过如何给这位妻子自圆其说" |
| 初代反派构成 | "**一名孕妇与她未出世的胎儿**" |

**证据等级：【已核实】（Wikipedia、今日头条、萌娘百科）。**

## 四、角色关系速览

```
红发大叔（主角）
   │  杀害
   ▼
金发女鬼（亡妻，怀孕）
   │
   ├─ 遗体被扔进湖里 → 岛右边水中的气泡
   └─ 半夜前来"锁魂"（初代最终BOSS）
          │
          └─ 【贯穿整个系列的BOSS】
                 【动机之谜直到《湖边小屋2》（前传）才揭晓：
                  妻子身处邪教的过往 → 大叔心魔 → 杀妻投湖】
```
