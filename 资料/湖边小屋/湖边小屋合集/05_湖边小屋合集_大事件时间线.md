# 05 湖边小屋合集 大事件时间线

> 对应游戏：《湖边小屋合集》（Lakeview Cabin Collection, 2015）
> 说明：本作由**五部"同一宇宙、彼此关联"的电影**组成，各电影时间不同。本时间线以"**电影内时序**"为骨架，并附**解锁顺序**与**现实发布时间轴**。

## 四、开发沿革（时间线中的"另一条线"）

| 时间 | 事件 |
|------|------|
| 开发初期 | Roope 想做一款类似 8-bit《松鼠大作战》机制的**小原型**，后**转为恐怖游戏** |
| 进一步开发前 | 因**妻子正怀孕**，Roope **寻求妻子同意**才做恐怖游戏（初代反派是孕妇与胎儿） |
| 初代之后 | 因初代偏**卡通风**，Roope 决定后续作品改 **8-bit 风**——更便于单人开发 |
| 2014 | 宣布寻求 **Steam Greenlight** 并在 Steam 发售 |
| **2015-03-25** | **合集发售**（Steam / Humble Bundle / itch.io） |
| 2017 | 追加小游戏《去年圣诞》 |
| **2024-07-25** | 登陆 **PS4 / PS5 / Xbox One / Xbox Series X\|S** |

**证据等级：【已核实】（Wikipedia）。**

## 五、要点与易混提示

1. **"电影"是叙事框架**：五部电影是"影院里播放的片子"，尾声则揭示"激发这些电影的真实事件"——这是理解合集结构的关键。
2. **枢纽关卡的前身**：影院关卡原计划是《湖边小屋 VI：曼哈顿湖大屠杀》，因太小而改为枢纽。
3. **III 的时间最明确**：初代约十年后——是唯一有明确时序锚点的电影。
4. **VIII 的顺序即解锁顺序**：小游戏需全部完成后才解锁。
5. **合集是系列主体**：初代的世界观在合集中才"基本展现出来"。
