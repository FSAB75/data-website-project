# 游戏科普网站

以**「游戏系列」为单位**的剧情 / 世界观科普百科站。

## 站点结构

```
系列（Series）
├── 系列主页 —— 作品卡片列表 + 底部世界观时间轴
└── 作品（Work）
    ├── 主线剧情
    ├── 支线剧情
    ├── 人物图鉴
    ├── 收集资料
    └── 剧情连接
```

## 核心特性

- **世界观时间轴**：某时发生什么大事件，哪部作品的哪个角色在经历什么
- **术语高亮联动**：剧情正文中的人名、实验 / 项目名、组织名、地名等关键词高亮可交互，
  悬停弹出卡片，或跳转到词条详情页 / 游戏内文档条目
